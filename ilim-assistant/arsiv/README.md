# Dijital arşiv kökü — Ümit & Gökçenur

RÜZGAR’ın **Kültür ve İlim Hazinesi** vizyonu: tasavvuf, hadis, klasik Türk edebiyatı ile tarih–kültür kaynaklarını aynı çatı altında, RAG ile okunabilir kılmak.

## Üst klasörler

| Klasör | Kapsam |
|--------|--------|
| `Tasavvuf_Kulliyati` | Mektubat, Mesnevî, Füsûs vb. tasavvuf külliyatı |
| `Hadis_Kulliyati` | Kutüb-i Sitte ve temel hadis literatürü |
| `Klasik_Turk_Edebiyati` | Divânlar, mesnevîler, şerhler |
| `Tarih_ve_Kultur` | Osmanlı ve İslâm tarihi kaynakları |

PDF, TXT ve `.md` dosyalarını ilgili alt klasörlere koyduktan sonra:

```bash
python -m ilim_assistant.arsiv_indexle
```

İndeks `knowledge/` ile birlikte oluşturulur.
