# Zenodo research sharing (devam 17)

---

Development Branded communities (part 1) As part of HORIZON-ZEN, we'll add support for custom visual identity on communities. The feature will only be available for specific communities. Launched on EU Open Research Repository Projects Launch of Software Heritage integration. We will launch the SWH integration on Zenodo during summer 2024. Planned October 2024 Projects EU Open Research Repository The EU Open Research Repository will be expanded to allow projects to more easily sign up. Completed June 2024. Development IIIF &amp; Annotations Support for storing and displaying WADM -based annotations for PDFs and images for the Biodiversity Literature Repository. Part of the work will focus on improving performance of the IIIF APIs so that we can make image Zoom generally available. Planned July 2024. Projects BiCIKL As part of the BiCIKL project , provide the infrastructure to support the FAIR preservation of liberated data and next-generation semantic publishing in biodiversity. 2023 DevOps Migration to OpenSearch Migrate our ElasticSearch infrastructure to OpenSearch. Planned March 2023 Development Zenodo on InvenioRDM We are migrating Zenodo's underlying technical platform to InvenioRDM. Follow the progress on https://zenodo-rdm.web.cern.ch as well as the InvenioRDM Roadmap Completed October 13, 2023 Projects HORIZON-ZEN kick-off We are kicking off a new EU-funded project that over the coming 2 years will adding multiple new features to communities such as branding capabilities, subcommunities, basic automated curation checks, and integrate third-party FAIR assessment tools directly in the Zenodo interface. Development Webhooks Webhook notifications support for community events. Cancelled/postponed 2022 Development Custom metadata Allowing user to enhance uploads with their domain-specific vocabulary metadata. DevOps Spam fighting improvements Introduce safe listing of users and a process to safe list new users and block publishing from identified spammer domains. Development Improved funding metadata Being able to specify funding information for uploads on the funder level, or fill-in custom funding metadata. Development ZenodoRDM: Legacy APIs Add basic support for existing Zenodo legacy APIs in InvenioRDM and perform the first initial data migration tests. Development ZenodoRDM Demo Site Setup a Zenodo-themed instance of InvenioRDM and make it publicly available so that users can follow progress on the move to InvenioRDM. Available on https://zenodo-rdm.web.cern.ch Development Workflows type Introduce a new Workflow upload type and integrate with REANA. 2021 Development EOSC AAI Integrate with OpenAIRE AAI to allow researchers to sign-in via their institution. Development ORCiD integration Allowing users in the upload form to search and auto-fill author names coming from ORCiD's database. DevOps Upgrade to PostgreSQL v12 In collaboration with the DBoD team at CERN, upgrade our databases to PostgreSQL v12. Development Stability improvements to GitHub integration Automatic retries for failed GitHub releases, better documentation on .zenodo.json , and overall easier troubleshooting. Development Community record requests Introduce a review workflow for adding records to communities. Projects 300k treatments Import a dataset of 300.000 biodiversity treatments records into Zenodo in collaboration with Plazi and Pensoft via an Arcadia Fund project. 2020 Development Thumbnails Produce thumbnails via IIIF APIs with proper caching. Projects Zenodo-Dryad integration Integration of Zenodo into the Dryad submission process. Development New resource types Support for two new resource types: Data Management Plan, Annotation Collection Development DCAT export format Support for the DCAT export format via the DataCite XML to DCAT XSLT. 2019 Development Citations Improve the regular import of citations from NASA ADS, OpenAIRE
