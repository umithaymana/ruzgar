limx → ∞f (x) = ∞ (or limx → −∞f (x) = ∞). On the other hand, if the values off are negative but become arbitrarily large in
magnitude as x → ∞ (or as x → −∞), we write limx → ∞f (x) = −∞ (or limx → −∞f (x) = −∞).
