Graphing a Function Using y- intercept and Slope Another way to graph linear functions is by using specific characteristics of the function rather than plotting points. The first characteristic is its y- intercept, which is the point at which the input value is zero. To find the y- intercept, we can set x = 0 x = 0 in the equation. The other characteristic of the linear function is its slope . Let’s consider the following function. f ( x ) = 1 2 x + 1 f ( x ) = 1 2 x + 1 The slope is 1 2 . 1 2 .
