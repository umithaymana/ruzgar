(3.10) Since the indefinite integral of a vector-valued function involves indefinite integrals of the component functions, each of these component integrals contains an integration constant. They can all be different. For example, in the two-dimensional case, we can have ∫ f ( t ) d t = F ( t ) + C 1 and ∫ g ( t ) d t = G ( t ) + C 2 , ∫ f ( t ) d t = F ( t ) + C 1 and ∫ g ( t ) d t = G ( t ) + C 2 , where F and G are antiderivatives of f and g, respectively.
