We conclude this section with a word of warning: The Cross-Partial Property of Conservative Vector Fields says that if F is conservative, then F has the cross-partial property. The theorem does not say that, if F has the cross-partial property, then F is conservative (the converse of an implication is not logically equivalent to the original implication). In other words, The Cross-Partial Property of Conservative Vector Fields can only help determine that a field is not conservative; it does not let you conclude that a vector field is conservative. For example, consider vector field F ( x , y ) = 〈 x 2 y , x 3 3 〉 . F ( x , y ) = 〈 x 2 y , x 3 3 〉 . This field has the cross-partial property, so it is natural to try to use The Cross-Partial Property of Conservative Vector Fields to conclude this vector field is conservative.
