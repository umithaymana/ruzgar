Using just polynomial arithmetic (with a dash of circuit engineering cleverness), we can solve surprisingly complex problems without knowing anything about the input. Combining this with a carefully designed software system optimized for parallel computing, we&#x27;ve built things from Fog of War chess to a Connect Four engine and more — all fast enough that you can barely tell anything different is happening under the hood. Fog of War Chess Fog of War chess is a chess variant in which each player sees only the squares their pieces can move to. Normally that takes a central server that knows both players&#x27; pieces and calculates what each side can see. Under FHE, clever board and piece encodings enable each side&#x27;s vision to be computed entirely on encrypted data. No one sees the full board until the game ends, and in some implementations no server is needed at all, as the encrypted calculations can run in a player&#x27;s browser. Connect Four In Connect Four, the first player can always force a win, but the winning strategies involve a lot of branching, which is hard under FHE because every operation must be data-oblivious. Instead, the engine precomputes a set of early-game moves and selects among them with an encrypted one-hot board state until the board reaches a steady state. From there it tracks that state and plays by a small set of rules instead of memorized moves.
