In particular, if f ( − x ) = f ( x ) f ( − x ) = f ( x ) for all x x in the domain of f , f , then f f is an even function and its graph is symmetric with respect to the y -axis. If f ( − x ) = − f ( x ) f ( − x ) = − f ( x ) for all x x in the domain of f , f , then f f is an odd function and its graph is symmetric with respect to the origin.
