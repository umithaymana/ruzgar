Transcendental Functions
Thus far, we have discussed algebraic functions. Some functions, however, cannot be described by basic algebraic
operations. These functions are known astranscendental functions because they are said to “transcend,” or go beyond,
algebra. The most common transcendental functions are trigonometric, exponential, and logarithmic functions. A
trigonometric functionrelatestheratiosoftwosidesofarighttriangle.Theyare sinx, cosx, tanx, cotx, secx, and cscx.
(We discuss trigonometric functions later in the chapter.) An exponential function is a function of the formf (x) = bx,
where the baseb > 0, b ≠ 1. A logarithmic function is a function of the formf (x) = logb(x) for some constant
b > 0, b ≠ 1, where logb (x) = y if and only ifby = x. (We also discuss exponential and logarithmic functions later in
the chapter.)
