Power Functions
Somepolynomialfunctionsarepowerfunctions.A power functionisanyfunctionoftheform f (x) =axb, where a and
b are any real numbers. The exponent in a power function can be any real number, but here we consider the case when the
exponent is a positive integer. (We consider other cases later.) If the exponent is a positive integer, thenf (x) =axn is a
polynomial. Ifn is even, thenf (x) =axn is an even function becausef (−x) =a(−x)n = axn if n is even. Ifn is odd,
