The Exponential Function
Wenowturnourattention tothe function ex. Note that the natural logarithm is one-to-one and therefore has an inverse
function. For now, we denote this inverse function by expx. Then,
exp(lnx) = x forx > 0 and ln(expx) = x for allx.

We hypothesize that expx = ex. For rational values ofx, this is easy to show. Ifx is rational, then we have
ln(ex) = x lne = x. Thus, when x is rational, ex = expx. For irrational values ofx, we simply defineex as the
inverse function of lnx.
