Additive Principle.
The additive principlestates that if eventA can occur inm ways,
andevent B canoccurin n disjointways,thentheevent“ Aor B”can
occur inm + n ways.
It is important that the events bedisjoint: i.e., that there is no way for
A and B to both happen at the same time. For example, a standard deck of
52 cards contains26 red cards and12 face cards. However, the number of
ways to select a card which is either red or a face card is not26 + 12 /equalx 38.
This is because there are 6 cards which are both red and face cards.

Multiplicative Principle.
The multiplicative principlestates that if eventA can occur inm
ways, and each possibility forA allows for exactlyn ways for event
B, then the event “A and B” can occur inm· n ways.
The multiplicative principle generalizes to more than two events as
well.
