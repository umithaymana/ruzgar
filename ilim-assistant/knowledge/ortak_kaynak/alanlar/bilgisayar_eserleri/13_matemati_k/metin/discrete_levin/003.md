The reason the sentence “3 + x /equalx 12” is not a statement is that it
contains a variable. Depending on whatx is, the sentence is either true
or false, but right now it is neither. One way to make thesentenceinto a
statementis to specify the value of the variable in some way. This could be
done by specifying a speciﬁc substitution, for example, “3 + x /equalx 12 where
x /equalx 9,” which is a true statement. Or you couldcapturethe free variable
byquantifyingover it, as in, “for all values ofx, 3 + x /equalx 12,” which is false.
We will discuss quantiﬁers in more detail at the end of this section.
You can build more complicated (molecular) statements out of simpler

Note that we can break this down into two smaller statements. The
two shorter statements areconnected by an “and.” We will consider 5
connectives: “and” (Sam is a man and Chris is a woman), “or” (Sam is a
