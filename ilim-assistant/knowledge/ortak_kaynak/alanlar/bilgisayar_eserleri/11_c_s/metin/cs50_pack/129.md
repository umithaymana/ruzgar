NPS and Sentiment Analyzer (Portuguese Language) by Silene Bonfante Garcia Barcaro This project is the NPS and Sentiment Analyzer, a web application built with Python and Flask. Its main objective is to automate customer feedback analysis, transforming large volumes of raw data into actionable business insights. The primary motivation was to solve the inefficiency and inaccuracy of manual comment analysis. The system handles two pillars of analysis: (1) Real-time Sentiment Analysis of Portuguese texts, classifying them as Positive, Neutral, or Negative; and (2) Bulk NPS Calculation, processing entire files to generate the Net Promoter Score metric. For the sentiment analysis in Portuguese, I utilized the Hugging Face (Transformers) library with a specific BERT model. I overcame the challenge of achieving precision by employing a hybrid system that combines artificial intelligence with a rule-based fallback logic based on strong keywords, guaranteeing 100% accuracy in extreme cases. The final solution offers data visualization via Matplotlib (for the NPS evolution graph) and includes a secure authentication system. The project demonstrates proficiency in web development, data analysis, and the practical application of AI.
