CS50 AI Grammer Corrector by Oussama Ghedjati ## 📖 Description The Grammar Corrector Web App is a platform designed to help users improve their writing by detecting and correcting grammatical mistakes. Many people struggle with grammar, and existing tools often provide corrections without explaining why the mistake happened. This project addresses that gap by not only fixing mistakes but also teaching the user the grammar rules behind those corrections. When a user enters a text, the application uses an AI model to analyze the content. It then highlights mistakes, suggests corrections, and provides clear explanations of the grammar rules. This way, users can learn as they write, turning errors into opportunities for improvement. The corrections are shown side by side with the original text so users can easily compare their writing with the suggested improvements. Another important feature of the application is the history system. Every time a user submits text, the original version, corrected version, and the chosen language are saved. Users can return later to review their submissions, track progress, and better understand recurring mistakes they make. Over time, this history helps learners reflect on their improvement and identify areas they need to focus on. The main purpose of this project is not just to provide instant grammar corrections, but to build a tool that supports long-term language learning. By combining correction with explanation, the app empowers users to become more confident writers. In the future, additional features such as real-time corrections, support for more languages, and personalized feedback could make the app even more powerful.
