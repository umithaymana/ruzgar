How to Take this Course Even if you are not a student at Harvard, you are welcome to “take” this course for free via this OpenCourseWare by working your way through the course’s eleven weeks of material. For each week, follow this workflow: flowchart TD A[Watch Lecture] --&gt; |recommended|B[Watch Section] A --&gt; D B --&gt; |recommended|C[Watch Shorts] B --&gt; D[Submit Problem Set] C --&gt; D And then submit the course’s final project . To submit the course’s problem sets and final project for feedback, be sure to create an edX account , if you haven’t already. Ask questions along the way via any of the course’s communities !
