It is free software released under the three-clause BSD license.[2] The name is derived from the term "panel data", an econometrics term for data sets that include observations over multiple time periods for the same individuals.[3] Its name is a play on the phrase "Python data analysis" itself.[4] Wes McKinney started building what would become pandas at AQR Capital while he was a researcher there from 2007 to 2010.[5] DataFrames Pandas is mainly used for data analysis and associated manipulation of tabular data in DataFrames. The development of pandas introduced into Python many comparable features of working with DataFrames that were established in the R programming language.
