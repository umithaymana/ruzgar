When a primary zone is loaded for the first time, if the zone's file does not exist but initial-file does, the zone file is copied into place from the initial file before loading. This can be used to simplify the process of adding new zones, removing the need to create the zone file before configuring the zone. For example, a template zonefile could be used by running: $ rndc addzone example.com \ '{ type primary; file "$name.db"; initial-file "template.db"; };' This creates a zone ``example.com``, with filename ``example.com.db``.
