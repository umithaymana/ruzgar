[GL !11790] Remove unneeded options in dns_zonefetch. a43a6cfba4 In the dns_zonefetch mechanism, some option flags for dns_resolver_createfetch() were used for all fetches, but were actually only needed by the DNSKEY refresh fetches. [GL !11866] Stop rndc-confgen from following symlinks when writing the keyfile. 468b09feb2 When rndc-confgen -a (re)created the rndc control key, it followed a symbolic link if one happened to exist at the keyfile path: the existence check looked through the link, then the file was truncated, its ownership changed, and the key contents written into whatever file the link pointed at. rndc-confgen now refuses to follow symbolic links at the keyfile path and fails with an error instead, so the wrong file can no longer be overwritten by accident.
