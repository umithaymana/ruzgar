The file, along with all files included by it, is parsed and checked for syntax errors. If no file is specified, /etc/named.conf is read by default. Note: files that named reads in separate parser contexts, such as rndc.conf or rndc.key , are not automatically read by named-checkconf . Configuration errors in these files may cause named to fail to run, even if named-checkconf was successful. However, named-checkconf can be run on these files explicitly.
