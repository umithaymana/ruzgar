[GL #5653] Notes for BIND 9.21.15  New Features  New rndc showconf command. The new rndc showconf command prints the running server configuration. There are three options: rndc showconf -user shows only settings explicitly declared in named.conf . rndc showconf -builtin shows the default settings, similar to named -C . rndc showconf -effective shows the result of applying user settings to defaults. [GL #1075] named-checkconf -b dumps the built-in configuration. named-checkconf now supports the option -b , that prints the default built-in configuration used by named . When the option is used, other options are ignored. [GL #1326] named-checkconf -e prints the effective configuration. The new named-checkconf -e option prints the effective server configuration. This is what would result from loading the specified configuration file into named . The report includes all default settings, as modified by user values from the configuration file.
