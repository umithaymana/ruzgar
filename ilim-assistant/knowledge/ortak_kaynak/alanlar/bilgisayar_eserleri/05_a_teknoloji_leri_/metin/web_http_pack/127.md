If enabled, BIND 9 does not generate signatures for the DNSKEY, CDS, and CDNSKEY RRsets. Instead, the signed DNSKEY, CDS and CDNSKEY RRsets are looked up from Signed Key Response (SKR) files. Any existing DNSKEY, CDS, and CDNSKEY RRsets in the unsigned version of the zone are filtered and replaced with RRsets from the SKR file. This feature is off by default.
