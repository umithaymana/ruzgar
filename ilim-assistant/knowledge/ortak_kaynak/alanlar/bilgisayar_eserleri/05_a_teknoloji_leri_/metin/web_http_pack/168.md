Resolver Queries Response Time counters  named provides query response round-trip time (RTT) counters (histogram) both for incoming and outgoing queries in milliseconds. Response times which are lower than 1ms are calculated under the ~0 counter. Response times from 1ms to 15ms are calculated under their own counters, e.g. a response that took 5ms to complete is calculated under the 5 counter. Response times starting from 16ms are calculated under the MinMS-MaxMS (inclusive) range counters. For example, a response that took 18ms to complete is calculated under the 18-19 counter, and a response that took 550ms to complete is calculated under the 512-575 counter. 8.5.2.5. Socket I/O Statistics Counters  Socket I/O statistics counters are defined per socket type, which are UDP4 (UDP/IPv4), UDP6 (UDP/IPv6), TCP4 (TCP/IPv4), and TCP6 (TCP/IPv6). In the following list, &lt;TYPE&gt; represents a socket type. Not all counters are available for all socket types; exceptions are noted in the descriptions. &lt;TYPE&gt;Accept This indicates the number of incoming connections successfully accepted. This counter does not apply to the UDP type. &lt;TYPE&gt;AcceptFail This indicates the number of failures to accept incoming connection requests. This counter does not apply to the UDP type. &lt;TYPE&gt;BindFail This indicates the number of failures to bind sockets. &lt;TYPE&gt;Clients This indicates the number of currently conencted clients. This counter does not apply to the UDP type. &lt;TYPE&gt;Close This indicates the number of closed sockets. &lt;TYPE&gt;ConnFail This indicates the number of failures to connect sockets. &lt;TYPE&gt;Conn This indicates the number of connections established successfully. &lt;TYPE&gt;Open This indicates the number of sockets opened successfully. &lt;TYPE&gt;OpenFail This indicates the number of failures to open sockets. &lt;TYPE&gt;RecvErr This indicates the number of errors in socket receive operations, including errors of send operations on a connected UDP socket, notified by an ICMP error message. &lt;TYPE&gt;SendErr This indicates the number of errors in socket send operations.
