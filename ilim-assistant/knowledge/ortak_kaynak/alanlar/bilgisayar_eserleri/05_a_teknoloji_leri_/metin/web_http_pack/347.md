[GL !10282] Removed Features  Deprecate the &quot;tkey-gssapi-credential&quot; statement. c47e8edd09 The tkey-gssapi-keytab statement allows GSS-TSIG to be set up in a simpler and more reliable way than using the tkey-gssapi-credential statement and setting environment variables (e.g. KRB5_KTNAME ).
