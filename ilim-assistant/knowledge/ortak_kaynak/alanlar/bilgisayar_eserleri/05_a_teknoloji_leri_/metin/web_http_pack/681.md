But what you should do is only use the s_addr field in this structure, because many systems only implement that one. struct sockaddr_in6 and struct in6_addr are very similar, except they’re used for IPv6. struct sockaddr_storage is a struct you can pass to accept() or recvfrom() when you’re trying to write IP version-agnostic code and you don’t know if the new address is going to be IPv4 or IPv6. The struct sockaddr_storage structure is large enough to hold both types, unlike the original small struct sockaddr .
