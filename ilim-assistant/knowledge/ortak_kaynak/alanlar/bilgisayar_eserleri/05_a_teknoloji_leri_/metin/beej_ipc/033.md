How can we put it all together into a chat server that you can telnet to? What we’ll do is start a listener socket, and add it to the set of file descriptors to poll() . (It will show ready-to-read when there’s an incoming connection.) Then we’ll add new connections to our struct pollfd array. And we’ll grow it dynamically if we run out of space. When a connection is closed, we’ll remove it from the array. And when a connection is ready-to-read, we’ll read the data from it and send that data to all the other connections so they can see what the other users typed. So give this poll server 30 a try. Run it in one window, then telnet localhost 9034 from a number of other terminal windows. You should be able to see what you type in one window in the other ones (after you hit RETURN).
