Sends the chunk header (&lt;hex-size&gt;\r\n) per RFC 7230. After this call, use esp_http_client_write() to send the chunk body data, then call esp_http_client_chunk_write_end() to finish the chunk. For normal (non-chunked) write operations this API is not used. Parameters : client -- [in] The esp_http_client handle (must not be NULL) len -- [in] Length of the chunk body that will follow (must be &gt; 0) Pre : Transfer-Encoding: chunked header must be set and esp_http_client_open() called with write_len = -1. Returns : 0 on success -1 on failure (NULL client, invalid state, len &lt;= 0, or transport write error) int esp_http_client_chunk_write_end ( esp_http_client_handle_t client , bool last_chunk )  End writing a chunk in chunked transfer encoding mode. Sends the chunk trailer (\r\n) per RFC 7230 to complete a chunk started by esp_http_client_chunk_write_begin(). When last_chunk is true, also sends the final terminator (0\r\n\r\n) to signal end of chunked body. For normal (non-chunked) write operations this API is not used.
