Attention 1. This API will return ESP_FAIL when called for STA interface (req-&gt;ifx == WIFI_IF_STA) while the station is in CONNECTING state. Attention 2. When PMF is enabled, broadcast action frames must be non-robust. Attention 3. wait_time_ms must be greater than 0. If wait_time_ms is 0, the API returns ESP_ERR_WIFI_ARG. Attention 4. The API returns ESP_FAIL while a CSA is pending. An ongoing operation is cancelled when a CSA is received or initiated. Attention 5. For a connected STA the beacon timeout is suspended during the operation and restarted when it ends, so a lost AP is detected only inactive_time (default 6 s) after it completes.
