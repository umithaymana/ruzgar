Aside: Using the Keywords and/or Versus the Operators &amp;/| &#182; One common point of confusion is the difference between the keywords and and or on one hand, and the operators &amp; and | on the other hand. When would you use one versus the other? The difference is this: and and or gauge the truth or falsehood of entire object , while &amp; and | refer to bits within each object . When you use and or or , it's equivalent to asking Python to treat the object as a single Boolean entity. In Python, all nonzero integers will evaluate as True. Thus: In&nbsp;[30]: bool ( 42 ), bool ( 0 ) Out[30]: (True, False) In&nbsp;[31]: bool ( 42 and 0 ) Out[31]: False In&nbsp;[32]: bool ( 42 or 0 ) Out[32]: True When you use &amp; and | on integers, the expression operates on the bits of the element, applying the and or the or to the individual bits making up the number: In&nbsp;[33]: bin ( 42 ) Out[33]: &#39;0b101010&#39; In&nbsp;[34]: bin ( 59 ) Out[34]: &#39;0b111011&#39; In&nbsp;[35]: bin ( 42 &amp; 59 ) Out[35]: &#39;0b101010&#39; In&nbsp;[36]: bin ( 42 | 59 ) Out[36]: &#39;0b111011&#39; Notice that the corresponding bits of the binary representation are compared in order to yield the result. When you have an array of Boolean values in NumPy, this can be thought of as a string of bits where 1 = True and 0 = False , and the result of &amp; and | operates similarly to above: In&nbsp;[37]: A = np . array ([ 1 , 0 , 1 , 0 , 1 , 0 ], dtype = bool ) B = np . array ([ 1 , 1 , 1 , 0 , 1 , 1 ], dtype = bool ) A | B Out[37]: array([ True, True, True, False, True, True], dtype=bool) Using or on these arrays will try to evaluate the truth or falsehood of the entire array object, which is not a well-defined value: In&nbsp;[38]: A or B --------------------------------------------------------------------------- ValueError Traceback (most recent call last) &lt;ipython-input-38-5d8e4f2e21c0&gt; in &lt;module&gt; () ----&gt; 1 A or B ValueError : The truth value of an array with more than one element is ambiguous.
