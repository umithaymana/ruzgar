Pretrained Models &mdash; Sentence Transformers documentation Pretrained Models Edit on GitHub Pretrained Models  We provide various pre-trained Sentence Transformers models via our Sentence Transformers Hugging Face organization. Additionally, over 6,000 community Sentence Transformers models have been publicly released on the Hugging Face Hub. All models can be found here: Original models : Sentence Transformers Hugging Face organization . Community models : All Sentence Transformer models on Hugging Face . Note The sentence-transformers library tag is shared by all four model types, so the community link above also returns Cross Encoder, Sparse Encoder and Multi-Vector Encoder models. Add the cross-encoder , sparse or multi-vector tag to jump to one of those instead. Loading Models For models from the Sentence Transformers Hugging Face organization , you can omit the sentence-transformers/ prefix. For models from other organizations, include the full model ID, as in Qwen/Qwen3-Embedding-0.6B below. Log in with hf auth login for higher Hugging Face Hub rate limits and access to private or gated models your account can read. See the login instructions . Each of these models can be easily downloaded and used like so: from sentence_transformers import SentenceTransformer model = SentenceTransformer ( &quot;Qwen/Qwen3-Embedding-0.6B&quot; ) query = &quot;Which planet is known as the Red Planet?&quot; documents = [ &quot;Jupiter is the largest planet in our solar system.&quot; , &quot;Mars gets its reddish color from iron minerals in its soil.&quot; , &quot;Photosynthesis lets plants turn sunlight into energy.&quot; , ] query_embedding = model . encode_query ( query ) document_embeddings = model . encode_document ( documents ) print ( query_embedding . shape , document_embeddings . shape ) # (1024,) (3, 1024) scores = model . similarity ( query_embedding , document_embeddings )[ 0 ] for index in scores . argsort ( descending = True ): print ( f &quot; { scores [ index ] : .4f } : { documents [ index ] } &quot; ) # 0.6115: Mars gets its reddish color from iron minerals in its soil. # 0.4360: Jupiter is the largest planet in our solar system. # 0.1893: Photosynthesis lets plants turn sunlight into energy. Note Consider using the Massive Textual Embedding Benchmark leaderboard as an inspiration of strong Sentence Transformer models. Be wary: Model sizes : it is recommended to filter away the large models that might not be feasible without excessive hardware. Experimentation is key : models that perform well on the leaderboard do not necessarily do well on your tasks, it is crucial to experiment with various promising models. Tip Read Sentence Transformer &gt; Speeding up Inference for tips on how to speed up inference of models by up to 2x-3x.
