Other plots # Plotting methods allow for a handful of plot styles other than the default line plot. These methods can be provided as the kind keyword argument to plot() , and include: ‘bar’ or ‘barh’ for bar plots ‘hist’ for histogram ‘box’ for boxplot ‘kde’ or ‘density’ for density plots ‘area’ for area plots ‘scatter’ for scatter plots ‘hexbin’ for hexagonal bin plots ‘pie’ for pie plots For example, a bar plot can be created the following way: In [14]: plt . figure (); In [15]: df . iloc [ 5 ] . plot ( kind = "bar" ); You can also create these other plots using the methods DataFrame.plot.&lt;kind&gt; instead of providing the kind keyword argument.
