Behavior differences # Differences in behavior will be primarily due to the kind of NA value. StringDtype with np.nan NA values # Like dtype=&quot;object&quot; , string accessor methods that return integer output will return a NumPy array that is either dtype int or float depending on the presence of NA values. Methods returning boolean output will return a NumPy array that is dtype bool, with the value False when an NA value is encountered. In [129]: s = pd . However boolean output results in False for the NA values. In [133]: s . str . isdigit () Out[133]: 0 False 1 False 2 False dtype: bool In [134]: s . str . match ( "a" ) Out[134]: 0 True 1 False 2 False dtype: bool Some string methods, like Series.str.decode() , are not available because the underlying array can only contain strings, not bytes.
