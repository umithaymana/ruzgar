Vectorized string methods # Series is equipped with a set of string processing methods that make it easy to operate on each element of the array. Perhaps most importantly, these methods exclude missing/NA values automatically. These are accessed via the Series’s str attribute and generally have names matching the equivalent (scalar) built-in string methods. For example: In [308]: s = pd . Series ( .....: [ "A" , "B" , "C" , "Aaba" , "Baca" , np . nan , "CABA" , "dog" , "cat" ], dtype = "string" .....: ) .....: In [309]: s . str . lower () Out[309]: 0 a 1 b 2 c 3 aaba 4 baca 5 &lt;NA&gt; 6 caba 7 dog 8 cat dtype: string Powerful pattern-matching methods are provided as well, but note that pattern-matching generally uses regular expressions by default (and in some cases always uses them). Note Prior to pandas 1.0, string methods were only available on object -dtype Series . pandas 1.0 added the StringDtype which is dedicated to strings. See Text data types for more. Please see Vectorized String Methods for a complete description.
