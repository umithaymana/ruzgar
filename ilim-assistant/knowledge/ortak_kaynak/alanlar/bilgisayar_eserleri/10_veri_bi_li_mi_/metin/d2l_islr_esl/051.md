Models ¶ The Module class is the base class of all models we will implement. At the very least we need three methods. The first, __init__ , stores the learnable parameters, the training_step method accepts a data batch to return the loss value, and finally, configure_optimizers returns the optimization method, or a list of them, that is used to update the learnable parameters. Optionally we can define validation_step to report the evaluation measures.
