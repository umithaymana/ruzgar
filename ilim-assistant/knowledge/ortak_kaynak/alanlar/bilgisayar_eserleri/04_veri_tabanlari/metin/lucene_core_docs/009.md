This optimization used to be an opt-in in late 8.x releases and is now opt-out as of 9.0. ConcurrentMergeScheduler now assumes fast I/O, likely improving indexing speed in case where heuristics would incorrectly detect whether the system had modern I/O or not Encoding of postings lists changed from FOR-delta to PFOR-delta to save further disk space Other File formats have all been changed from big-endian order to little endian order Lucene 9 no longer has split packages. This required renaming some packages outside of the lucene-core JAR, so you will need to adjust some imports accordingly. Using Lucene 9 with the module system should be considered experimental. We expect to make progress on this in future 9.x releases.
