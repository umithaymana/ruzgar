# SQL Index Pack (devam 4)

---

Learn how to enable memory-mapped I/O and about the various advantages and disadvantages to using memory-mapped I/O in this document. Multi-threaded Programs and SQLite &rarr; SQLite is safe to use in multi-threaded programs. This document provides the details and hints on how to maximize performance. Null Handling &rarr; Different SQL database engines handle NULLs in different ways. The SQL standards are ambiguous. This (circa 2003) document describes how SQLite handles NULLs in comparison with other SQL database engines. Partial Indexes &rarr; A partial index is an index that only covers a subset of the rows in a table. Learn how to use partial indexes in SQLite from this document. Shared Cache Mode &rarr; Version 3.3.0 and later supports the ability for two or more database connections to share the same page and schema cache. This feature is useful for certain specialized applications. Unlock Notify &rarr; The "unlock notify" feature can be used in conjunction with shared cache mode to more efficiently manage resource conflict (database table locks). URI Filenames &rarr; The names of database files can be specified using either an ordinary filename or a URI. Using URI filenames provides additional capabilities, as this document describes. WITHOUT ROWID Tables &rarr; The WITHOUT ROWID optimization is a option that can sometimes result in smaller and faster databases. Write-Ahead Log (WAL) Mode &rarr; Transaction control using a write-ahead log offers more concurrency and is often faster than the default rollback transactions. This document explains how to use WAL mode for improved performance. &#x25ba; Tools Command-Line Shell (sqlite3.exe) &rarr; Notes on using the "sqlite3.exe" command-line interface that can be used to create, modify, and query arbitrary SQLite database files. Remote Copy Of A Live Database &rarr; The sqlite3_rsync program makes a consistent copy of a live database to or from a remote system. Database Hash (dbhash.exe) &rarr; This program demonstrates how to compute a hash over the content of an SQLite database. Fossil &rarr; The Fossil Version Control System is a distributed VCS designed specifically to support SQLite development. Fossil uses SQLite as for storage. RBU &rarr; The "Resumable Bulk Update" utility program allows a batch of changes to be applied to a remote database running on embedded hardware in a way that is resumeable and does not interrupt ongoing operation. SQLite Database Analyzer (sqlite3_analyzer.exe) &rarr; This stand-alone program reads an SQLite database and outputs a file showing the space used by each table and index and other statistics. Built using the dbstat virtual table .
