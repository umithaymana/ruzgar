# SQL Index Pack (devam 3)

Csv Virtual Table &rarr; The CSV virtual table allows SQLite to directly read and query RFC 4180 formatted files. Carray &rarr; CARRAY is a table-valued function that allows C-language arrays to be used in SQL queries. generate_series &rarr; A description of the generate_series() table-valued function . Spellfix1 &rarr; The spellfix1 extension is an experiment in doing spelling correction for full-text search . Zipfile &rarr; A [virtual table] with accompanying support functions that can read and write a ZIP archive as if it were a database. The IEEE754 Extension &rarr; A set of SQL functions for encoding and decoding IEEE-754 floating point numbers. The Decimal Extension &rarr; A set of functions for doing arbitrary-precision decimal arithmetic, including expanding IEEE-754 floating point values to their exact decimal representation. The UINT Collating Sequence &rarr; A collating sequence that sorts text with embedded numbers in numeric order. The Percentile Extension &rarr; An implementation of aggregate functions: median() , percentile() , percentile_cont() , and percentile_disc() . &#x25ba; Features 8+3 Filenames &rarr; How to make SQLite work on filesystems that only support 8+3 filenames. Autoincrement &rarr; A description of the AUTOINCREMENT keyword in SQLite, what it does, why it is sometimes useful, and why it should be avoided if not strictly necessary. Backup API &rarr; The online-backup interface can be used to copy content from a disk file into an in-memory database or vice versa and it can make a hot backup of a live database. This application note gives examples of how. Error and Warning Log &rarr; SQLite supports an "error and warning log" design to capture information about suspicious and/or error events during operation. Embedded applications are encouraged to enable the error and warning log to help with debugging application problems that arise in the field. This document explains how to do that. Foreign Key Support &rarr; This document describes the support for foreign key constraints introduced in version 3.6.19. Indexes On Expressions &rarr; Notes on how to create indexes on expressions instead of just individual columns. Internal versus External Blob Storage &rarr; Should you store large BLOBs directly in the database, or store them in files and just record the filename in the database? This document seeks to shed light on that question. Limits In SQLite &rarr; This document describes limitations of SQLite (the maximum length of a string or blob, the maximum size of a database, the maximum number of tables in a database, etc.) and how these limits can be altered at compile-time and run-time. Memory-Mapped I/O &rarr; SQLite supports memory-mapped I/O.
