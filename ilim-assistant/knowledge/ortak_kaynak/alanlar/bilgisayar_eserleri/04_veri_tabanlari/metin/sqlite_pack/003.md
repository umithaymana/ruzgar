# SQLite docs pack (devam 3)

---

Backup API &rarr; The online-backup interface can be used to copy content from a disk file into an in-memory database or vice versa and it can make a hot backup of a live database. This application note gives examples of how. Error and Warning Log &rarr; SQLite supports an "error and warning log" design to capture information about suspicious and/or error events during operation. Embedded applications are encouraged to enable the error and warning log to help with debugging application problems that arise in the field. This document explains how to do that. Foreign Key Support &rarr; This document describes the support for foreign key constraints introduced in version 3.6.19. Indexes On Expressions &rarr; Notes on how to create indexes on expressions instead of just individual columns. Internal versus External Blob Storage &rarr; Should you store large BLOBs directly in the database, or store them in files and just record the filename in the database? This document seeks to shed light on that question. Limits In SQLite &rarr; This document describes limitations of SQLite (the maximum length of a string or blob, the maximum size of a database, the maximum number of tables in a database, etc.) and how these limits can be altered at compile-time and run-time. Memory-Mapped I/O &rarr; SQLite supports memory-mapped I/O. Learn how to enable memory-mapped I/O and about the various advantages and disadvantages to using memory-mapped I/O in this document. Multi-threaded Programs and SQLite &rarr; SQLite is safe to use in multi-threaded programs. This document provides the details and hints on how to maximize performance. Null Handling &rarr; Different SQL database engines handle NULLs in different ways. The SQL standards are ambiguous. This (circa 2003) document describes how SQLite handles NULLs in comparison with other SQL database engines. Partial Indexes &rarr; A partial index is an index that only covers a subset of the rows in a table. Learn how to use partial indexes in SQLite from this document. Shared Cache Mode &rarr; Version 3.3.0 and later supports the ability for two or more database connections to share the same page and schema cache. This feature is useful for certain specialized applications. Unlock Notify &rarr; The "unlock notify" feature can be used in conjunction with shared cache mode to more efficiently manage resource conflict (database table locks). URI Filenames &rarr; The names of database files can be specified using either an ordinary filename or a URI. Using URI filenames provides additional capabilities, as this document describes. WITHOUT ROWID Tables &rarr; The WITHOUT ROWID optimization is a option that can sometimes result in smaller and faster databases. Write-Ahead Log (WAL) Mode &rarr; Transaction control using a write-ahead log offers more concurrency and is often faster than the default rollback transactions. This document explains how to use WAL mode for improved performance. &#x25ba; Tools Command-Line Shell (sqlite3.exe) &rarr; Notes on using the "sqlite3.exe" command-line interface that can be used to create, modify, and query arbitrary SQLite database files. Remote Copy Of A Live Database &rarr; The sqlite3_rsync program makes a consistent copy of a live database to or from a remote system. Database Hash (dbhash.exe) &rarr; This program demonstrates how to compute a hash over the content of an SQLite database.
