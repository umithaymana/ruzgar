TTS Command Line Interface (CLI). - tts Local Demo Server. - tts-server In 🐍Python. - from TTS.api import TTS On the Commandline - tts # After the installation, 🐸TTS provides a CLI interface for synthesizing speech using pre-trained models. You can either use your own model or the release models under 🐸TTS. Listing released 🐸TTS models. tts --list_models Run a TTS model, from the release models list, with its default vocoder. (Simply copy and paste the full model names from the list as arguments for the command below.) tts --text &quot;Text for TTS&quot; \ --model_name &quot;&lt;type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; \ --out_path folder/to/save/output.wav Run a tts and a vocoder model from the released model list. Note that not every vocoder is compatible with every TTS model. tts --text &quot;Text for TTS&quot; \ --model_name &quot;tts_models/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; \ --vocoder_name &quot;vocoder_models/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; \ --out_path folder/to/save/output.wav Run your own TTS model (Using Griffin-Lim Vocoder) tts --text &quot;Text for TTS&quot; \ --model_path path/to/model.pth \ --config_path path/to/config.json \ --out_path folder/to/save/output.wav Run your own TTS and Vocoder models tts --text &quot;Text for TTS&quot; \ --config_path path/to/config.json \ --model_path path/to/model.pth \ --out_path folder/to/save/output.wav \ --vocoder_path path/to/vocoder.pth \ --vocoder_config_path path/to/vocoder_config.json Run a multi-speaker TTS model from the released models list. tts --model_name &quot;tts_models/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --list_speaker_idxs # list the possible speaker IDs. tts --text &quot;Text for TTS.&quot; --out_path output/path/speech.wav --model_name &quot;tts_models/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --speaker_idx &quot;&lt;speaker_id&gt;&quot; Run a released voice conversion model tts --model_name &quot;voice_conversion/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --source_wav &quot;my/source/speaker/audio.wav&quot; --target_wav &quot;my/target/speaker/audio.wav&quot; --out_path folder/to/save/output.wav Note: You can use ./TTS/bin/synthesize.py if you prefer running tts from the TTS project folder. On the Demo Server - tts-server # --> You can boot up a demo 🐸TTS server to run an inference with your models. Note that the server is not optimized for performance but gives you an easy way to interact with the models. The demo server provides pretty much the same interface as the CLI command. tts-server -h # see the help tts-server --list_models # list the available models. Run a TTS model, from the release models list, with its default vocoder. If the model you choose is a multi-speaker TTS model, you can select different speakers on the Web interface and synthesize speech. tts-server --model_name &quot;&lt;type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; Run a TTS and a vocoder model from the released model list. Note that not every vocoder is compatible with every TTS model. tts-server --model_name &quot;&lt;type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; \ --vocoder_name &quot;&lt;type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot;
