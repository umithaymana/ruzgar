Single Speaker Models # List provided models: $ tts --list_models Get model info (for both tts_models and vocoder_models): Query by type/name: The model_info_by_name uses the name as it from the –list_models. $ tts --model_info_by_name &quot;&lt;model_type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; For example: $ tts --model_info_by_name tts_models/tr/common-voice/glow-tts $ tts --model_info_by_name vocoder_models/en/ljspeech/hifigan_v2 Query by type/idx: The model_query_idx uses the corresponding idx from –list_models. $ tts --model_info_by_idx &quot;&lt;model_type&gt;/&lt;model_query_idx&gt;&quot; For example: $ tts --model_info_by_idx tts_models/3 Query info for model info by full name: $ tts --model_info_by_name &quot;&lt;model_type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; Run TTS with default models: $ tts --text &quot;Text for TTS&quot; --out_path output/path/speech.wav Run TTS and pipe out the generated TTS wav file data: $ tts --text &quot;Text for TTS&quot; --pipe_out --out_path output/path/speech.wav | aplay Run a TTS model with its default vocoder model: $ tts --text &quot;Text for TTS&quot; --model_name &quot;&lt;model_type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --out_path output/path/speech.wav For example: $ tts --text &quot;Text for TTS&quot; --model_name &quot;tts_models/en/ljspeech/glow-tts&quot; --out_path output/path/speech.wav Run with specific TTS and vocoder models from the list: $ tts --text &quot;Text for TTS&quot; --model_name &quot;&lt;model_type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --vocoder_name &quot;&lt;model_type&gt;/&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --out_path output/path/speech.wav For example: $ tts --text &quot;Text for TTS&quot; --model_name &quot;tts_models/en/ljspeech/glow-tts&quot; --vocoder_name &quot;vocoder_models/en/ljspeech/univnet&quot; --out_path output/path/speech.wav Run your own TTS model (Using Griffin-Lim Vocoder): $ tts --text &quot;Text for TTS&quot; --model_path path/to/model.pth --config_path path/to/config.json --out_path output/path/speech.wav Run your own TTS and Vocoder models: $ tts --text &quot;Text for TTS&quot; --model_path path/to/model.pth --config_path path/to/config.json --out_path output/path/speech.wav --vocoder_path path/to/vocoder.pth --vocoder_config_path path/to/vocoder_config.json Multi-speaker Models # List the available speakers and choose a &lt;speaker_id&gt; among them: $ tts --model_name &quot;&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --list_speaker_idxs Run the multi-speaker TTS model with the target speaker ID: $ tts --text &quot;Text for TTS.&quot; --out_path output/path/speech.wav --model_name &quot;&lt;language&gt;/&lt;dataset&gt;/&lt;model_name&gt;&quot; --speaker_idx &lt;speaker_id&gt; Run your own multi-speaker TTS model: $ tts --text &quot;Text for TTS&quot;
