The kernel also has a large number of documents that can be automatically generated from the source code itself or from ReStructuredText markups (ReST), like this one. This includes a full description of the in-kernel API, and rules on how to handle locking properly. All such documents can be generated as PDF or HTML by running: make pdfdocs make htmldocs respectively from the main kernel source directory. The documents that uses ReST markup will be generated at Documentation/output.
