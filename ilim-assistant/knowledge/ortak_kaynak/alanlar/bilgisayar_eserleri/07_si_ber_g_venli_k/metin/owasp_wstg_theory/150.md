Stack and Memory Protections &para; -fstack-protector-strong : Inserts stack canaries into functions with vulnerable buffers and checks them when the function returns; detects linear overflows that reach the return address, but not heap overflows, overwrites of other local variables, or arbitrary writes. -fstack-clash-protection : Protects against stack-clash attacks by probing the stack page-by-page so dynamic stack allocations cannot bypass the guard page; does not prevent stack exhaustion or buffer overflows within an allocated frame. -D_FORTIFY_SOURCE=3 (or -D_FORTIFY_SOURCE=2 ): Hardens standard C library memory and string functions by validating buffer bounds at compile time and runtime; requires optimization ( -O1 or higher) and cannot check buffers whose size the compiler cannot determine. -D_GLIBCXX_ASSERTIONS (libstdc++) or -D_LIBCPP_HARDENING_MODE=_LIBCPP_HARDENING_MODE_FAST (libc++): Enables runtime bounds checks for C++ standard library containers; adds runtime overhead. Binary Layout and Control-Flow Mitigations &para; -fPIE (compiler) and -pie (linker): Produces Position Independent Executables to enable full Address Space Layout Randomization (ASLR); applies only to executable binaries and does not prevent address leaks (information disclosure). -Wl,-z,relro -Wl,-z,now : Enables full Relocation Read-Only (RELRO) by resolving symbols at load time and marking relocation tables and the Global Offset Table read-only; increases program startup time for binaries with many dynamic symbols. -Wl,-z,noexecstack : Marks the stack as non-executable (NX), so code injected on the stack cannot run; does not prevent code-reuse attacks that repurpose existing executable memory. -fcf-protection=full (x86 only): Emits markers for Intel Control-flow Enforcement Technology (CET) shadow stacks and indirect branch tracking (IBT). In Linux user space only the shadow stack is enforced , which protects return addresses against return-oriented programming (ROP); IBT, which targets jump-oriented programming (JOP), is not. Requires CPU, kernel, and C library support. Verification &para; Use a tool such as checksec to confirm which mitigations a Linux binary has (RELRO, stack canaries, NX, PIE, _FORTIFY_SOURCE ). Microsoft Visual C++ (MSVC) &para; Microsoft Visual C++ provides compiler and linker switches for security hardening on Windows platforms. Official reference documentation includes MSVC Compiler Options Listed by Category , MSVC Linker Options , and Microsoft Security Best Practices for C++ .
