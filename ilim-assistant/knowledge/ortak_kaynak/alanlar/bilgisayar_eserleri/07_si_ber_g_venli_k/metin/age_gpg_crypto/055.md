It runs on GNU/Linux, Windows, MacOS and other operating systems. Gpg4win is a software bundle for Windows that includes GnuPG and additional software: An add-in for Outlook to handle crypto emails. An add-in for Explorer to handle files. A PDF application to create and verify signatures (experimental). Kleopatra, a graphical interface to manage keys (and offer some expert functions).
