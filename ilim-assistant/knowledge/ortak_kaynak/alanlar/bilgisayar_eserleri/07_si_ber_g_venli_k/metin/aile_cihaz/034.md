( @tr4nt0r - #184381 ) ( Kraken documentation ) Matter Matter concentration sensors now use the unit the device reports instead of a fixed one. Before, a device measuring in another unit was shown with the wrong unit, for example a TVOC sensor measuring in ppb was shown as ppm. This affects existing TVOC, carbon monoxide, nitrogen dioxide, and ozone sensors whose device reports a unit other than ppm: If the device’s unit converts to the old one (for example ppb), the sensor keeps its old unit and the value is now converted, so it changes: a TVOC sensor reporting 189 ppb now shows 0.189 ppm instead of 189 ppm, and the history shows a jump. To get the previous numbers back with the correct unit, set the sensor’s unit to the device’s unit (here ppb) in its entity settings. Otherwise, update automations, scripts, and templates that use the value. Sensors added from now on use the device’s unit directly. TVOC sensors reporting µg/m³ or mg/m³ keep their value but switch to the “Volatile organic compounds” device class, which changes their default name (the entity ID stays the same). Their old statistics can’t be converted: in Settings &gt; Tools &gt; Statistics , either update the old unit without converting or delete the old statistics. ( @valeronm - #167177 ) ( Matter documentation ) Matter climate entities now resume their last supported non-off HVAC mode when turned on from Home Assistant, including through dashboard controls and voice commands. For example, an air conditioner turned off while cooling will resume cooling when turned on again. Calling climate.turn_on on an entity that is already running now leaves its mode unchanged. Previously, climate.turn_on ignored the previous mode and selected heat/cool, then heat, then cool, depending on what the device supports. Automations or scripts that relied on that behavior should call climate.set_hvac_mode with the desired mode instead of climate.turn_on . Devices with a separate power switch, such as Matter room air conditioners, are now switched on by climate.turn_on . Previously, Home Assistant only changed the mode, so a device that was switched off stayed off. If the device kept its mode while switched off, only the power is switched on and the mode is left unchanged. If no previous supported mode is known, the earlier fallback order is still used.
