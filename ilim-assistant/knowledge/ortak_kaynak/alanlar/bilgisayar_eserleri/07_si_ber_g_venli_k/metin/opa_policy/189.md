Ordered starting at the active rule, going outward to the most distant node in its package ancestry. A chain entry is a JSON document with two members: &quot;path&quot;, an array representing the path of the node; and &quot;annotations&quot;, a JSON document containing the annotations declared for the node. The first entry in the chain always points to the active rule, even if it has no declared annotations (in which case the &quot;annotations&quot; member is not present).
