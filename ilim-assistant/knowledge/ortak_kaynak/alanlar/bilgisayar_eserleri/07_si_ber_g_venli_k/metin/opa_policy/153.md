Write the OPA policy to check the plan ​ The policy computes a score for a Terraform that combines The number of deletions of each resource type The number of creations of each resource type The number of modifications of each resource type The policy authorizes the plan when the score for the plan is below a threshold and there are no changes made to any IAM resources.
