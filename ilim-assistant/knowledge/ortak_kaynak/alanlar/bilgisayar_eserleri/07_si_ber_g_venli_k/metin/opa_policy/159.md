The &#x27;test&#x27; command takes a file or directory path as input and executes all test cases discovered in matching files. Test cases are rules whose names have the prefix &quot;test_&quot;. If the &#x27;--bundle&#x27; option is specified the paths will be treated as policy bundles and loaded following standard bundle conventions. The path can be a compressed archive file or a directory which will be treated as a bundle. Without the &#x27;--bundle&#x27; flag OPA will recursively load ALL *.rego, *.json, and *.yaml files for evaluating the test cases. Test cases under development may be prefixed &quot;todo_&quot; in order to skip their execution, while still getting marked as skipped in the test results. OPA Management APIs and Architecture | Open Policy Agent Skip to main content The 2026 OPA Community Survey is open - We need your input OPA Management APIs and Architecture OPA exposes a set of APIs that enable unified, logically centralized policy management. Read this page if you are interested in how to build a control plane around OPA that enables policy distribution and collection of important telemetry data like decision logs. OPA enables low-latency, highly-available policy enforcement by providing a lightweight engine for distributed architectures. By default, all of the policy and data that OPA uses to make decisions is kept in-memory: OPA is designed to enable distributed policy enforcement. You can run OPA next to each and every service that needs to offload policy decision-making. By co-locating OPA with the services that require decision-making, you ensure that policy decisions are rendered as fast as possible and in a highly-available manner. To control and observe a set of OPA instances, each OPA can be configured to connect to management APIs that enable: Policy distribution ( Bundles ) Decision telemetry ( Decision Logs ) Agent telemetry ( Status ) Dynamic agent configuration ( Discovery ) By configuring and implementing these management APIs you can unify control and visibility over OPA instances in your environments.
