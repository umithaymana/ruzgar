OWASP Threat Dragon | OWASP Foundation OWASP Foundation Sign in Donate OWASP Threat Dragon OWASP Threat Dragon is a free, open-source, cross-platform threat modeling application used to draw threat modeling diagrams and to list threats for elements in the diagram. Threat Dragon is designed to be accessible, with an emphasis on flexibility and simplicity. It supports multiple threat modeling frameworks including STRIDE, CIA, LINDDUN, and more. You can run Threat Dragon as a standalone desktop application or a fully featured, configurable, self-hosted web application. I get failures when installing from source code The Threat Dragon source code can be downloaded from github, and installed using npm clean-install . If you are running off main branch then it really should install cleanly, so if you get errors along the lines of Running postinstall script failed then some package downloads my be blocked by your network. Try using a VPN, or find out if your router / network can allow the traffic. If all else fails, you can open an issue and we will do our best to support you. Why do I get &#x27;OWASP-Threat-Dragon-Setup isn&#x27;t commonly downloaded&#x27; warnings after downloading on Windows? This is due to the way we sign the Windows images and how Windows SmartScreen has evolved. The signature is verified by the community rather than going through a process with Microsoft. After enough installs, Windows will fully trust it ... until then we have to put up with this irritation on first install. Click on the 'show more' and agree to keep the file. You will have to agree again 'Keep anyway' before Windows accepts that you really want to keep the file. You can then double click on the download to install Threat Dragon. Why do the earlier releases come from Mike Goodwin&#x27;s repo, not the OWASP repo? For more than 4 years Mike hosted Threat Dragon on his github, and in mid-2020 he felt that the time was right for it to migrate to the OWASP organisation github space. This was done through June and July 2020 and with version 1.3 (released September 2020) the migration was completed. What happened to the old project page? In September 2026, OWASP launched a new website that no longer uses the www-* github repositories for projects and chapters. These repositories are slated to be deleted by the end of 2026. To preserve the history of our contributors, a fork was made to serve as a public archive with a note explaining the transition at the top of the README. We sincerely appreciate all of the contributions to our project page over the years.
