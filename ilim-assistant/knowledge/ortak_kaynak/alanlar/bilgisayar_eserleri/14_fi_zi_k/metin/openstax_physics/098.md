Defining a Coordinate System It is important to set up a coordinate system when analyzing projectile motion. One part of defining the coordinate system is to define an origin for the x x and y y positions. Often, it is convenient to choose the initial position of the object as the origin such that x 0 = 0 x 0 = 0 and y 0 = 0 y 0 = 0 . It is also important to define the positive and negative directions in the x x and y y directions. Typically, we define the positive vertical direction as upwards, and the positive horizontal direction is usually the direction of the object’s motion. When this is the case, the vertical acceleration, a y = – g a y = – g , takes a negative value (since it is directed downwards towards the Earth). However, it is occasionally useful to define the coordinates differently.
