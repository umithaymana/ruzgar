Try Tuple Types A tuple type is another sort of Array type that knows exactly how many elements it contains, and exactly which types it contains at specific positions. ts type StringNumberPair = [ string , number ]; Try Here, StringNumberPair is a tuple type of string and number . Like ReadonlyArray , it has no representation at runtime, but is significant to TypeScript. To the type system, StringNumberPair describes arrays whose 0 index contains a string and whose 1 index contains a number . ts function doSomething ( pair : [ string , number ]) { const a = pair [ 0 ]; const a: string const b = pair [ 1 ]; const b: number // ... } &nbsp; doSomething ([ "hello" , 42 ]); Try If we try to index past the number of elements, we’ll get an error. ts function doSomething ( pair : [ string , number ]) { // ... &nbsp; const c = pair [ 2 ]; Tuple type '[string, number]' of length '2' has no element at index '2'. 2493 Tuple type '[string, number]' of length '2' has no element at index '2'. } Try We can also destructure tuples using JavaScript’s array destructuring. ts function doSomething ( stringHash : [ string , number ]) { const [ inputString , hash ] = stringHash ; &nbsp; console . log ( inputString ); const inputString: string &nbsp; console . log ( hash ); const hash: number } Try Tuple types are useful in heavily convention-based APIs, where each element’s meaning is “obvious”.
