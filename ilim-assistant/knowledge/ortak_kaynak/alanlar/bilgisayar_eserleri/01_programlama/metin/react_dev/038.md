Setting state requests a new re-render, but does not change it in the already running code. So score continues to be 0 right after you call setScore(score + 1) . console . log ( score ) ; // 0 setScore ( score + 1 ) ; // setScore(0 + 1); console . log ( score ) ; // 0 setScore ( score + 1 ) ; // setScore(0 + 1); console . log ( score ) ; // 0 setScore ( score + 1 ) ; // setScore(0 + 1); console . log ( score ) ; // 0 You can fix this by passing an updater function when setting state. But you shouldn’t change objects and arrays that you hold in the React state directly. Instead, when you want to update an object and array, you need to create a new one (or make a copy of an existing one), and then update the state to use that copy. Usually, you will use the ... spread syntax to copy objects and arrays that you want to change.
