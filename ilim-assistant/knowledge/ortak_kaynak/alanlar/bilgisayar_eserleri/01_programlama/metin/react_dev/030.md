JavaScript in JSX with Curly Braces – React Learn React Describing the UI Copy page Copy JavaScript in JSX with Curly Braces JSX lets you write HTML-like markup inside a JavaScript file, keeping rendering logic and content in the same place. Sometimes you will want to add a little JavaScript logic or reference a dynamic property inside that markup. In this situation, you can use curly braces in your JSX to open a window to JavaScript. That’s because curly braces let you work with JavaScript right there in your markup! Using curly braces: A window into the JavaScript world JSX is a special way of writing JavaScript. That means it’s possible to use JavaScript inside it—with curly braces { } . The example below first declares a name for the scientist, name , then embeds it with curly braces inside the &lt;h1&gt; : App.js App.js Reload Clear Fork export default function TodoList ( ) { const name = &#x27;Gregorio Y. Zara&#x27; ; return ( &lt; h1 &gt; { name } &#x27;s To Do List &lt;/ h1 &gt; ) ; } Try changing the name ’s value from &#x27;Gregorio Y. Zara&#x27; to &#x27;Hedy Lamarr&#x27; . See how the list title changes? As attributes immediately following the = sign: src={avatar} will read the avatar variable, but src=&quot;{avatar}&quot; will pass the string &quot;{avatar}&quot; . Using “double curlies”: CSS and other objects in JSX In addition to strings, numbers, and other JavaScript expressions, you can even pass objects in JSX. Objects are also denoted with curly braces, like { name: &quot;Hedy Lamarr&quot;, inventions: 5 } . Therefore, to pass a JS object in JSX, you must wrap the object in another pair of curly braces: person={{ name: &quot;Hedy Lamarr&quot;, inventions: 5 }} . You may see this with inline CSS styles in JSX. React does not require you to use inline styles (CSS classes work great for most cases). But when you need an inline style, you pass an object to the style attribute: App.js App.js Reload Clear Fork export default function TodoList ( ) { return ( &lt; ul style = { { backgroundColor : &#x27;black&#x27; , color : &#x27;pink&#x27; } } &gt; &lt; li &gt; Improve the videophone &lt;/ li &gt; &lt; li &gt; Prepare aeronautics lectures &lt;/ li &gt; &lt; li &gt; Work on the alcohol-fuelled engine &lt;/ li &gt; &lt;/ ul &gt; ) ; } Try changing the values of backgroundColor and color . You can really see the JavaScript object inside the curly braces when you write it like this: &lt; ul style = { { backgroundColor : &#x27;black&#x27; , color : &#x27;pink&#x27; } } &gt; The next time you see {{ and }} in JSX, know that it’s nothing more than an object inside the JSX curlies! Pitfall Inline style properties are written in camelCase. For example, HTML &lt;ul style=&quot;background-color: black&quot;&gt; would be written as &lt;ul style={{ backgroundColor: &#x27;black&#x27; }}&gt; in your component.
