Conditionally including JSX In the previous example, you controlled which (if any!) JSX tree would be returned by the component. Conditional (ternary) operator ( ? : ) JavaScript has a compact syntax for writing a conditional expression — the conditional operator or “ternary operator”. Instead of this: if ( isPacked ) { return &lt; li className = &quot;item&quot; &gt; { name } ✅ &lt;/ li &gt; ; } return &lt; li className = &quot;item&quot; &gt; { name } &lt;/ li &gt; ; You can write this: return ( &lt; li className = &quot;item&quot; &gt; { isPacked ? name + &#x27; ✅&#x27; : name } &lt;/ li &gt; ) ; You can read it as “if isPacked is true, then ( ? ) render name + &#x27; ✅&#x27; , otherwise ( : ) render name ” .
