The Never Type That Never Returns Rust has a special type named ! that’s known in type theory lingo as the empty type because it has no values. We prefer to call it the never type because it stands in the place of the return type when a function will never return. Here is an example: fn bar() -&gt; ! { // --snip-- panic!(); } This code is read as “the function bar returns never.” Functions that return never are called diverging functions . We can’t create values of the type ! , so bar can never possibly return. But what use is a type you can never create values for?
