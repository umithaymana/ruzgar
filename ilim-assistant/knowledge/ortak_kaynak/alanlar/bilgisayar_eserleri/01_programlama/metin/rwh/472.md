Behavior Change ​ A bunch of Playwright APIs already support the waitUntil: 'domcontentloaded' option. For example: await page . goto ( 'https://playwright.dev' , { waitUntil : 'domcontentloaded' , } ) ; Prior to 1.26, this would wait for all iframes to fire the DOMContentLoaded event. To align with web specification, the 'domcontentloaded' value only waits for the target frame to fire the 'DOMContentLoaded' event. Use waitUntil: 'load' to wait for all iframes.
