The note() function lets you do this: &gt;&gt;&gt; from hypothesis import given , note , strategies as st &gt;&gt;&gt; @given ( st . lists ( st . integers ()), st . randoms ()) ... def test_shuffle_is_noop ( ls , r ): ... ls2 = list ( ls ) ... r . shuffle ( ls2 ) ... note ( f "Shuffle: { ls2 !r} " ) ... assert ls == ls2 ... &gt;&gt;&gt; try : ... test_shuffle_is_noop () ... except AssertionError : ... print ( "ls != ls2" ) ... Failing test case: test_shuffle_is_noop(ls=[0, 1], r=RandomWithSeed(1)) Shuffle: [1, 0] ls != ls2 note() is like a print statement that gets attached to the minimal failing test case reported by Hypothesis. It’s also reported by observability , and shown for all test cases (if settings.verbosity is set to Verbosity.verbose or higher). Note event() is a similar function which tells Hypothesis to count the number of test cases which reported each distinct value you pass, for inclusion in test statistics and observability reports .
