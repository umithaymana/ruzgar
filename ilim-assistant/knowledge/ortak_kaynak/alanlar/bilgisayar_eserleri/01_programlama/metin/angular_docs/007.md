List wrapping By default, the cdkDropList sorts the draggable elements by moving them around using a CSS transform. This allows for the sorting to be animated which provides a better user experience. However this also comes with the drawback that the drop list works only in one direction: vertically or horizontally. If you have a sortable list that needs to wrap onto new lines, you can set cdkDropListOrientation attribute to mixed . This causes the list to use a different strategy of sorting the elements which involves moving them in the DOM.
