Frame locators capture the logic sufficient to retrieve the iframe and then locate elements in that iframe. Frame locators are strict by default, will wait for iframe to appear and can be used in Web-First assertions. Frame locators can be created with either page.frameLocator() or locator.frameLocator() method. const locator = page . frameLocator ( '#my-iframe' ) . locator ( 'text=Submit' ) ; await locator . click ( ) ; Read more at our documentation .
