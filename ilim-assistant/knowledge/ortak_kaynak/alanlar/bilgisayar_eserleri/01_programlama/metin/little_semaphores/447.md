Release notes | Playwright Skip to main content On this page Release notes Version 1.65 ​ 🥟 Run tests with Bun ​ The test runner now runs under Bun . Bun transpiles your TypeScript test files itself, so Playwright does not use Babel or its compilation cache. Pass the --bun flag, because without it bunx playwright test runs on Node.js: bunx --bun playwright test Our CI runs the test runner tests under Bun 1.4.3 on Linux. Some features work differently under Bun: There is no watch mode. UI mode does not run tests again when files change, and --only-changed does not follow imports. Bun loads modules itself, so --tsconfig and the JSX options in tsconfig.json have no effect, and custom ESM loaders are not supported. Stack traces do not include async frames, and API names do not include the class name: click instead of locator.click . This changes some step locations, step titles and error messages. Console output of a test does not get into the trace and UI mode. 🚨 Reports with only failures ​ New failures reporter prints failures and successful retries as they occur, followed by a summary, without progress output. New onlyFailures option of the HTML, JSON and JUnit reporters keeps only tests with unexpected outcomes, flaky tests and interrupted tests: playwright.config.ts import { defineConfig } from '@playwright/test' ; export default defineConfig ( { reporter : [ [ 'failures' ] , [ 'html' , { onlyFailures : true } ] , ] , } ) ; 🎯 Test runner ​ New built-in -exclusive- test lock runs a test only when no other tests are running. All other tests continue to run in parallel with each other: test ( 'restart the server' , { lock : '-exclusive-' } , async ( ) => { // No other test runs while this one is running. } ) ; test.skip() , test.fixme() , test.fail() and test.slow() now accept only a description. It is recorded in the test annotation: test ( 'upload a file' , async ( { page } ) => { test . skip ( 'Not implemented yet' ) ; } ) ; New PLAYWRIGHT_TRANSFORM_CACHE_DIR environment variable sets the directory for transpiled test files, for example on a Linux machine shared with other users. New APIs ​ New options timeout and signal in cdpSession.send() . New testRun.mode() returns the execution mode of a suite during reporter.preprocess() . Breaking Changes ⚠️ ​ TypeScript class fields now follow useDefineForClassFields from your tsconfig.json , the same as tsc . It is enabled for ES2022 and later targets, and when target is not specified. A field initializer that reads a constructor parameter property now fails, because the initializer runs first: class LoginPage { // TypeError: Cannot read properties of undefined (reading 'getByRole') readonly submit = this . page . getByRole ( 'button' , { name : 'Submit' } ) ; constructor ( private readonly page : Page ) { } } Move the initialization to the constructor, or set "useDefineForClassFields": false in your tsconfig.json . Actions such as locator.click() , locator.check() , locator.tap() , locator.fill() , locator.clear() and locator.selectOption() now wait for the element to be not inert . An action on an element with the inert attribute, or inside such an element, now times out if the element stays inert. A sharded run now fails with "No tests found" when no tests match across all shards. Pass --pass-with-no-tests to allow this. An empty shard still passes when other shards have tests. Cookie matching now follows RFC 6265. With a URL, browserContext.cookies() and apiRequestContext.cookies() no longer return host-only cookies for subdomains or Path=/api cookies for /apiv2 , and a Path=/foo/ cookie does not match /foo . APIRequestContext sends a cookie without a name as Cookie: x instead of Cookie: =x , and stores Set-Cookie: token as a cookie without a name. Proxy credentials are no longer sent to websites. The credentials in the proxy option now answer only proxy challenges. To authenticate on a website, use httpCredentials . Text that the browser does not render, such as text that is not assigned to a slot or text directly inside a closed &lt;details> , is no longer part of accessible names and aria snapshots. This can change the results of page.getByRole() with a name, locator.ariaSnapshot() and expect(locator).toMatchAriaSnapshot() . String and URLSearchParams values of the params option in APIRequestContext requests are now appended to the query that the URL already has, instead of replacing it. .css , .less and .scss imports in test files now load as empty modules instead of being removed, so the imported file must exist. The blob reporter again deletes the content of its output directory before it writes the report. Playwright 1.64 kept reports with other names. Test locations of imported calls such as test( in CommonJS output now point to the start of the callee, for example a.spec.ts:3:7 instead of a.spec.ts:3:11 . This is the same as in ESM.
