# class: Frame * since: v1.8 At every point of time, page exposes its current frame tree via the [`method: Page.mainFrame`] and [`method: Frame.childFrames`] methods. [Frame] object's lifecycle is controlled by three events, dispatched on the page object: * [`event: Page.frameAttached`] - fired when the frame gets attached to the page. A Frame can be attached to the page only once. * [`event: Page.frameNavigated`] - fired when the frame commits navigation to a different URL. * [`event: Page.frameDetached`] - fired when the frame gets detached from the page. A Frame can be detached from the page only once. An example of dumping frame tree: ```js const { firefox } = require('playwright'); // Or 'chromium' or 'webkit'.
