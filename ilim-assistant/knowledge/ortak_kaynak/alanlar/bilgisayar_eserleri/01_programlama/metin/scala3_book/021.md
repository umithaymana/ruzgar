Bad val v42 = 42 3 match { case v42 =&gt; println("42") case _ =&gt; println("Not 42") } v42 is interpreted as a name matching any Int value, and “42” is printed. Good val v42 = 42 3 match { case `v42` =&gt; println("42") case _ =&gt; println("Not 42") } `v42` with backticks is interpreted as the existing val v42 , and “Not 42” is printed. Good val UppercaseVal = 42 3 match { case UppercaseVal =&gt; println("42") case _ =&gt; println("Not 42") } UppercaseVal is treated as an existing val, rather than a new pattern variable, because it starts with an uppercase letter. 1 case None =&gt; 0 } 0 if empty, otherwise 1 . option.orElse(Some(y)) same as option match { case Some(x) =&gt; Some(x) case None =&gt; Some(y) } Evaluate and return alternate optional value if empty. option.getOrElse(y) same as option match { case Some(x) =&gt;
