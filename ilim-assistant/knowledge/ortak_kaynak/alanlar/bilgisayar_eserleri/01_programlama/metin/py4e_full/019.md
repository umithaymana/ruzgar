The values stored in a tuple can be any type, and they are indexed by integers. The important difference is that tuples are immutable . Tuples are also comparable and hashable so we can sort lists of them and use tuples as key values in Python dictionaries. Syntactically, a tuple is a comma-separated list of values: &gt;&gt;&gt; t = &#39;a&#39;, &#39;b&#39;, &#39;c&#39;, &#39;d&#39;, &#39;e&#39; Although it is not necessary, it is common to enclose tuples in parentheses to help us quickly identify tuples when we look at Python code: &gt;&gt;&gt; t = (&#39;a&#39;, &#39;b&#39;, &#39;c&#39;, &#39;d&#39;, &#39;e&#39;) To create a tuple with a single element, you have to include the final comma: &gt;&gt;&gt; t1 = (&#39;a&#39;,) &gt;&gt;&gt; type(t1) &lt;type &#39;tuple&#39;&gt; Without the comma Python treats ('a') as an expression with a string in parentheses that evaluates to a string: &gt;&gt;&gt; t2 = (&#39;a&#39;) &gt;&gt;&gt; type(t2) &lt;type &#39;str&#39;&gt; Another way to construct a tuple is the built-in function tuple . With no argument, it creates an empty tuple: &gt;&gt;&gt; t = tuple() &gt;&gt;&gt; print(t) () If the argument is a sequence (string, list, or tuple), the result of the call to tuple is a tuple with the elements of the sequence: &gt;&gt;&gt; t = tuple(&#39;lupins&#39;) &gt;&gt;&gt; print(t) (&#39;l&#39;, &#39;u&#39;, &#39;p&#39;, &#39;i&#39;, &#39;n&#39;, &#39;s&#39;) Because tuple is the name of a constructor, you should avoid using it as a variable name. Most list operators also work on tuples. The bracket operator indexes an element: &gt;&gt;&gt; t = (&#39;a&#39;, &#39;b&#39;, &#39;c&#39;, &#39;d&#39;, &#39;e&#39;) &gt;&gt;&gt; print(t[0]) &#39;a&#39; And the slice operator selects a range of elements. &gt;&gt;&gt; print(t[1:3]) (&#39;b&#39;, &#39;c&#39;) But if you try to modify one of the elements of the tuple, you get an error: &gt;&gt;&gt; t[0] = &#39;A&#39; TypeError: object doesn&#39;t support item assignment You can’t modify the elements of a tuple, but you can replace one tuple with another: &gt;&gt;&gt; t = (&#39;A&#39;,) + t[1:] &gt;&gt;&gt; print(t) (&#39;A&#39;, &#39;b&#39;, &#39;c&#39;, &#39;d&#39;, &#39;e&#39;) Comparing tuples The comparison operators work with tuples and other sequences. Python starts by comparing the first element from each sequence. If they are equal, it goes on to the next element, and so on, until it finds elements that differ. Subsequent elements are not considered (even if they are really big). &gt;&gt;&gt; (0, 1, 2) &lt; (0, 3, 4) True &gt;&gt;&gt; (0, 1, 2000000) &lt; (0, 3, 4) True The sort function works the same way. It sorts primarily by first element, but in the case of a tie, it sorts by second element, and so on. This feature lends itself to a pattern called DSU for Decorate a sequence by building a list of tuples with one or more sort keys preceding the elements from the sequence, Sort the list of tuples using the Python built-in sort , and Undecorate by extracting the sorted elements of the sequence. The keyword argument reverse=True tells sort to go in decreasing order. The second loop traverses the list of tuples and builds a list of words in descending order of length. The four-character words are sorted in reverse alphabetical order, so “what” appears before “soft” in the following list. Tuple assignment One of the unique syntactic features of the Python language is the ability to have a tuple on the left side and a sequence on the right side of an assignment statement. This allows you to assign more than one variable at a time to the given sequence. In this example we have a two-element tuple and assign the first and second elements of the tuple to the variables x and y in a single statement. &gt;&gt;&gt; m = ( &#39;have&#39;, &#39;fun&#39; ) &gt;&gt;&gt; x, y = m &gt;&gt;&gt; x &#39;have&#39; &gt;&gt;&gt; y &#39;fun&#39; &gt;&gt;&gt; This is more general than tuple-to-tuple assignment. Both tuples and lists are sequences, so this syntax works with a two element list as well. &gt;&gt;&gt; m = [ &#39;have&#39;, &#39;fun&#39; ] &gt;&gt;&gt; x, y = m &gt;&gt;&gt; x &#39;have&#39; &gt;&gt;&gt; y &#39;fun&#39; &gt;&gt;&gt; It is not magic, Python roughly translates the tuple assignment syntax to be the following: 2 &gt;&gt;&gt; m = ( &#39;have&#39;, &#39;fun&#39; ) &gt;&gt;&gt; x = m[0] &gt;&gt;&gt; y = m[1] &gt;&gt;&gt; x &#39;have&#39; &gt;&gt;&gt; y &#39;fun&#39; &gt;&gt;&gt; Stylistically when we use a tuple on the left side of the assignment statement, we omit the parentheses, but the following is an equally valid syntax: &gt;&gt;&gt; m = ( &#39;have&#39;, &#39;fun&#39; ) &gt;&gt;&gt; (x, y) = m &gt;&gt;&gt; x &#39;have&#39; &gt;&gt;&gt; y &#39;fun&#39; &gt;&gt;&gt; A particularly clever application of tuple assignment allows us to swap the values of two variables in a single statement: &gt;&gt;&gt; a, b = b, a Both sides of this statement are tuples, but the left side is a tuple of variables; the right side is a tuple of expressions. Each value on the right side is assigned to its respective variable on the left side. All the expressions on the right side are evaluated before any of the assignments. The number of variables on the left and the number of values on the right must be the same: &gt;&gt;&gt; a, b = 1, 2, 3 ValueError: too many values to unpack More generally, the right side can be any kind of sequence (string, list, or tuple). However, since the list of tuples is a list, and tuples are comparable, we can now sort the list of tuples. Converting a dictionary to a list of tuples is a way for us to output the contents of a dictionary sorted by key: &gt;&gt;&gt; d = {&#39;b&#39;:1, &#39;a&#39;:10, &#39;c&#39;:22} &gt;&gt;&gt; t = list(d.items()) &gt;&gt;&gt; t [(&#39;b&#39;, 1), (&#39;a&#39;, 10), (&#39;c&#39;, 22)] &gt;&gt;&gt; t.sort() &gt;&gt;&gt; t [(&#39;a&#39;, 10), (&#39;b&#39;, 1), (&#39;c&#39;, 22)] The list of tuples is now sorted in ascending alphabetical order by the key. Multiple assignment with dictionaries Combining items , tuple assignment, and for , you can see a nice code pattern for traversing the keys and values of a dictionary in a single loop: d = {&#39;a&#39;:10, &#39;b&#39;:1, &#39;c&#39;:22} for key, val in d.items(): print(val, key) This loop has two iteration variables because items returns a list of tuples and key, val is a tuple assignment that successively iterates through each of the key-value pairs in the dictionary. For each iteration through the loop, both key and val are advanced to the next key-value pair in the dictionary (still in hash order). The output of this loop is: 10 a 1 b 22 c Again, it is in hash key order (i.e., no particular order). If we combine these two techniques, we can print out the contents of a dictionary sorted by the value stored in each key-value pair. To do this, we first make a list of tuples where each tuple is (value, key) . The items method would give us a list of (key, value) tuples, but this time we want to sort by value, not key. Once we have constructed the list with the value-key tuples, it is a simple matter to sort the list in reverse order and print it out. &gt;&gt;&gt; d = {&#39;a&#39;:10, &#39;b&#39;:1, &#39;c&#39;:22} &gt;&gt;&gt; l = list() &gt;&gt;&gt; for key, val in d.items() : ... l.append( (val, key) ) ... &gt;&gt;&gt; l [(10, &#39;a&#39;), (1, &#39;b&#39;), (22, &#39;c&#39;)] &gt;&gt;&gt; l.sort(reverse=True) &gt;&gt;&gt; l [(22, &#39;c&#39;), (10, &#39;a&#39;), (1, &#39;b&#39;)] &gt;&gt;&gt; By carefully constructing the list of tuples to have the value as the first element of each tuple, we can sort the list of tuples and print our dictionary contents sorted by value.
