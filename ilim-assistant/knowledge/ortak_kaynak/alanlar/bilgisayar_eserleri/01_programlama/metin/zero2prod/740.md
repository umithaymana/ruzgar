Note that rather than having self , &amp;self , or &amp;mut self as the first parameter of the method, we have self: Box&lt;Self&gt; . This syntax means the method is only valid when called on a Box holding the type. This syntax takes ownership of Box&lt;Self&gt; , invalidating the old state so that the state value of the Post can transform into a new state. To consume the old state, the request_review method needs to take ownership of the state value.
