The most interesting aspect of the server is the part that handles long

There will be multiple places in which we have to send an array of talks

SkillShareServer.prototype.talkResponse = function() {

body: JSON.stringify(talks),

};

index.html when a request is made directly to a path that corresponds to
a directory. The file server module we use, serve-static, supports this
convention. When a request is made to the path/, the server looks for the
file ./public/index.html (./public being the root we gave it) and returns
that file if found.
