PY4E - Python for Everybody Skip to main content PY4E Lessons Book Courses Login Python for Everybody The goal of this book is to provide an Informatics-oriented introduction to programming. The primary difference between a computer science approach and the Informatics approach taken in this book is a greater focus on using Python to solve data analysis problems common in the world of Informatics. The sample code and data files for the book are here: Code Samples .
