In the second, the scope of the empty array temporary does undergo lifetime extension, and so it is rejected due to being a mutable borrow of a lifetime-extended temporary (and therefore borrowing a non-transient place expression). The effect is surprising because temporary lifetime extension, in this case, causes less code to compile than would without it. See issue #143129 for more details.
