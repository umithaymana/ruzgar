Diverging functions Diverging functions never return. They are marked using ! , which is an empty type. #![allow(unused)] fn main() { fn foo() -&gt; ! { panic!("This call never returns."); } } As opposed to all the other types, this one cannot be instantiated, because the set of all possible values this type can have is empty. Note that, it is different from the () type, which has exactly one possible value.
