Writing Excel Documents OpenPyXL also provides ways of writing data, meaning that your programs can create and edit spreadsheet files. With Python, it’s simple to create spreadsheets with thousands of rows of data. Creating and Saving Excel Documents Call the openpyxl.Workbook() function to create a new, blank Workbook object. Enter the following into the interactive shell: &gt;&gt;&gt; import openpyxl &gt;&gt;&gt; wb = openpyxl.Workbook() # Create a blank workbook. &gt;&gt;&gt; wb.sheetnames # It starts with one sheet. ['Sheet'] &gt;&gt;&gt; sheet = wb.active &gt;&gt;&gt; sheet.title 'Sheet' &gt;&gt;&gt; sheet.title = 'Spam Bacon Eggs Sheet' # Change title. &gt;&gt;&gt; wb.sheetnames ['Spam Bacon Eggs Sheet'] The workbook will start off with a single sheet named Sheet . You can change the name of the sheet by storing a new string in its title attribute. Any time you modify the Workbook object or its sheets and cells, the spreadsheet file will not be saved until you call the save() workbook method. Enter the following into the interactive shell (with example.xlsx in the current working directory): &gt;&gt;&gt; import openpyxl &gt;&gt;&gt; wb = openpyxl.load_workbook('example.xlsx') &gt;&gt;&gt; sheet = wb.active &gt;&gt;&gt; sheet.title = 'Spam Spam Spam' &gt;&gt;&gt; wb.save('example_copy.xlsx') # Save the workbook. Here, we change the name of our sheet. To save our changes, we pass a filename as a string to the save() method. Passing a different filename than the original, such as 'example_copy.xlsx' , saves the changes to a copy of the spreadsheet. Whenever you edit a spreadsheet you’ve loaded from a file, you should always save the new, edited spreadsheet to a different filename than the original. That way, you’ll still have the original spreadsheet file to work with in case a bug in your code caused the new, saved file to have incorrect or corrupt data. Creating and Removing Sheets Sheets can be added to and removed from a workbook with the create_sheet() method and del operator. Enter the following into the interactive shell: &gt;&gt;&gt; import openpyxl &gt;&gt;&gt; wb = openpyxl.Workbook() &gt;&gt;&gt; wb.sheetnames ['Sheet'] &gt;&gt;&gt; wb.create_sheet() # Add a new sheet. &lt;Worksheet "Sheet1"&gt; &gt;&gt;&gt; wb.sheetnames ['Sheet', 'Sheet1'] &gt;&gt;&gt; # Create a new sheet at index 0. &gt;&gt;&gt; wb.create_sheet(index=0, title='First Sheet') &lt;Worksheet "First Sheet"&gt; &gt;&gt;&gt; wb.sheetnames ['First Sheet', 'Sheet', 'Sheet1'] &gt;&gt;&gt; wb.create_sheet(index=2, title='Middle Sheet') &lt;Worksheet "Middle Sheet"&gt; &gt;&gt;&gt; wb.sheetnames ['First Sheet', 'Sheet', 'Middle Sheet', 'Sheet1'] The create_sheet() method returns a new Worksheet object named Sheet X , which by default is set to be the last sheet in the workbook. Optionally, the index and name of the new sheet can be specified with the index and title keyword arguments. Continue the previous example by entering the following: &gt;&gt;&gt; wb.sheetnames ['First Sheet', 'Sheet', 'Middle Sheet', 'Sheet1'] &gt;&gt;&gt; del wb['Middle Sheet'] &gt;&gt;&gt; del wb['Sheet1'] &gt;&gt;&gt; wb.sheetnames ['First Sheet', 'Sheet'] You can use the del operator to delete a sheet from a workbook, just like you can use it to delete a key-value pair from a dictionary. Remember to call the save() method to save the changes after adding sheets to or removing sheets from the workbook. Writing Values to Cells Writing values to cells is much like writing values to keys in a dictionary. Enter this into the interactive shell: &gt;&gt;&gt; import openpyxl &gt;&gt;&gt; wb = openpyxl.Workbook() &gt;&gt;&gt; sheet = wb['Sheet'] &gt;&gt;&gt; sheet['A1'] = 'Hello, world!' # Edit the cell's value. &gt;&gt;&gt; sheet['A1'].value 'Hello, world!' If you have the cell’s coordinate as a string, you can use it just like a dictionary key on the Worksheet object to specify which cell to write to.
