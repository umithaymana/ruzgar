Downloading and Uploading Spreadsheets You can download a Google Sheets spreadsheet in a number of formats: Excel, OpenOffice, CSV, TSV, and PDF. You can also download it as a ZIP file containing HTML files of the spreadsheet’s data. EZSheets contains functions for each of these options: &gt;&gt;&gt; import ezsheets &gt;&gt;&gt; ss = ezsheets.Spreadsheet(' 1J-Jx6Ne2K_vqI9J2SO-TAXOFbxx_9tUjwnkPC22LjeU ') &gt;&gt;&gt; ss.title 'Class Data' &gt;&gt;&gt; ss.downloadAsExcel() # Downloads the spreadsheet as an Excel file. 'Class_Data.xlsx' &gt;&gt;&gt; ss.downloadAsODS() # Downloads the spreadsheet as an OpenOffice file. 'Class_Data.ods' &gt;&gt;&gt; ss.downloadAsCSV() # Only downloads the first sheet as a CSV file. 'Class_Data.csv' &gt;&gt;&gt; ss.downloadAsTSV() # Only downloads the first sheet as a TSV file. 'Class_Data.tsv' &gt;&gt;&gt; ss.downloadAsPDF() # Downloads the spreadsheet as a PDF. 'Class_Data.pdf' &gt;&gt;&gt; ss.downloadAsHTML() # Downloads the spreadsheet as a ZIP of HTML files. 'Class_Data.zip' Note that files in the CSV and TSV formats can contain only one sheet; therefore, if you download a Google Sheets spreadsheet in this format, you will get the first sheet only. To download other sheets, you’ll need to change the Sheet object’s index attribute to 0 . See “Creating and Deleting Sheets” on page 341 for information on how to do this. The download functions all return a string of the downloaded file’s filename. You can also specify your own filename for the spreadsheet by passing the new filename to the download function: &gt;&gt;&gt; ss.downloadAsExcel(' a_different_filename .xlsx') ' a_different_filename .xlsx' The function should return the updated filename. Deleting Spreadsheets To delete a spreadsheet, call the delete() method: &gt;&gt;&gt; import ezsheets &gt;&gt;&gt; ss = ezsheets.createSpreadsheet('Delete me') # Create the spreadsheet. &gt;&gt;&gt; ezsheets.listSpreadsheets() # Confirm that we've created a spreadsheet. {'1aCw2NNJSZblDbhygVv77kPsL3djmgV5zJZllSOZ_mRk': 'Delete me'} &gt;&gt;&gt; ss.delete() # Delete the spreadsheet. &gt;&gt;&gt; ezsheets.listSpreadsheets() {} The delete() method will move your spreadsheet to the Trash folder on your Google Drive. You can view the contents of your Trash folder at https://drive.google.com/drive/trash . To permanently delete your spreadsheet, pass True for the permanent keyword argument: &gt;&gt;&gt; ss.delete(permanent=True) In general, permanently deleting your spreadsheets is not a good idea, because it would be impossible to recover a spreadsheet that a bug in your script accidentally deleted. Even free Google Drive accounts have gigabytes of storage available, so you most likely don’t need to worry about freeing up space. Sheet Objects A Spreadsheet object will have one or more Sheet objects. The Sheet objects represent the rows and columns of data in each sheet. You can access these sheets using the square brackets operator and an integer index. The Spreadsheet object’s sheets attribute holds a tuple of Sheet objects in the order in which they appear in the spreadsheet. To access the Sheet objects in a spreadsheet, enter the following into the interactive shell: &gt;&gt;&gt; import ezsheets &gt;&gt;&gt; ss = ezsheets.Spreadsheet(' 1J-Jx6Ne2K_vqI9J2SO-TAXOFbxx_9tUjwnkPC22LjeU ') &gt;&gt;&gt; ss.sheets&nbsp;&nbsp;&nbsp;&nbsp; # The Sheet objects in this Spreadsheet, in order. (&lt;Sheet sheetId=1669384683, title='Classes', rowCount=1000, columnCount=26&gt;, &lt;Sheet sheetId=151537240, title='Resources', rowCount=1000, columnCount=26&gt;) &gt;&gt;&gt; ss.sheets[0] # Gets the first Sheet object in this Spreadsheet. &lt;Sheet sheetId=1669384683, title='Classes', rowCount=1000, columnCount=26&gt; &gt;&gt;&gt; ss[0]&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; # Also gets the first Sheet object in this Spreadsheet. &lt;Sheet sheetId=1669384683, title='Classes', rowCount=1000, columnCount=26&gt; You can also obtain a Sheet object with the square brackets operator and a string of the sheet’s name. The Spreadsheet object’s sheetTitles attribute holds a tuple of all the sheet titles. For example, enter the following into the interactive shell: &gt;&gt;&gt; ss.sheetTitles # The titles of all the Sheet objects in this Spreadsheet. ('Classes', 'Resources') &gt;&gt;&gt; ss['Classes'] # Sheets can also be accessed by title. &lt;Sheet sheetId=1669384683, title='Classes', rowCount=1000, columnCount=26&gt; Once you have a Sheet object, you can read data from and write data to it using the Sheet object’s methods, as explained in the next section.
