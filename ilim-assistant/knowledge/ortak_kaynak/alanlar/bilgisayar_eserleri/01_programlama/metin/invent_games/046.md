The Sonar Treasure Hunt game uses lists of lists and other complicated variables, called data structures . Data structures store arrangements of values to represent something. For example, in Chapter 10 , a Tic-Tac-Toe board data structure was a list of strings. The string represented an X , an O , or an empty space, and the index of the string in the list represented the space on the board. The Sonar Treasure Hunt game will have similar data structures for the locations of treasure chests and sonar devices.
