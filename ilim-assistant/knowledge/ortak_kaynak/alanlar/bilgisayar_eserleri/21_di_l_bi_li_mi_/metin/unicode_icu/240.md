4.4.27 Unikemet properties The Unikemet data are represented as attributes. The attribute kEH_Cat is a catalog entry corresponding to the IFAO-based taxonomy. The attribute kEH_Core determines whether an Egyptian hieroglyph is part of the 'Core' set, Legacy or None. The attribute kEH_Desc provides a detailed description of the appearance of the hieroglyph. The attribute kEH_Func represents a function type representing a pictogram, a logogram, a phonemogram (or “phonogram”), a classifier (or “determinative”), a phono-repeater (sub-category of classifier), a radicogram or interpretant. The attribute kEH_FVal expresses the function type using the Gardiner 1957 convention for Egyptian hieroglyph transliteration. The attribute kEH_HG indicates the Hieroglyphica source. The attribute kEH_IFAO indicates the IFAO source value defined as page number and order in that page. The attribute kEH_JSesh indicates the JSesh source as specified in JSesh Documentation. The attribute kEH_NoMirror determines whether the hieroglyph does not mirror. The attribute kEH_NoRotate determines whether the hieroglyph does not rotate. The attribute kEH_UniK represent the original Unikemet catalog index used by the Egyptian Hieroglyph block.
