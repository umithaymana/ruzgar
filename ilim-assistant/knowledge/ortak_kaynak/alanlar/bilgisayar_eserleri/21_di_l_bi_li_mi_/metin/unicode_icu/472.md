Revision 16 The report has been converted to HTML. Edits for clarification and flow. The entire text was reviewed for content and clarity as well as for stale information or items that might need to be changed or corrected due to the new editing workflow or new characters or changes outside this report. As a result of the long time elapsed between this and the previous revision, there are a large number of detail changes throughout the text, figures and tables. The [Data] files have been updated to use the W3C HTML-MathML Entity definitions, and to list the Unicode General Category. Added 3.1.3, Multiple Use Added new paragraph describing single text runs in 3.2.7, Combining Marks Revised formatting for internal and external links. Revised formatting for references. Removed obsolete references. Improved consistency in how characters are listed. Corrected some errors and added some references. Revision 15 Documented the variation sequence &lt;U+2205 U+FE00&gt; for the slashed-0 form of the empty set symbol and the variation sequence &lt;U+0030 U+FE00&gt; for the form of the digit 0 with a diagonal stroke. Used [UTN28] in referring to Unicode Technical Note #28. Various editorial improvements. Revision 14 The [Data] file has been updated to include the Arabic Mathematical Alphabetic Symbols and mathematical symbols added in [Unicode7.0] . Over forty symbols have been assigned math-class values and a number of data corrections have been made along with minor text improvements. Revision 13 Section 2.15 has been expanded to discuss Unicode solidi and reverse solidi from a mathematical point of view and renamed “Fraction Slash and Other Diagonals” to reflect this expansion. The [Data] file has been updated to include the diagonal operators U+27CB and U+27CD introduced in [Unicode6.1] . Revision 12 The [Data] file has been updated to include the operators U+27CE and U+27CF introduced in [Unicode6.0] . The reference to [UTN28] has been updated. Revision 11 This report has been updated with some minor fixes and formatting changes. The text of the report has not received extensive modification, but the report is now available in PDF and docx formats rather than HTML. Revision 10 being a proposed update, only changes between revisions 9 and 11 are noted here. Revision 9 Added several short notes and references regarding Arabic mathematical notation. Added table 2.4 and text on vertical lines. Many minor edits for style, punctuation and formatting. Some improvement and extensions to the sample formulas. Revision 8 Split the data file into separate classification and mapping data. Added a section discussing bidirectional layout. Updated the discussion of geometrical shapes and combining marks. Revision 7 Added information on characters added in Unicode 4.1 and Unicode 5.0. This includes discussion of dotless characters and horizontal delimiters. Split the listing of weakly mathematical characters into two numbered tables 3.1 and 3.2. Added a section on security considerations. Integrated the results of extensive copy editing. Added section 4.2 on mirroring. Revision 6 Rewrote the Overview. Brought table 2.7 into alignment with the standardized variant listing in the Unicode Character Database: 2278 and 2279 have been moved to table 2.5. 2225 was removed from table 2.7 because there is now a new character 2AFD and the variation is no longer needed. Added Table 2.3. Added Section 2.15. Removed section 3.3. Renumbered the appendix to become Section 5. Moved the actual classification of characters into a separate data file. Updated references to the Unicode Standard to Unicode 4.0 where appropriate. Improved the layout of tables 2.5, 2.6 and 2.7. Many minor spelling, wording and formatting fixes throughout. Updated status and conformance section. Completed the classification in sections 3.1.1 and 3.1.2. Changed header and improved visual layout of the data file. Revision 5 Added section 2.16. Added section 3.3. Added Appendix A. Added a few typographical samples. Revision 4 Fixed some CSS issues. Revision 3 Changed many special symbols to NCRs. Fixed an HTML glitch affecting table formatting and fixed contents of Table 2.4. A number of additional typographical mistakes and inconsistencies in the original proposed draft have been corrected. Merged duplicated text in section 2.7 and made additional revisions to further align the text with Unicode 3.2. Minor wording changes for clarity or consistency throughout. Revision 2 A large number of minor, but annoying typographical and HTML mistakes in the original proposed draft have been corrected.
