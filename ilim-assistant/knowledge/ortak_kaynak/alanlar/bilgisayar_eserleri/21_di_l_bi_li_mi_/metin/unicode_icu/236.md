The majority of the characters in Unicode have a name which is of the form CJK UNIFIED IDEOGRAPH- &lt;code point&gt; . It also happens that character names cannot contain the character U+0023 # NUMBER SIGN, so we adopted the following convention: if a code point has the attribute na (either directly or by inheritance from an enclosing group), then occurrences of the character # in the name are to be interpreted as the value of the code point. For example: &lt;char cp="3400" na="CJK UNIFIED IDEOGRAPH-3400"/&gt; and &lt;char cp="3400" na="CJK UNIFIED IDEOGRAPH-#"/&gt; are equivalent. The # can be in any position in the value of the na attribute. The convention also applies just as well to a set of multiple code points: &lt;char cp="3400" na="CJK UNIFIED IDEOGRAPH-3400"/&gt; &lt;char cp="3401" na="CJK UNIFIED IDEOGRAPH-3401"/&gt; is equivalent to &lt;char cp="3400" na="CJK UNIFIED IDEOGRAPH-#"/&gt; &lt;char cp="3401" na="CJK UNIFIED IDEOGRAPH-#"/&gt; which in turn is equivalent to: &lt;char first-cp="3400" last-cp="3401" na="CJK UNIFIED
