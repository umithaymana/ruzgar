Property kSEAL_THXSrc Status Normative Category Sources Introduced 18.0 Delimiter N/A Syntax TH-(\d{5}|X\d{3}|Y\d{3}) Default N/A Description Tenghuaxie THX (額勒布藤花榭本《説文解字》) source, one version of the Daxu Ben Shuowen Jiezi. The so-called "newly added characters" (新附字) specific to Daxu Ben versions are here numbered in the character sequence as 3-digit numbers prefixed with 'X'. These data files were created using data originally present in the encoding proposals and their updates. The data file for Tangut was incorporated into the UCD in Unicode 9.0, when Tangut was first encoded. The data file for Nüshu was incorporated into the UCD in Unicode 10.0, when Nüshu was first encoded. The documentation formerly located in the preambles to those data files has been augmented here for this annex with details found in the original encoding proposals for those scripts. Similarly, for the other two scripts, Jurchen and Small Seal, which are being encoded in Unicode 18.0, the information was directly extracted from the encoding proposals material.
