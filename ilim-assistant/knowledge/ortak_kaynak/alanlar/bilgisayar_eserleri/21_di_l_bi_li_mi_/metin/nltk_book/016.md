Suppose it needs to do this work in two places, once when it is processing some texts, and again when it is processing user input. Rather than repeating the same code several times over, it is more efficient and reliable to localize this work inside a function . A function is just a named block of code that performs some well-defined task, as we saw in 1 . A function is usually defined to take some inputs, using special variables known as parameters , and it may produce a result, also known as a return value . We define a function using the keyword def followed by the function name and any input parameters, followed by the body of the function.
