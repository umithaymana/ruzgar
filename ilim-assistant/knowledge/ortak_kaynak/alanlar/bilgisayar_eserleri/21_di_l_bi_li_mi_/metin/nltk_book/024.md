Accessing Substrings Figure 3.2 : String Slicing: The string &quot;Monty Python&quot; is shown along with its positive and negative indexes; two substrings are selected using &quot;slice&quot; notation. The slice [m,n] contains the characters from position m through n-1 . A substring is any continuous section of a string that we want to pull out for further processing. We can easily access substrings using the same slice notation we used for lists (see 3.2 ). For example, the following code accesses the substring starting at index 6 , up to (but not including) index 10 : &nbsp; &gt;&gt;&gt; monty[6:10] 'Pyth' Here we see the characters are 'P' , 'y' , 't' , and 'h' which correspond to monty[6] ... monty[9] but not monty[10] . This is because a slice starts at the first index but finishes one before the end index. We can also slice with negative indexes &#8212; the same basic rule of starting from the start index and stopping one before the end index applies; here we stop before the space character. &nbsp; &gt;&gt;&gt; monty[-12:-7] 'Monty' As with list slices, if we omit the first value, the substring begins at the start of the string. If we omit the second value, the substring continues to the end of the string: &nbsp; &gt;&gt;&gt; monty[:5] 'Monty' &gt;&gt;&gt; monty[6:] 'Python' We test if a string contains a particular substring using the in operator, as follows: &nbsp; &gt;&gt;&gt; phrase = 'And now for something completely different' &gt;&gt;&gt; if 'thing' in phrase: ... print ( 'found &quot;thing&quot;' ) found &quot;thing&quot; We can also find the position of a substring within a string, using find() : &nbsp; &gt;&gt;&gt; monty.find( 'Python' ) 6 Note Your Turn: Make up a sentence and assign it to a variable, e.g. sent = 'my sentence...' .
