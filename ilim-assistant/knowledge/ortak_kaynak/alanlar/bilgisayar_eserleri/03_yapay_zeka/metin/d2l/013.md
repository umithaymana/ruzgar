Saving Memory ¶ Running operations can cause new memory to be allocated to host results. For example, if we write Y = X + Y , we dereference the tensor that Y used to point to and instead point Y at the newly allocated memory. We can demonstrate this issue with Python’s id() function, which gives us the exact address of the referenced object in memory. Note that after we run Y = Y + X , id(Y) points to a different location.
