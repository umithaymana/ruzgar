Notation &#8212; Dive into Deep Learning 1.0.3 documentation Table Of Contents Table Of Contents Notation ¶ Throughout this book, we adhere to the following notational conventions. Note that some of these symbols are placeholders, while others refer to specific objects. As a general rule of thumb, the indefinite article “a” often indicates that the symbol is a placeholder and that similarly formatted symbols can denote other objects of the same type. For example, “ \(x\) : a scalar” means that lowercased letters generally represent scalar values, but “ \(\mathbb{Z}\) : the set of integers” refers specifically to the symbol \(\mathbb{Z}\) .
