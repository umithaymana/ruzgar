The template methods return a reference to the specified array element. For the sake of higher performance, the index range checks are only performed in the Debug configuration. Note that the variants with a single index (i) can be used to access elements of single-row or single-column 2-dimensional arrays. That is, if, for example, A is a 1 x N floating-point matrix and B is an M x 1 integer matrix, you can simply write A.at&lt;float&gt;(k+4) and B.at&lt;int&gt;(2*i+1) instead of A.at&lt;float&gt;(0,k+4) and B.at&lt;int&gt;(2*i+1,0) , respectively. The example below initializes a Hilbert matrix: Mat H(100, 100, CV_64F ); for ( int i = 0; i &lt; H.rows; i++) for ( int j = 0; j &lt; H.cols; j++) H.at&lt; double &gt;(i,j)=1./(i+j+1); Keep in mind that the size identifier used in the at operator cannot be chosen at random. It depends on the image from which you are trying to retrieve the data. The table below gives a better insight in this: If matrix is of type CV_8U then use Mat.at &lt;uchar&gt;(y,x) . If matrix is of type CV_8S then use Mat.at &lt;schar&gt;(y,x) . If matrix is of type CV_16U then use Mat.at &lt;ushort&gt;(y,x) . If matrix is of type CV_16S then use Mat.at &lt;short&gt;(y,x) . If matrix is of type CV_32S then use Mat.at &lt;int&gt;(y,x) . If matrix is of type CV_32F then use Mat.at &lt;float&gt;(y,x) . If matrix is of type CV_64F then use Mat.at &lt;double&gt;(y,x) .
