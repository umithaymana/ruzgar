No In RepRapFirmware this code is used to apply the configuration of a previously loaded filament (see M701). All it does is run /filaments/&lt;loaded filament&gt;/config.g which may contain codes to set parameters like extrusion factor, retraction distances and temperatures. If no filament is assigned to the current tool, this code will not generate a warning. If the filaments feature is used, it is recommended to put this code into tpost*.g to ensure the right filament parameters are set. Supported in RepRapFirmware 2.02 and newer.
