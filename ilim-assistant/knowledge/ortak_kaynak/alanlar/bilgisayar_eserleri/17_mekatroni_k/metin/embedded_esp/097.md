Symbol can be set when: CONFIG_ESP_HTTP_CLIENT_SAVE_RESPONSE_HEADERS is enabled Default value: 128 CONFIG_ESP_HTTP_CLIENT_STRICT_HEADER_BUFFER  Fail the request when a header does not fit in the tx buffer Found in: Component config &gt; ESP HTTP client When enabled, esp_http_client_request_send() returns ESP_ERR_HTTP_HEADER_TOO_LONG if any individual header is larger than buffer_size_tx. With this option disabled, the legacy behavior is preserved: oversized headers are silently dropped and the request is emitted without its 'rnrn' terminator, which typically results in the server timing out the connection. The strict check adds two small comparisons in the header send loop.
