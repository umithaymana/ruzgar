Symbol can be set when: CONFIG_BT_A2DP_USE_EXTERNAL_CODEC is enabled &amp;&amp; CONFIG_BT_BLUEDROID_ENABLED is enabled Default value: Disabled CONFIG_BT_A2DP_SEP_NUM_MAX  Maximum number of Stream End Points registered per A2DP connection Found in: Component config &gt; Bluetooth &gt; Bluedroid Options &gt; CONFIG_BT_A2DP_ENABLE &gt; CONFIG_BT_A2DP_USE_EXTERNAL_CODEC Number of Stream End Points (SEPs) that can be registered on a single A2DP connection, i.e. how many codecs one peer can see (SBC only = 1, SBC + AAC = 2). This is not the system-wide SEP pool. The AVDTP pool is sized automatically as BT_A2DP_SEP_NUM_MAX * BT_A2DP_SINK_MAX_CONN. Two simultaneous sink connections with SBC and AAC therefore use 4 SEPs without raising this option to 4. Symbol can be set when: CONFIG_BT_A2DP_USE_EXTERNAL_CODEC is enabled &amp;&amp; CONFIG_BT_BLUEDROID_ENABLED is enabled Range: from 1 to 3 Default value: 2 if CONFIG_BT_A2DP_CODEC_AAC_ENABLED is enabled 1 CONFIG_BT_A2DP_SINK_MAX_CONN  Maximum number of simultaneous A2DP sink connections Found in: Component config &gt; Bluetooth &gt; Bluedroid Options &gt; CONFIG_BT_A2DP_ENABLE The maximum number of A2DP source devices that can be connected to the local sink at the same time. When set to 2, the local device behaves like a common Bluetooth speaker: both sources stay connected, but only one of them is the active stream and gets rendered. Media packets of the inactive stream are discarded. Once the active stream is suspended, stopped or closed, the other stream takes over without needing to reconnect. Note this requires CONFIG_BT_ACL_CONNECTIONS and the controller BR/EDR ACL connection number to be at least 2. Symbol can be set when: CONFIG_BT_A2DP_ENABLE is enabled &amp;&amp; CONFIG_BT_BLUEDROID_ENABLED is enabled Range: from 1 to 2 Default value: 1 CONFIG_BT_A2DP_AUDIO_STATS  A2DP audio glitch statistics Found in: Component config &gt; Bluetooth &gt; Bluedroid Options &gt; CONFIG_BT_A2DP_ENABLE Count A2DP audio glitches, packet totals, and lost packets, and expose them through esp_a2d_get_audio_stats().
