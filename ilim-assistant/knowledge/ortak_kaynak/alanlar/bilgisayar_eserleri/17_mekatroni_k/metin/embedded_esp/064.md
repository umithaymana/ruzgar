The spec allows up to 65533 octets, but the host ACL reassembly buffer (BT_DEFAULT_BUFFER_SIZE) accepts at most 4096. A larger advertised receive MPS makes a peer send K-frames that are dropped before LE credit accounting. Legacy CoC minimum is 23; ECFC/EATT minimum is 64. Symbol can be set when: CONFIG_BT_BLE_L2CAP_COC_ENABLED is enabled &amp;&amp; CONFIG_BT_BLE_ENABLED is enabled &amp;&amp; ( CONFIG_BT_GATTC_ENABLE is enabled || CONFIG_BT_GATTS_ENABLE is enabled) &amp;&amp; CONFIG_BT_BLUEDROID_ENABLED is enabled Range: from 23 to 4096 if CONFIG_BT_BLE_L2CAP_ENHANCED_COC is disabled from 64 to 4096 if CONFIG_BT_BLE_L2CAP_ENHANCED_COC is enabled Default value: 247 CONFIG_BT_BLE_L2CAP_COC_INIT_CREDITS  Initial RX credit window (K-frames per channel) Found in: Component config &gt; Bluetooth &gt; Bluedroid Options &gt; Bluedroid L2CAP CoC &gt; CONFIG_BT_BLE_L2CAP_COC_ENABLED Number of LE CoC RX credits granted to the peer when a channel opens. One credit allows the peer to send one K-frame. A larger window can raise sustained throughput but increases how many in-flight frames the peer may send before waiting for more credits (higher RX memory pressure). A smaller window reduces that pressure but can lower throughput. Manual credit mode can stall if a single SDU needs more K-frames than this window; prefer automatic credit mode or a larger MPS when using large MTUs. Symbol can be set when: CONFIG_BT_BLE_L2CAP_COC_ENABLED is enabled &amp;&amp; CONFIG_BT_BLE_ENABLED is enabled &amp;&amp; ( CONFIG_BT_GATTC_ENABLE is enabled || CONFIG_BT_GATTS_ENABLE is enabled) &amp;&amp; CONFIG_BT_BLUEDROID_ENABLED is enabled Range: from 1 to 64 Default value: 24 CONFIG_BT_BLE_L2CAP_ENHANCED_COC  Enable Enhanced Credit Based Flow Control (ECFC) Found in: Component config &gt; Bluetooth &gt; Bluedroid Options &gt; Bluedroid L2CAP CoC &gt; CONFIG_BT_BLE_L2CAP_COC_ENABLED Enable LE Enhanced CoC (L2CAP signaling 0x17/0x18) for multi-channel establishment.
