Symbol can be set when: (CONFIG_BLE_LOG_PRPH_COPY_FIFO is enabled || CONFIG_BLE_LOG_PRPH_TEST is enabled) &amp;&amp; CONFIG_BLE_LOG_ENABLED is enabled Range: from -1 to 1000 Default value: 10 if CONFIG_BLE_LOG_PRPH_COPY_FIFO is enabled &quot;-1&quot; CONFIG_BLE_LOG_TASK_ID_MAX  Maximum number of distinct logging tasks Found in: Component config &gt; Bluetooth &gt; Common Options &gt; BT Logs &gt; CONFIG_BLE_LOG_ENABLED Size of the task-id registry (protocol v8). Every ENCODE record carries the one-byte id of the task that formatted it; the registry maps task names to those stable ids. One binding record per registered entry is broadcast as an INTERNAL frame on every periodic snapshot window, so a receiver that missed or lost a binding converges on the next window. A task that starts logging after the registry is full falls back to the unknown id (0xFF) and its records are still emitted. RAM cost is 16 bytes per entry (256 bytes at the default 16) plus one dedicated binding transport (320 bytes at 16 entries, 624 at 32; the broadcast frame must fit in one transport). Symbol can be set when: CONFIG_BLE_LOG_ENABLED is enabled Default value: Enabled CONFIG_BLE_LOG_TS_SYNC_TOGGLE_IO_ENABLED  Output snapshot counts on the BLE Log TS sync GPIO Found in: Component config &gt; Bluetooth &gt; Common Options &gt; BT Logs &gt; CONFIG_BLE_LOG_ENABLED Every periodic Internal Snapshot samples the link-layer, ESP and OS clocks regardless of this option. Enable this option to build seven-byte 1 Mbaud UART 8N1 labels containing snapshot count and ESP time for external logic analyzers. UART1 is reserved for labels and must not be used by the console, BLE Log transport or application. No DMA is used. Output starts automatically with BLE Log initialization and stops at deinitialization, independently of log enable commands. Legacy sync enable APIs are no-ops. The pin idles high. UART TX inversion produces a falling edge and clocks are sampled in the same critical section. Afterwards, normal TX polarity is restored before the label is sent via the public UART API. A low BREAK of at least 12 us and high separator of at least 2 us are ensured with short delays outside the critical section.
