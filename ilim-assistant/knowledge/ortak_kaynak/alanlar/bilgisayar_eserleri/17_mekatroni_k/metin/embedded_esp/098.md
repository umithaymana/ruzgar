Symbol can be set when: CONFIG_HTTPD_WS_SUPPORT is enabled Default value: Disabled CONFIG_HTTPD_QUEUE_WORK_BLOCKING  httpd_queue_work as blocking API Found in: Component config &gt; HTTP Server Selects the wait policy for httpd_queue_work() when the UDP control-socket mbox is at capacity. The HTTP server always uses a counting semaphore (sized to LWIP_UDP_RECVMBOX_SIZE) to prevent silent mbox overflow drops that would leak the caller's async-send callback context. When disabled (default): httpd_queue_work() returns ESP_FAIL immediately if the mbox is full, so the caller can free its callback context. This preserves the non-blocking semantics of httpd_ws_send_data_async(). When enabled: httpd_queue_work() blocks until a slot is available. Use this only if your application can tolerate the call blocking and wants guaranteed delivery instead of a fast-fail.
