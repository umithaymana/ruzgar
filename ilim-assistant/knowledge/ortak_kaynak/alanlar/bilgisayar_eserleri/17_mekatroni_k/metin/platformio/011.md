The PlatformIO Build System allows the user to extend the build process with custom scripts using the Python interpreter and the SCons construction tool. Build flags, upload flags, targets, toolchains data and other information are available for modification as SCons Construction Environments . Custom scripts are included with extra_scripts . Warning Please note that you can not run or debug these scripts independently with Python interpreter. They will be loaded automatically when the pio run command processes the project environment.
