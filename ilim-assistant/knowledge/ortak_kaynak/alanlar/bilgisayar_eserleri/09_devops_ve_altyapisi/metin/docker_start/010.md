Testing the managed experience with a small group helps uncover access or workflow problems before they affect everyone. In this 15-minute tutorial, you'll invite one pilot user, apply one managed setting to that user, and confirm that Docker Desktop receives the policy. Before you start You need: A Docker Business subscription Owner access to a Docker organization A verified company domain Enforced Docker Desktop sign-in One pilot user with Docker Desktop installed Invite the pilot user Sign in to Docker Home and select your organization. Select Members , then Invite . Select Emails or usernames and enter the pilot user's email address. Assign the Member role and a Docker Desktop license, then send the invitation. Have the pilot user accept the invitation from the email or the Notifications Center . The pilot user is now part of the organization and can receive its Docker Desktop policies. Create a pilot policy In Docker Home, select Docker Desktop , then Settings Management . Select Create a settings policy . Name the policy Docker pilot . Apply the policy to Specific users , then select the pilot user. Set Automatically update components to Always enabled . Leave the other settings as User-defined . Select Create . This policy locks one low-impact setting, making the result visible without changing the pilot user's development workflow. Apply and verify the policy Ask the pilot user to: Quit Docker Desktop completely. Start Docker Desktop and sign in with the account that joined the organization. Open Docker Desktop settings and confirm that Automatically update components is enabled and can't be changed. Run a familiar development project to confirm their normal workflow still works. Docker Desktop checks for policy updates when it starts and every 60 minutes while running. Fully quitting and reopening it applies the policy without waiting for the next check. What you learned You added a user, targeted a policy, and verified the managed Docker Desktop experience before applying controls across the organization. Use the pilot's feedback to refine the policy and its deployment communication.
