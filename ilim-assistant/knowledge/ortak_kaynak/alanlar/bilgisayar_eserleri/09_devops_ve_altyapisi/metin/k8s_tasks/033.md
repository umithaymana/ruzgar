Docker Engine Note: These instructions assume that you are using the cri-dockerd adapter to integrate Docker Engine with Kubernetes. On each of your nodes, install Docker for your Linux distribution as per Install Docker Engine . Install cri-dockerd , following the directions in the install section of the documentation. Mirantis Container Runtime Mirantis Container Runtime (MCR) is a commercially available container runtime that was formerly known as Docker Enterprise Edition. You can use Mirantis Container Runtime with Kubernetes using the open source cri-dockerd component, included with MCR. To learn more about how to install Mirantis Container Runtime, visit MCR Deployment Guide . Check the systemd unit named cri-docker.socket to find out the path to the CRI socket.
