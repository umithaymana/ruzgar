You can pass - to read from standard input. &lt;vmid&gt; : &lt;integer&gt; (100 - 999999999) The (unique) ID of the VM. --bwlimit &lt;number&gt; (0 - N) Override I/O bandwidth limit (in KiB/s). --force &lt;boolean&gt; Allow to overwrite existing VM. --ha-managed &lt;boolean&gt; ( default = 0 ) Add the VM as a HA resource after it was restored. --live-restore &lt;boolean&gt; Start the VM immediately from the backup and restore in background. PBS only. --pool &lt;string&gt; Add the VM to the specified pool. --start &lt;boolean&gt; ( default = 0 ) Start VM after it was restored successfully. --storage &lt;storage ID&gt; Default storage. --unique &lt;boolean&gt; Assign a unique random ethernet address. DESCRIPTION Restore the QemuServer vzdump backup archive to virtual machine vmid . Volumes are allocated on the original storage if there is no storage specified.
