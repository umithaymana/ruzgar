DESCRIPTION SPICE (the Simple Protocol for Independent Computing Environments) is an open remote computing solution, providing client access to remote displays and devices (e.g. keyboard, mouse, audio). The main use case is to get remote access to virtual machines and container. This daemon listens on TCP port 3128, and implements an HTTP proxy to forward CONNECT request from the SPICE client to the correct Proxmox VE VM. It runs as user www-data and has very limited permissions. Host based Access Control It is possible to configure "apache2" like access control lists. Values are read from file /etc/default/pveproxy . See pveproxy documentation for details.
