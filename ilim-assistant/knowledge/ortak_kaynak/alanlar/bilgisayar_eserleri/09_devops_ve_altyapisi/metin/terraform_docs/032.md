Configure HCP Packer integration On the HCP Packer Buckets page, click Integrate with HCP Terraform . This displays information you will use to configure your HCP Terraform run task. The Endpoint URL is a unique HCP Packer URL, specific to your HCP organization and HCP Packer registry. The HCP Terraform run task will send a payload to this URL for artifact validation. The HMAC Key is a secret key that lets HCP Packer verify the run task request. Warning Do not share these values. If your HMAC key is compromised, re-generate it and update your HCP Terraform run task to use the new value. Leave this tab open to reference the displayed values for the next step.
