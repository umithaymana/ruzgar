Generators Generators are functions that create file formats from Nix data structures, e.g. for configuration files. There are generators available for: INI , JSON and YAML . All generators follow a similar call interface: generatorName configFunctions data , where configFunctions is an attrset of user-defined functions that format nested parts of the content. They each have common defaults, so often they do not need to be set manually.
