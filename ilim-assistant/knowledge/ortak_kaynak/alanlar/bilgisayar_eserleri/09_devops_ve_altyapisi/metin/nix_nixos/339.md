Property Store Path Title: Store Path Type string Required No Same definition as path Description: A store path identifying a store object. This schema describes the JSON representation of store paths as used in various Nix JSON APIs. Warning This JSON format is currently experimental and subject to change. Format Store paths in JSON are represented as strings containing just the hash and name portion, without the store directory prefix. For example: "g1w7hy3qg1w7hy3qg1w7hy3qg1w7hy3q-foo.drv" (If the store dir is /nix/store , then this corresponds to the path /nix/store/g1w7hy3qg1w7hy3qg1w7hy3qg1w7hy3q-foo.drv .) Structure The format follows this pattern: ${digest}-${name} hash : Digest rendered in Nix32 , a variant of base-32 (20 hash bytes become 32 ASCII characters) name : The package name and optional version/suffix information 2.8.2.
