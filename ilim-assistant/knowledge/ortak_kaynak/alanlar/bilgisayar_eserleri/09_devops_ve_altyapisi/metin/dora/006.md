The site is built using a hybrid architecture: Static site generator : Hugo compiles the content and layouts (located under /hugo ). Interactive tools : Built as Svelte applications (under /svelte ) and embedded as compiled assets within the Hugo pages. Hosting and routing : Powered by Firebase , which handles URL redirects, hosting, and PR-specific preview environments. 📖 Documentation directory Developer onboarding guide : Workspace setup, prerequisites, Jujutsu ( jj )/Git workflows, and building individual Svelte applications.
