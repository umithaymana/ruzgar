New in v2.28 Self Metrics NOTE : This endpoint is experimental and might change in the future. The following endpoint returns Prometheus&#x27; own instrumentation metrics from its internal client registry as structured JSON. These are the same metrics that are exposed on the /metrics endpoint in Prometheus text exposition format, but returned as JSON for programmatic access by the web UI. The response uses the standard ProtoJSON representation of the io.prometheus.client.MetricFamily protocol buffer message. GET /api/v1/status/self_metrics URL query parameters: metric_name_pattern=&lt;string&gt; : A regular expression filter for metric names (fully anchored, like PromQL label matchers). Only metric families whose names fully match the pattern are returned. For example, metric_name_pattern=prometheus_tsdb_.* returns all metric families whose names start with prometheus_tsdb_ . Optional. When omitted, all metric families are returned. Each returned metric family is a ProtoJSON-encoded MetricFamily containing: name : The metric name. help : The metric help string. type : The metric type ( COUNTER , GAUGE , SUMMARY , HISTOGRAM , UNTYPED ). unit : The metric unit, if set (optional). metric : A list of individual metrics, each containing: label : A list of {name, value} label pairs. gauge , counter , summary , histogram , or untyped : The type-specific metric data. curl &#x27;http://localhost:9090/api/v1/status/self_metrics?metric_name_pattern=prometheus_build_info&#x27; { &quot;status&quot; : &quot;success&quot; , &quot;data&quot; : [ { &quot;name&quot; : &quot;prometheus_build_info&quot; , &quot;help&quot; : &quot;A metric with a constant &#x27;1&#x27; value labeled by version, revision, branch, goversion from which prometheus was built, and the goos and goarch for the build.&quot; , &quot;type&quot; : &quot;GAUGE&quot; , &quot;metric&quot; : [ { &quot;label&quot; : [ { &quot;name&quot; : &quot;branch&quot; , &quot;value&quot; : &quot;main&quot; }, { &quot;name&quot; : &quot;goarch&quot; , &quot;value&quot; : &quot;amd64&quot; }, { &quot;name&quot; : &quot;goos&quot; , &quot;value&quot; : &quot;linux&quot; }, { &quot;name&quot; : &quot;goversion&quot; , &quot;value&quot; : &quot;go1.26.1-X:nodwarf5&quot; }, { &quot;name&quot; : &quot;revision&quot; , &quot;value&quot; : &quot;7b5
