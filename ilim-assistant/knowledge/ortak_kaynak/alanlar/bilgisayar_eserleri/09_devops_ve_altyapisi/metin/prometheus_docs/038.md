HTTP configuration for promtool | Prometheus Prometheus Docs Download Community Support &amp; Training Blog Ctrl + K Show nav HTTP configuration for promtool Promtool is a versatile CLI tool for Prometheus that supports validation, debugging, querying, unit testing, tsdb management, pushing data, and experimental PromQL editing. Prometheus supports basic authentication and TLS. Since promtool needs to connect to Prometheus, we need to provide the authentication details. To specify those authentication details, use the --http.config.file for all requests that need to communicate with Prometheus. For instance, if you would like to check whether your local Prometheus server is healthy, you would use: promtool check healthy --url=http://localhost:9090 --http.config.file=http-config-file.yml The file is written in YAML format , defined by the schema described below. Brackets indicate that a parameter is optional. For non-list parameters the value is set to the specified default. The file is read upon every http request, such as any change in the configuration and the certificates is picked up immediately.
