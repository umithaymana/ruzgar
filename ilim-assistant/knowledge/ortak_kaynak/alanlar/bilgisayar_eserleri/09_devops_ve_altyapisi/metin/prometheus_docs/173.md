One of the following &lt;triton_role&gt; types can be configured to discover targets: container The container role discovers one target per &quot;virtual machine&quot; owned by the account . These are SmartOS zones or lx/KVM/bhyve branded zones. The following meta labels are available on targets during relabeling : __meta_triton_groups : the list of groups belonging to the target joined by a comma separator __meta_triton_machine_alias : the alias of the target container __meta_triton_machine_brand : the brand of the target container __meta_triton_machine_id : the UUID of the target container __meta_triton_machine_image : the target container&#x27;s image type __meta_triton_server_id : the server UUID the target container is running on cn The cn role discovers one target for per compute node (also known as &quot;server&quot; or &quot;global zone&quot;) making up the Triton infrastructure. The account must be a Triton operator and is currently required to own at least one container .
