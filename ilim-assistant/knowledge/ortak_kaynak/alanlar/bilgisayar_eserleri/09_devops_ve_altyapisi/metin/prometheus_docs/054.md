In addition it returns the currently active alerts fired by the Prometheus instance of each alerting rule. As the /rules endpoint is fairly new, it does not have the same stability guarantees as the overarching API v1. GET /api/v1/rules URL query parameters: type=alert|record : return only the alerting rules (e.g. type=alert ) or the recording rules (e.g. type=record ).
