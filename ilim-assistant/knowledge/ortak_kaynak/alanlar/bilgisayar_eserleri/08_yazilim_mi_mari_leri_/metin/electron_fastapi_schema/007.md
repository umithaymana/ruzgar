It should be a reverse-DNS style ID such as `com.example.MyApp`, following the [desktop entry naming conventions](https://specifications.freedesktop.org/desktop-entry/latest/file-naming.html). This value is used as: * the XDG application ID (`app_id`) on Wayland and `WM_CLASS` on X11, used to match the app's icon and window grouping. * the app ID that `xdg-desktop-portal` reports to portal backends such as [GlobalShortcuts](global-shortcut.md).
