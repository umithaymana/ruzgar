This means that the process for releasing a new JS version is: 1. Bump the version in `@automerge/automerge` also in `javascript/package.json` 2. Put in a PR to main with the version bump, wait for tests to run and merge to `main` 3. Once merged to main, create a tag of the form `js/automerge- ` 4. Create a new release on Github referring to the tag in question This does depend on an access token available as `NPM_TOKEN` in the actions environment, this token is generated with a 30 day expiry date so needs (manually) refreshing every so often. #### Rust Package This is much easier, but less automatic. The steps to release are: 1. Bump the version in `automerge/Cargo.toml` 2. Push a PR and merge once clean 3. Tag the release as `rust/automerge@ ` 4. Push the tag to the repository 5. Publish the release with `cargo publish`
