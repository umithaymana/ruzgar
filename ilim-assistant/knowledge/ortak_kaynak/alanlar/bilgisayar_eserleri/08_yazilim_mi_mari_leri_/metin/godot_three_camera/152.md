Heads up display  The final piece our game needs is a User Interface (UI) to display things like score, a &quot;game over&quot; message, and a restart button. Create a new scene, click the &quot;Other Node&quot; button and add a CanvasLayer node named HUD . &quot;HUD&quot; stands for &quot;heads-up display&quot;, an informational display that appears as an overlay on top of the game view. The CanvasLayer node lets us draw our UI elements on a layer above the rest of the game, so that the information it displays isn't covered up by any game elements like the player or mobs. The HUD needs to display the following information: Score, changed by ScoreTimer . A message, such as &quot;Game Over&quot; or &quot;Get Ready!&quot; A &quot;Start&quot; button to begin the game. The basic node for UI elements is Control . To create our UI, we'll use two types of Control nodes: Label and Button . Create the following as children of the HUD node: Label named ScoreLabel . Label named Message . Button named StartButton . Timer named MessageTimer . Click on the ScoreLabel and type a number into the Text field in the Inspector. The default font for Control nodes is small and doesn't scale well. There is a font file included in the game assets called &quot;Xolonium-Regular.ttf&quot;. To use this font, do the following: Under &quot;Theme Overrides &gt; Fonts&quot;, choose &quot;Load&quot; and select the &quot;Xolonium-Regular.ttf&quot; file. The font size is still too small, increase it to 64 under &quot;Theme Overrides &gt; Font Sizes&quot;. Once you've done this with the ScoreLabel , repeat the changes for the Message and StartButton nodes. Note Anchors: Control nodes have a position and size, but they also have anchors. Anchors define the origin - the reference point for the edges of the node. Arrange the nodes as shown below. You can drag the nodes to place them manually, or for more precise placement, use &quot;Anchor Presets&quot;. ScoreLabel  Add the text 0 . Set the &quot;Horizontal Alignment&quot; and &quot;Vertical Alignment&quot; to Center . Choose the &quot;Anchor Preset&quot; Center Top . Message  Add the text Dodge the Creeps! . Set the &quot;Horizontal Alignment&quot; and &quot;Vertical Alignment&quot; to Center . Set the &quot;Autowrap Mode&quot; to Word , otherwise the label will stay on one line. Under &quot;Control - Layout/Transform&quot; set &quot;Size X&quot; to 480 to use the entire width of the screen. Choose the &quot;Anchor Preset&quot; Center . StartButton  Add the text Start . Under &quot;Control - Layout/Transform&quot;, set &quot;Size X&quot; to 200 and &quot;Size Y&quot; to 100 to add a little bit more padding between the border and text. Choose the &quot;Anchor Preset&quot; Center Bottom . Under &quot;Control - Layout/Transform&quot;, set &quot;Position Y&quot; to 580 . On the MessageTimer , set the Wait Time to 2 and set the One Shot property to &quot;On&quot;. Removing old creeps  If you play until &quot;Game Over&quot; and then start a new game right away, the creeps from the previous game may still be on the screen. It would be better if they all disappeared at the start of a new game. We just need a way to tell all the mobs to remove themselves. We can do this with the &quot;group&quot; feature. In the Mob scene, select the root node and click the Groups tab next to the Signals tab and the &quot;+&quot; button to open the &quot;Create New Group&quot; dialog. Name the group mobs and click &quot;ok&quot; to add a new scene group. Now all mobs will be in the &quot;mobs&quot; group. We can then add the following line to the new_game() function in Main : GDScript C# get_tree () . call_group ( &quot;mobs&quot; , &quot;queue_free&quot; ) // Note that for calling Godot-provided methods with strings, // we have to use the original Godot snake_case name. GetTree (). CallGroup ( &quot;mobs&quot; , Node . MethodName . QueueFree ); The call_group() function calls the named function on every node in a group - in this case we are telling every mob to delete itself. The game's mostly done at this point.
