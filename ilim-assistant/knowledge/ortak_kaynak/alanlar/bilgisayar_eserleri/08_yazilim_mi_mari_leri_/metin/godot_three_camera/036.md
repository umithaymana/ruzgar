It contains a dictionary of :ref:`AnimationLibrary ` resources and custom blend times between animation transitions. Some methods and properties use a single key to reference an animation directly. These keys are formatted as the key for the library, followed by a forward slash, then the key for the animation within the library, for example ``"movement/run"``. It can also be used over :ref:`Tween ` if the animation track editor is more convenient than doing it in code.
