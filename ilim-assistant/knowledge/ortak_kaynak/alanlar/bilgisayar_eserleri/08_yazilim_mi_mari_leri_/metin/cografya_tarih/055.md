Leaflet Quick Start Guide - Leaflet &larr; Tutorials For Leaflet 2.0 beta Leaflet Quick Start Guide This step-by-step guide will quickly get you started on Leaflet basics, including setting up a Leaflet map, working with markers, polylines and popups, and dealing with events. See this example stand-alone. Preparing your page Leaflet is an ES module , and the quickest way to start is to load it from a CDN. Save this page as an HTML file and open it in a browser: &lt;! DOCTYPE html &gt; &lt; html &gt; &lt; head &gt; &lt; meta charset = "utf-8" &gt; &lt; meta name = "viewport" content = "width=device-width, initial-scale=1" &gt; &lt; link rel = "stylesheet" href = "https://cdn.jsdelivr.net/npm/leaflet@2.0.0-beta.3/dist/leaflet.css" &gt; &lt; script type = "importmap" &gt; {"imports": {"leaflet": "https://cdn.jsdelivr.net/npm/leaflet@2.0.0-beta.3/dist/leaflet.js"}} &lt;/ script &gt; &lt;/ head &gt; &lt; body &gt; &lt; div id = "map" style = "height: 400px" &gt;&lt;/ div &gt; &lt; script type = "module" &gt; import { LeafletMap , TileLayer } from 'leaflet' ; // the map code goes here &lt;/ script &gt; &lt;/ body &gt; &lt;/ html &gt; Here&#8217;s what each part does: The &lt;link&gt; loads Leaflet&#8217;s CSS. The import map tells the browser where to load &#39;leaflet&#39; from when your code imports it. The div is where the map goes. It needs a height. Your code goes in the script with type=&quot;module&quot; . Module scripts run after the page is parsed, so the map div already exists. For production, the install page has the same snippets with integrity hashes , which make sure the files from the CDN haven&#8217;t been tampered with. Once your code grows, you may want to move it to its own file, like &lt;script type=&quot;module&quot; src=&quot;app.js&quot;&gt;&lt;/script&gt; . Browsers don&#8217;t load module files from pages opened directly from disk, so you&#8217;ll then need to open the page through a local web server, for example by running npx serve or python3 -m http.server in its folder. Using a bundler If you build your app with a bundler such as Vite , install Leaflet from npm instead: npm install leaflet@2.0.0-beta.3 Then import Leaflet&#8217;s classes and its CSS in your code. You don&#8217;t need the import map or the &lt;link&gt; then, and the bundler only includes the parts of Leaflet your app uses: import { LeafletMap , TileLayer } from 'leaflet' ; import 'leaflet/styles.css' ; The rest of this guide works the same either way. If you can&#8217;t use modules at all, see the install page for leaflet-global.js , a classic script that puts Leaflet in the global L variable. Setting up the map See this example stand-alone. Let&#8217;s create a map of the center of London with pretty OpenStreetMap tiles. From here on, the code goes in the module script. First we&#8217;ll initialize the map and set its view to our chosen geographical coordinates and a zoom level: const map = new LeafletMap ( 'map' ). setView ([ 51.505 , -0.09 ], 13 ); By default (as we didn&#8217;t pass any options when creating the map instance), all mouse and touch interactions on the map are enabled, and it has zoom and attribution controls. Note that the setView call also returns the map object &#8212; most Leaflet methods act like this when they don&#8217;t return an explicit value, which allows method chaining. Next, we&#8217;ll add a tile layer to add to our map, in this case it&#8217;s a OpenStreetMap tile layer. Creating a tile layer usually involves setting the URL template for the tile images, the attribution text, and the maximum zoom level of the layer. OpenStreetMap tiles are fine for programming your Leaflet map, but read the Tile Usage Policy of OpenStreetMap if you&#8217;re going to use the tiles in production. new TileLayer ( 'https://tile.openstreetmap.org/{z}/{x}/{y}.png' , { maxZoom : 19 , attribution : '&amp;copy; &lt;a href="https://www.openstreetmap.org/copyright"&gt;OpenStreetMap&lt;/a&gt;' }). addTo (map); That&#8217;s it! You have a working Leaflet map now. It&#8217;s worth noting that Leaflet is provider-agnostic, meaning that it doesn&#8217;t enforce a particular choice of providers for tiles. Also, Leaflet doesn&#8217;t even contain a single provider-specific line of code, so you&#8217;re free to use other providers if you need to. Whenever using anything based on OpenStreetMap, an attribution is obligatory as per the copyright notice . Most other tile providers (such as Mapbox or Thunderforest ) require an attribution as well. Make sure to give credit where credit is due. Markers, circles, and polygons See this example stand-alone. Besides tile layers, you can easily add other things to your map, including markers, polylines, polygons, circles, and popups. Add the classes you use to the import line at the top of the script: import { LeafletMap , TileLayer , Marker , Circle , Polygon } from 'leaflet' ; Let&#8217;s add a marker: const marker = new Marker ([ 51.5 , -0.09 ]). addTo (map); Adding a circle is similar, except that you set its radius in meters with the radius option. Options also control how it looks: const circle = new Circle ([ 51.508 , -0.11 ], { color : 'red' , fillColor : '#f03' , fillOpacity : 0.5 , radius : 500 }). addTo (map); Adding a polygon is as easy: const polygon = new Polygon ([ [ 51.509 , -0.08 ], [ 51.503 , -0.06 ], [ 51.51 , -0.047 ] ]). addTo (map); Working with popups See this example stand-alone. Popups are usually used when you want to attach some information to a particular object on a map. Leaflet has a very handy shortcut for this: marker. bindPopup ( "&lt;b&gt;Hello world!&lt;/b&gt;&lt;br&gt;I am a popup." ). openPopup (); circle. bindPopup ( "I am a circle." ); polygon. bindPopup ( "I am a polygon." ); Try clicking on our objects. The bindPopup method attaches a popup with the specified HTML content to your marker so the popup appears when you click on the object, and the openPopup method (for markers only) immediately opens the attached popup. Note that popup content is rendered as HTML, so don&#8217;t pass untrusted user input to it directly. You can also use popups as layers (when you need something more than attaching a popup to an object). This one needs Popup in the imports: const popup = new Popup () . setLatLng ([ 51.513 , -0.09 ]) . setContent ( "I am a standalone popup." ) . openOn (map); Here we use openOn instead of addTo because it handles automatic closing of a previously opened popup when opening a new one which is good for usability. Dealing with events Every time something happens in Leaflet, e.g. user clicks on a marker or map zoom changes, the corresponding object sends an event which you can subscribe to with a function. It allows you to react to user interaction: function onMapClick ( e ) { alert ( "You clicked the map at " + e.latlng); } map. on ( 'click' , onMapClick); Each object has its own set of events &#8212; see documentation for details. The first argument of the listener function is an event object &#8212; it contains useful information about the event that happened. For example, map click event object ( e in the example above) has latlng property which is a location at which the click occurred. Let&#8217;s improve our example by using a popup instead of an alert: const popup = new Popup (); function onMapClick ( e ) { popup . setLatLng (e.latlng) . setContent ( "You clicked the map at " + e.latlng. toString ()) . openOn (map); } map. on ( 'click' , onMapClick); Try clicking on the map and you will see the coordinates in a popup.
