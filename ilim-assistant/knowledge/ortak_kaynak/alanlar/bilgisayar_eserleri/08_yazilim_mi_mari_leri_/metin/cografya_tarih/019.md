DefaultIcon A subclass of Icon , represents the icon to use in Marker s when no icon is specified. The marker, with a soft shadow under its tip, is one inlined SVG data URI, so it needs no image files. Usage example new Marker (latlng, { icon : new DefaultIcon ({ color : 'crimson' })}). addTo (map); In order to customize the default icon, just change the properties of DefaultIcon.defaultOptions (which is a set of Icon options ). If you want to completely replace the default icon, override the Marker.defaultOptions.icon with your own icon instead.
