LayersControl The layers control gives users the ability to switch between different base layers and switch overlays on/off (check out the detailed example ). Extends Control . Usage example const baseLayers = { "Mapbox" : mapbox, "OpenStreetMap" : osm }; const overlays = { "Marker" : marker, "Roads" : roadsLayer }; new LayersControl (baseLayers, overlays). addTo (map); The baseLayers and overlays parameters are object literals with layer names as keys and Layer objects as values: { "&lt;someName1&gt;" : layer1, "&lt;someName2&gt;" : layer2 } The layer names can contain HTML, which allows you to add additional styling to the items: { "&lt;img src='my-layer-icon' /&gt; &lt;span class='my-layer-item'&gt;My Layer&lt;/span&gt;" : myLayer} Constructor Constructor Description new LayersControl ( baseLayers? : Object, overlays? : Object, options? : LayersControl options ) Creates a layers control with the given layers. Base layers will be switched with radio buttons, while overlays will be switched with checkboxes. Note that all base layers should be passed in the base layers object, but only one should be added to the map during map instantiation.
