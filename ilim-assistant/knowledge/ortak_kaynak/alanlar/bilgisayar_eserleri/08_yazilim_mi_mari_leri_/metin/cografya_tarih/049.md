Usage example import { version } from 'leaflet' ; console. log (version); // "2.0.0", or whatever version is in use Class Class is the base of Evented , Handler , Icon and Control , and through them of almost all of the Leaflet classes documented here. Leaflet classes are plain JavaScript classes: extend them with extends and put setup code in constructor() , after calling super() . Class adds what plugins need on top of that: default options, mixins and constructor hooks. Usage example class MyClass extends Class { constructor ( greeter ) { super (); this .greeter = greeter; } greet ( name ) { alert ( this .greeter + ', ' + name) } } // create instance of MyClass, passing "Hello" to the constructor const a = new MyClass ( "Hello" ); // call greet method, alerting "Hello, World" a. greet ( "World" ); Leaflet 1.x classes used an initialize() method instead of constructor() . Constructing a class that still has an initialize() method throws an error. Options Declare the default options of a class with a static defaultOptions field. They are merged with the default options of the parent class instead of replacing them, which makes managing configuration of objects and default values convenient: class MyClass extends Class { static defaultOptions = { myOption1 : 'foo' , myOption2 : 'bar' }; } class MyChildClass extends MyClass { static defaultOptions = { myOption1 : 'baz' , myOption3 : 5 }; } const a = new MyChildClass (); a.options.myOption1; // 'baz' a.options.myOption2; // 'bar' a.options.myOption3; // 5 Every instance gets its own options object, which inherits from the default options of its class. Changing a default later, like Marker.defaultOptions.riseOnHover = true , affects all instances that don&#39;t set the option themselves. mergeOptions() adds or changes defaults of an existing class without touching the defaults of its parent, which makes it the way to change defaults from a plugin: MyChildClass. mergeOptions ({ myOption4 : true }); There&#39;s also Util.setOptions , a method for conveniently merging options passed to constructor with the defaults defined in the class: class MyClass extends Class { static defaultOptions = { foo : 'bar' , bla : 5 }; constructor ( options ) { super (); Util. setOptions ( this , options); ... } } const a = new MyClass ({ bla : 10 }); a.options; // {foo: 'bar', bla: 10} Note that the options object allows any keys, not just the options defined by the class and its base classes. This means you can use the options object to store application specific information, as long as you avoid keys that are already used by the class in question.
