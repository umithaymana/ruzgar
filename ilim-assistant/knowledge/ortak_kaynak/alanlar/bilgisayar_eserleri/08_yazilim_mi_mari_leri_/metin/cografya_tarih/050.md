Leaflet comes with a way to do it easily using the addInitHook method: MyClass. addInitHook ( function () { // ... do something in constructor additionally // e.g. add event listeners, set custom properties etc. }); You can also use the following shortcut when you just need to make one additional method call: MyClass. addInitHook ( 'methodName' , arg1, arg2, …); Hooks added to a class also run for instances of its subclasses, parent class hooks first, and each hook runs once per instance. For Leaflet&#39;s own classes, they run after the constructor has finished, so a hook added to Layer sees a fully built Polygon . For a class of your own that extends a Leaflet class, they run before the constructor body of your class. If other code adds hooks to a class of yours and these hooks need the constructor of your class to have run, mark the class with static initHooks = true and end its constructor with this.callInitHooks() : class MyLayer extends Layer { static initHooks = true ; constructor ( options ) { super (); Util. setOptions ( this , options); this ._items = []; this . callInitHooks (); } } Methods Method Description callInitHooks () Called at the end of the constructor of every class with static initHooks = true . The last of these calls, from the deepest such class, runs all hooks of the chain once, so they see a fully built instance. Evented A set of methods shared between event-powered classes (like Map and Marker ). Generally, events allow you to execute some function when something happens with an object (e.g. the user clicks on the map, causing the map to fire &#39;click&#39; event). Usage example map. on ( 'click' , function ( e ) { alert (e.latlng); } ); Leaflet deals with event listeners by reference, so if you want to add a listener and then remove it, define it as a function: function onClick ( e ) { ... } map. on ( 'click' , onClick); map. off ( 'click' , onClick); Methods Method Description on ( type : String, fn : Listener, context? : *) : this Adds a listener function ( fn ) to a particular event type of the object. You can optionally specify the context of the listener (object the this keyword will point to).
