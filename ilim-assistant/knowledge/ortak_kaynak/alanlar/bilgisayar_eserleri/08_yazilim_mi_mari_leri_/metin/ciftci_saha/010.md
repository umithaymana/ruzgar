Instantaneous values are useful for direct comparison with local measurements. However, for energy calculations or model evaluations, backward-averaged (preceding hour) data is preferred. By default, the Open-Meteo API provides backward-averaged solar radiation to simplify energy calculations. uv_index uv_index_clear_sky Preceding hour mean Index UV index starting from 0 as average of the preceding hour. uv_index_clear_sky assumes cloud free conditions.
