Download XLSX Download CSV API URL ( Open in new tab , copy this URL into your application, or paste an API URL to restore its settings) Data Sources This API uses global Météo-France ARPEGE weather forecast and combines them with high-resolution AROME forecasts. AROME is a 1.5 km high resolution model covering France and neighboring areas. For other locations, only ARPEGE is used. For ARPEGE, values are interpolated from 3 or 6-hourly to 1-hourly values after 72 or 96 hours respectively. * AROME France HD has the same model area, but at higher resolution with a smaller selection of weather variables. You can find the update timings in the model updates documentation .
