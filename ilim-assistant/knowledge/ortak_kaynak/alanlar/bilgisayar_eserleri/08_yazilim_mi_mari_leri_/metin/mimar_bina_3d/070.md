Tags for only the building facades under the roof Key Comment building:levels =&#42; Number of floors of the building above ground (without levels in the roof). Allows you to texturize the building in a simple way because some 3D renderings add rows of windows for each floor. If you tag new buildings, try to give a height value . Try to use building:levels =&#42; only in addition to a height tag! See the section below for a good understanding of this tag and the usage of height =&#42; , roof:height =&#42; and roof:levels =&#42; . building:min_level =&#42; Levels skipped in a building part, analogous to min_height building:material =&#42; Outer material for the building façades. building:colour =&#42; Colour of the building façades. See colour =&#42; for possible values. Note: there is no tag for the height of the facades (no tag building:height ). This value is automatically calculated as the building's total height =&#42; minus roof:height =&#42; . Tags for only the roof of the building Roof shape You can characterize the building roof using a catalogue of well-known roof types. Here are just a few of the most popular roof:shape=* values in no particular order: Image roof:shape flat skillion gabled half-hipped hipped pyramidal Image roof:shape gambrel mansard dome onion round saltbox Not all values of roof:shape =&#42; which are found in the OSM database are standardized as part of Simple 3D Buildings. Additional roof shapes may be introduced later ( S3DB Proposals ), including advanced approaches for manual modelling (e.g., ProposedRoofLines or parts of OSM-4D/Roof table ). Other roof tags Key Comment roof:orientation = along/across For roofs with a ridge the ridge is assumed to be parallel to the longest side of the building ( roof:orientation = along ). But it can be tagged explicitly with this tag. roof:direction =&#42; Direction from back side of roof to front, i.e. the direction towards which the main face of the roof is looking roof:height =&#42; The height of the building (i.e. the height of the façade) is calculated as the building's total height =&#42; minus roof:height =&#42; . roof:levels =&#42; Number of floors within the roof, which are not already counted in building:levels =&#42; . roof:angle =&#42; Alternatively to roof:height =&#42; , roof height can be indicated implicitly by providing the inclination of the sides (in degrees). roof:colour =&#42; The (dominant) colour of the roof. Useful in conjunction with roof:material =&#42; . roof:material =&#42; The outermost material of the roof. Software support Main article: 3D development Many maps and tools support the simple 3D buildings schema. Among the first were the OSM-3D.org renderer in 2009, the OSM2World renderer and Kendzi3D JOSM plugin in 2011, and the Nutiteq Android 3D Mapping SDK (now Carto Mobile SDK ) and WikiMiniAtlas in 2012. OSMBuildings launched a 2.5D display in 2012, followed by a 3D version in 2015. In 2013, F4 Map became the first browser-based renderer to fully support the Simple 3D Buildings schema.
