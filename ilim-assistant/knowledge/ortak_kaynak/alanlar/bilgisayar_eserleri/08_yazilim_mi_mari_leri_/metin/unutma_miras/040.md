Adding to a Nonexistent Target An example target JSON document: { &quot;foo&quot;: &quot;bar&quot; } A JSON Patch document: [ { &quot;op&quot;: &quot;add&quot;, &quot;path&quot;: &quot;/baz/bat&quot;, &quot;value&quot;: &quot;qux&quot; } ] This JSON Patch document, applied to the target JSON document above, would result in an error (therefore, it would not be applied), because the &quot;add&quot; operation&#39;s target location that references neither the root of the document, nor a member of an existing object, nor a member of an existing array. Invalid JSON Patch Document A JSON Patch document: [ { &quot;op&quot;: &quot;add&quot;, &quot;path&quot;: &quot;/baz&quot;, &quot;value&quot;: &quot;qux&quot;, &quot;op&quot;: &quot;remove&quot; } ] This JSON Patch document cannot be treated as an &quot;add&quot; operation, because it contains a later &quot;op&quot;:&quot;remove&quot; element. JSON requires that object member names be unique with a &quot;SHOULD&quot; requirement, and there is no standard error handling for duplicates.
