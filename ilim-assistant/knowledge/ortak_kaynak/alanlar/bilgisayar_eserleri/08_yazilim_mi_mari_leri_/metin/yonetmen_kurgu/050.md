If disabled (the default), any aspect ratio mismatches, including those from e.g. anamorphic video sources, are forwarded to the output pixel aspect ratio. normalize_sar Like reset_sar , but instead of stretching the video content to fill the new output aspect ratio, the content is instead padded or cropped as necessary. Mutually exclusive with fit_mode . Disabled by default. pad_crop_ratio Specifies a ratio (between 0.0 and 1.0 ) between padding and cropping when the input aspect ratio does not match the output aspect ratio and normalize_sar is in effect. The default of 0.0 always pads the content with black borders, while a value of 1.0 always crops off parts of the content. Intermediate values are possible, leading to a mix of the two approaches. sar Force the output sample aspect ratio. The default of 0 derives it from the input, see reset_sar . fit_mode Specify the content fit strategy according to a list of predefined modes. Determines how the input image is to be placed inside the destination crop rectangle (as defined by pos_x/y and pos_w/h ). The names and their implementations are taken from the CSS &rsquo;object-fit&rsquo; property. Note that this option is mutually exclusive with normalize_sar . Defaults to fill . Valid values are: &lsquo; fill &rsquo; Stretch the input to the output rectangle, ignoring aspect ratio mismatches. Note that unless reset_sar is also enabled, the output will still have the correct pixel aspect ratio tagged. &lsquo; contain &rsquo; Scale the input to fit inside the output, preserving aspect ratio by padding. Equivalent to normalize_sar with pad_crop_ratio set to 0.0 . &lsquo; cover &rsquo; Scale the input to fill the output, preserving aspect ratio by cropping. Equivalent to normalize_sar with pad_crop_ratio set to 1.0 . &lsquo; none, place &rsquo; Don&rsquo;t scale the input. The input will be placed inside the output rectangle at its natural size; which may result in additional padding or cropping. &lsquo; scale_down &rsquo; Scale the input down as much as needed to fit inside the output. Equivalent to either contain or none , depending on whether the input is larger than the output or not. fit_sense When fit_mode is in use, this option controls how the fit strategy is applied against the specified output resolution. Mutually exclusive with force_original_aspect_ratio . Valid values are: &lsquo; target &rsquo; The computed output resolution is taken as the exact size of the output frame. This is the default behavior. &lsquo; constraint &rsquo; The computed output resolution is a size reference against which the fit mode is applied, enlarging or decreasing the true frame size as needed to fit the content. fillcolor Set the color used to fill the output area not covered by the output image, for example as a result of normalize_sar . For the general syntax of this option, check the &quot;Color&quot; section in the ffmpeg-utils manual . Defaults to black@0 . corner_rounding Render frames with rounded corners. The value, given as a float ranging from 0.0 to 1.0 , indicates the relative degree of rounding, from fully square to fully circular.
