This filter accepts the following options: fps Specify the output frame rate. This can be rational e.g. 60000/1001 . Frames are dropped if fps is lower than source fps. Default 60 . mi_mode Motion interpolation mode. Following values are accepted: &lsquo; dup &rsquo; Duplicate previous or next frame for interpolating new ones. &lsquo; blend &rsquo; Blend source frames. Interpolated frame is mean of previous and next frames. &lsquo; mci &rsquo; Motion compensated interpolation. Following options are effective when this mode is selected: &lsquo; mc_mode &rsquo; Motion compensation mode. Following values are accepted: &lsquo; obmc &rsquo; Overlapped block motion compensation. &lsquo; aobmc &rsquo; Adaptive overlapped block motion compensation. Window weighting coefficients are controlled adaptively according to the reliabilities of the neighboring motion vectors to reduce oversmoothing. Default mode is &lsquo; obmc &rsquo;. &lsquo; me_mode &rsquo; Motion estimation mode. Following values are accepted: &lsquo; bidir &rsquo; Bidirectional motion estimation. Motion vectors are estimated for each source frame in both forward and backward directions. &lsquo; bilat &rsquo; Bilateral motion estimation. Motion vectors are estimated directly for interpolated frame. Default mode is &lsquo; bilat &rsquo;. &lsquo; me &rsquo; The algorithm to be used for motion estimation. Following values are accepted: &lsquo; esa &rsquo; Exhaustive search algorithm. &lsquo; tss &rsquo; Three step search algorithm. &lsquo; tdls &rsquo; Two dimensional logarithmic search algorithm. &lsquo; ntss &rsquo; New three step search algorithm. &lsquo; fss &rsquo; Four step search algorithm. &lsquo; ds &rsquo; Diamond search algorithm. &lsquo; hexbs &rsquo; Hexagon-based search algorithm. &lsquo; epzs &rsquo; Enhanced predictive zonal search algorithm. &lsquo; umh &rsquo; Uneven multi-hexagon search algorithm. Default algorithm is &lsquo; epzs &rsquo;. &lsquo; mb_size &rsquo; Macroblock size. Default 16 . &lsquo; search_param &rsquo; Motion estimation search parameter. Default 32 . &lsquo; vsbmc &rsquo; Enable variable-size block motion compensation. Motion estimation is applied with smaller block sizes at object boundaries in order to make them less blurry. Default is 0 (disabled). scd Scene change detection method. Scene change leads motion vectors to be in random direction. Scene change detection replace interpolated frames by duplicate ones. May not be needed for other modes. Following values are accepted: &lsquo; none &rsquo; Disable scene change detection. &lsquo; fdiff &rsquo; Frame difference. Corresponding pixel values are compared and if it satisfies scd_threshold scene change is detected. Default method is &lsquo; fdiff &rsquo;. scd_threshold Scene change detection threshold.
