Judder can be introduced, for instance, by pullup filter. If the original source was partially telecined content then the output of pullup,dejudder will have a variable frame rate. May change the recorded frame rate of the container. Aside from that change, this filter will not affect constant frame rate video. The option available in this filter is: cycle Specify the length of the window over which the judder repeats. Accepts any integer greater than 1. Useful values are: &lsquo; 4 &rsquo; If the original was telecined from 24 to 30 fps (Film to NTSC). &lsquo; 5 &rsquo; If the original was telecined from 25 to 30 fps (PAL to NTSC). &lsquo; 20 &rsquo; If a mixture of the two. The default is &lsquo; 4 &rsquo;. 11.63 delogo # TOC Suppress a TV station logo by a simple interpolation of the surrounding pixels. This filter helps remove camera shake from hand-holding a camera, bumping a tripod, moving on a vehicle, etc. The filter accepts the following options: x y w h Specify a rectangular area where to limit the search for motion vectors. If desired the search for motion vectors can be limited to a rectangular area of the frame defined by its top left corner, width and height. These parameters have the same meaning as the drawbox filter which can be used to visualise the position of the bounding box. This is useful when simultaneous movement of subjects within the frame might be confused for camera motion by the motion vector search. If any or all of x , y , w and h are set to -1 then the full frame is used. This allows later options to be set without specifying the bounding box for the motion vector search. Default - search the whole frame. rx ry Specify the maximum extent of movement in x and y directions in the range 0-64 pixels. Default 16. edge Specify how to generate pixels to fill blanks at the edge of the frame. Available values are: &lsquo; blank, 0 &rsquo; Fill zeroes at blank locations &lsquo; original, 1 &rsquo; Original image at blank locations &lsquo; clamp, 2 &rsquo; Extruded edge value at blank locations &lsquo; mirror, 3 &rsquo; Mirrored edge at blank locations Default value is &lsquo; mirror &rsquo;. blocksize Specify the blocksize to use for motion search. Range 4-128 pixels, default 8. contrast Specify the contrast threshold for blocks. Only blocks with more than the specified contrast (difference between darkest and lightest pixels) will be considered. Range 1-255, default 125. search Specify the search strategy. Available values are: &lsquo; exhaustive, 0 &rsquo; Set exhaustive search &lsquo; less, 1 &rsquo; Set less exhaustive search. Default value is &lsquo; exhaustive &rsquo;. filename If set then a detailed log of the motion search is written to the specified file. 11.66 despill # TOC Remove unwanted contamination of foreground colors, caused by reflected color of greenscreen or bluescreen.
