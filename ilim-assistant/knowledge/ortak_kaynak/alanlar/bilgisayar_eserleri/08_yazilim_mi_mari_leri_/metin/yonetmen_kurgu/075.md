Default value is 0. 11.287 w3fdif # TOC Deinterlace the input video (&quot;w3fdif&quot; stands for &quot;Weston 3 Field Deinterlacing Filter&quot;). Based on the process described by Martin Weston for BBC R&amp;D, and implemented based on the de-interlace algorithm written by Jim Easterbrook for BBC R&amp;D, the Weston 3 field deinterlacing filter uses filter coefficients calculated by BBC R&amp;D. This filter uses field-dominance information in frame to decide which of each pair of fields to place first in the output. If it gets it wrong use setfield filter before w3fdif filter. There are two sets of filter coefficients, so called &quot;simple&quot; and &quot;complex&quot;. Which set of filter coefficients is used can be set by passing an optional parameter: filter Set the interlacing filter coefficients. Accepts one of the following values: &lsquo; simple &rsquo; Simple filter coefficient set. &lsquo; complex &rsquo; More-complex filter coefficient set. Default value is &lsquo; complex &rsquo;. mode The interlacing mode to adopt. It accepts one of the following values: frame Output one frame for each frame. field Output one frame for each field. The default value is field . parity The picture field parity assumed for the input interlaced video. It accepts one of the following values: tff Assume the top field is first. bff Assume the bottom field is first. auto Enable automatic detection of field parity. The default value is auto . If the interlacing is unknown or the decoder does not export this information, top field first will be assumed. deint Specify which frames to deinterlace. Accepts one of the following values: &lsquo; all &rsquo; Deinterlace all frames, &lsquo; interlaced &rsquo; Only deinterlace frames marked as interlaced. Default value is &lsquo; all &rsquo;. 11.287.1 Commands # TOC This filter supports same commands as options. 11.288 waveform # TOC Video waveform monitor. The waveform monitor plots color component intensity. By default luma only. Each column of the waveform corresponds to a column of pixels in the source video. It accepts the following options: mode, m Can be either row , or column . Default is column . In row mode, the graph on the left side represents color component value 0 and the right side represents value = 255. In column mode, the top side represents color component value = 0 and bottom side represents value = 255. intensity, i Set intensity. Smaller values are useful to find out how many values of the same luminance are distributed across input rows/columns. Default value is 0.04 . Allowed range is [0, 1]. mirror, r Set mirroring mode. 0 means unmirrored, 1 means mirrored. In mirrored mode, higher values will be represented on the left side for row mode and at the top for column mode. Default is 1 (mirrored). display, d Set display mode. It accepts the following values: &lsquo; overlay &rsquo; Presents information identical to that in the parade , except that the graphs representing color components are superimposed directly over one another. This display mode makes it easier to spot relative differences or similarities in overlapping areas of the color components that are supposed to be identical, such as neutral whites, grays, or blacks. &lsquo; stack &rsquo; Display separate graph for the color components side by side in row mode or one below the other in column mode. &lsquo; parade &rsquo; Display separate graph for the color components side by side in column mode or one below the other in row mode. Using this display mode makes it easy to spot color casts in the highlights and shadows of an image, by comparing the contours of the top and the bottom graphs of each waveform. Since whites, grays, and blacks are characterized by exactly equal amounts of red, green, and blue, neutral areas of the picture should display three waveforms of roughly equal width/height. If not, the correction is easy to perform by making level adjustments the three waveforms. Default is stack . components, c Set which color components to display. Default is 1, which means only luma or red color component if input is in RGB colorspace. If is set for example to 7 it will display all 3 (if) available color components. envelope, e &lsquo; none &rsquo; No envelope, this is default. &lsquo; instant &rsquo; Instant envelope, minimum and maximum values presented in graph will be easily visible even with small step value. &lsquo; peak &rsquo; Hold minimum and maximum values presented in graph across time. This way you can still spot out of range values without constantly looking at waveforms. &lsquo; peak+instant &rsquo; Peak and instant envelope combined together. filter, f &lsquo; lowpass &rsquo; No filtering, this is default. &lsquo; flat &rsquo; Luma and chroma combined together. &lsquo; aflat &rsquo; Similar as above, but shows difference between blue and red chroma. &lsquo; xflat &rsquo; Similar as above, but use different colors. &lsquo; yflat &rsquo; Similar as above, but again with different colors. &lsquo; chroma &rsquo; Displays only chroma. &lsquo; color &rsquo; Displays actual color value on waveform. &lsquo; acolor &rsquo; Similar as above, but with luma showing frequency of chroma values. graticule, g Set which graticule to display. &lsquo; none &rsquo; Do not display graticule. &lsquo; green &rsquo; Display green graticule showing legal broadcast ranges. &lsquo; orange &rsquo; Display orange graticule showing legal broadcast ranges. &lsquo; invert &rsquo; Display invert graticule showing legal broadcast ranges. opacity, o Set graticule opacity. flags, fl Set graticule flags. &lsquo; numbers &rsquo; Draw numbers above lines. By default enabled. &lsquo; dots &rsquo; Draw dots instead of lines. scale, s Set scale used for displaying graticule. &lsquo; digital &rsquo; &lsquo; millivolts &rsquo; &lsquo; ire &rsquo; Default is digital. bgopacity, b Set background opacity. tint0, t0 tint1, t1 Set tint for output. Only used with lowpass filter and when display is not overlay and input pixel formats are not RGB. fitmode, fm Set sample aspect ratio of video output frames. Can be used to configure waveform so it is not stretched too much in one of directions. &lsquo; none &rsquo; Set sample aspect ration to 1/1. &lsquo; size &rsquo; Set sample aspect ratio to match input size of video Default is &lsquo; none &rsquo;. input Set input formats for filter to pick from. Can be &lsquo; all &rsquo;, for selecting from all available formats, or &lsquo; first &rsquo;, for selecting first available format.
