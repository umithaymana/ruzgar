The filter accepts the following options: angle, a Set lens angle expression as a number of radians. The value is clipped in the [0,PI/2] range. Default value: &quot;PI/5&quot; x0 y0 Set center coordinates expressions. Respectively &quot;w/2&quot; and &quot;h/2&quot; by default. mode Set forward/backward mode. Available modes are: &lsquo; forward &rsquo; The larger the distance from the central point, the darker the image becomes. &lsquo; backward &rsquo; The larger the distance from the central point, the brighter the image becomes. This can be used to reverse a vignette effect, though there is no automatic detection to extract the lens angle and other settings (yet). It can also be used to create a burning effect. &lsquo; wavelet &rsquo; Like &lsquo; backward &rsquo;, but the noise amplified in the dark areas is suppressed in a 9/7 wavelet domain, undecimated by default: detail coefficients are shrunk toward 0 according to the local attenuation and the noise level, while the low frequencies, which average over larger areas, are kept. It needs about 150 bytes of memory per pixel. Default value is &lsquo; forward &rsquo;. noise Set the standard deviation of the input noise in 8-bit levels, used by the &lsquo; wavelet &rsquo; mode. Quantization alone contributes about 0.3-0.4. Default is 0.5 . decimated Use a decimated instead of an undecimated wavelet transform in the &lsquo; wavelet &rsquo; mode. Several times faster and needs about 20 bytes of memory per pixel, the result has slightly more artifacts. Default is 0 . eval Set evaluation mode for the expressions ( angle , x0 , y0 ). It accepts the following values: &lsquo; init &rsquo; Evaluate expressions only once during the filter initialization. &lsquo; frame &rsquo; Evaluate expressions for each incoming frame. This is way slower than the &lsquo; init &rsquo; mode since it requires all the scalers to be re-computed, but it allows advanced dynamic expressions. Default value is &lsquo; init &rsquo;. dither Set dithering to reduce the circular banding effects. Default is 1 (enabled). aspect Set vignette aspect. This setting allows one to adjust the shape of the vignette. Setting this value to the SAR of the input will make a rectangular vignetting following the dimensions of the video. Default value is 0. 11.287 w3fdif # TOC Deinterlace the input video (&quot;w3fdif&quot; stands for &quot;Weston 3 Field Deinterlacing Filter&quot;). Based on the process described by Martin Weston for BBC R&amp;D, and implemented based on the de-interlace algorithm written by Jim Easterbrook for BBC R&amp;D, the Weston 3 field deinterlacing filter uses filter coefficients calculated by BBC R&amp;D. This filter uses field-dominance information in frame to decide which of each pair of fields to place first in the output. If it gets it wrong use setfield filter before w3fdif filter. There are two sets of filter coefficients, so called &quot;simple&quot; and &quot;complex&quot;. Which set of filter coefficients is used can be set by passing an optional parameter: filter Set the interlacing filter coefficients. Accepts one of the following values: &lsquo; simple &rsquo; Simple filter coefficient set. &lsquo; complex &rsquo; More-complex filter coefficient set. Default value is &lsquo; complex &rsquo;. mode The interlacing mode to adopt. It accepts one of the following values: frame Output one frame for each frame. field Output one frame for each field. The default value is field . parity The picture field parity assumed for the input interlaced video. It accepts one of the following values: tff Assume the top field is first. bff Assume the bottom field is first. auto Enable automatic detection of field parity. The default value is auto . If the interlacing is unknown or the decoder does not export this information, top field first will be assumed. deint Specify which frames to deinterlace. Accepts one of the following values: &lsquo; all &rsquo; Deinterlace all frames, &lsquo; interlaced &rsquo; Only deinterlace frames marked as interlaced.
