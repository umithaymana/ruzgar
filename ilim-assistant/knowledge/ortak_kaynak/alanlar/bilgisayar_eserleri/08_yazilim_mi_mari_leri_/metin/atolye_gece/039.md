That is negative values are earlier in the file, 0 is at EOF. -isync input_index ( input ) Assign an input as a sync source. This will take the difference between the start times of the target and reference inputs and offset the timestamps of the target file by that difference. The source timestamps of the two inputs should derive from the same clock source for expected results. If copyts is set then start_at_zero must also be set. If either of the inputs has no starting timestamp then no sync adjustment is made. Acceptable values are those that refer to a valid ffmpeg input index. If the sync reference is the target index itself or -1 , then no adjustment is made to target timestamps. A sync reference may not itself be synced to any other input. Default value is -1 . -itsoffset offset ( input ) Set the input time offset. offset must be a time duration specification, see the Time duration section in the ffmpeg-utils(1) manual . The offset is added to the timestamps of the input files. Specifying a positive offset means that the corresponding streams are delayed by the time duration specified in offset . -itsscale scale ( input,per-stream ) Rescale input timestamps. scale should be a floating point number. -timestamp date ( output ) Set the recording timestamp in the container. date must be a date specification, see the Date section in the ffmpeg-utils(1) manual . -metadata[:metadata_specifier] key = value ( output,per-metadata ) Set a metadata key/value pair. It is also possible to delete metadata by using an empty value. For example, for setting the title in the output file: ffmpeg -i in.avi -metadata title=&quot;my title&quot; out.flv To set the language of the first audio stream: ffmpeg -i INPUT -metadata:s:a:0 language=eng OUTPUT -keep_metadata[: metadata_specifier ] key ( output,per-metadata ) When re-encoding a stream, certain metadata keys that are likely to become stale (such as iTunSMPB or encoded_by ) are automatically discarded. This option prevents a specific key from being discarded, preserving its original value from the input. Without a specifier, the key is preserved in all metadata contexts (format and streams). Use g to restrict to format (global) metadata, or s with an optional stream specifier to restrict to matching streams only. For example, to keep iTunSMPB in format metadata only when re-encoding: ffmpeg -i in.mp3 -keep_metadata:g iTunSMPB out.mp3 To keep NUMBER_OF_BYTES only for the video stream: ffmpeg -i in.mkv -keep_metadata:s:v NUMBER_OF_BYTES out.mkv Some keys are stored in the metadata with a suffix (e.g. NUMBER_OF_BYTES-eng ). Specifying the unsuffixed family name (e.g. NUMBER_OF_BYTES ) keeps all variants. To keep only a specific one, specify the full key explicitly: ffmpeg -i in.mkv -keep_metadata:s:v NUMBER_OF_BYTES-eng out.mkv Some (such as major_brand , minor_version , and compatible_brands ) are always removed regardless of re-encoding, because they describe the source container and are meaningless in the output. -keep_metadata applies to those keys even when stream-copying. Re-encoding-only keys (such as encoder tags and Matroska stream statistics) are removed from a stream&rsquo;s metadata only when that stream is being re-encoded, and from format metadata only when at least one audio or video stream is re-encoded. Only format and stream metadata are filtered. Chapter and program metadata are never modified by this mechanism. -disposition[:stream_specifier] value ( output,per-stream ) Sets the disposition flags for a stream. Default value: by default, all disposition flags are copied from the input stream, unless the output stream this option applies to is fed by a complex filtergraph - in that case no disposition flags are set by default. value is a sequence of disposition flags separated by &rsquo;+&rsquo; or &rsquo;-&rsquo;. A &rsquo;+&rsquo; prefix adds the given disposition, &rsquo;-&rsquo; removes it. If the first flag is also prefixed with &rsquo;+&rsquo; or &rsquo;-&rsquo;, the resulting disposition is the default value updated by value . If the first flag is not prefixed, the resulting disposition is value . It is also possible to clear the disposition by setting it to 0. If no -disposition options were specified for an output file, ffmpeg will automatically set the &rsquo;default&rsquo; disposition flag on the first stream of each type, when there are multiple streams of this type in the output file and no stream of that type is already marked as default. The -dispositions option lists the known disposition flags. For example, to make the second audio stream the default stream: ffmpeg -i in.mkv -c copy -disposition:a:1 default out.mkv To make the second subtitle stream the default stream and remove the default disposition from the first subtitle stream: ffmpeg -i in.mkv -c copy -disposition:s:0 0 -disposition:s:1 default out.mkv To add an embedded cover/thumbnail: ffmpeg -i in.mp4 -i IMAGE -map 0 -map 1 -c copy -c:v:1 png -disposition:v:1 attached_pic out.mp4 To add the &rsquo;original&rsquo;
