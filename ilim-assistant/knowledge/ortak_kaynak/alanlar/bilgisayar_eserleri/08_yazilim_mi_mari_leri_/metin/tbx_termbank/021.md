ISO-24633-Resources &#8211; Introduction to TermBase eXchange (TBX) Skip to content Introduction to TermBase eXchange (TBX) ISO-24633-Resources ISO 24633 describes the structure and process for validating a TBX core file and RNG and Schematron schema structures. The following downloads are resources for anyone creating a validation schema. Accessible at the ISO Standards Maintenance Portal is a series of UML diagrams (as PDF files) that starts with low-level representation of the TBX core attributes and goes up to a high-level data model of a TBX schema. There are diagrams for the following concepts: 1. Attribute classes 2. Elements (excluding children) 3. Element entities 4. Parent-child relationships in the element entities 5. High-level data model: The UML diagrams used as examples are not the only ones that could be used in creating an RNG schema for TBX Core, but are cited in order to provide practical orientation.
