TBX Elements Reference &#8211; Introduction to TermBase eXchange (TBX) Skip to content Introduction to TermBase eXchange (TBX) TBX Elements Reference This page lists all TBX elements as given in the TBX core RNG schema (https://github.com/LTAC-Global/TBX_Core_RNG). The format of this page is patterned after the HTML elements reference created by Mozilla as part of the MDN web docs. Descriptions given here are purely informative and are not authoritative. Namespace All core elements must be in the namespace &#8216; urn:iso:std:iso:30042:ed-2 &#8216;. This namespace is for TBX version 2, even though it is only the second edition from the perspective of ISO. TBX version 1 was published by the now defunct LISA (Localization Industry Standards Association). Note that in XML, a default namespace is only required on the root element (where a default namespace exists). Descendants of the root element will inherit the default namespace. In DCT, data categories used as element names come from the namespace of the module from which that data category is imported ( i.e. , &lt;partOfSpeech&gt; have the namespace of the Min module , if imported from Min). Root Element Element Description &lt;tbx&gt; The TBX &lt;tbx&gt; element is the root element of tbx files. Entity Elements Entities are logical groupings of elements which often occur together as permitted children. Elements may belong to more than one entity. *Note, the inline markup elements are also entity elements, but they have been separated due to their unique relationship with XLIFF. Element Entity Grouping(s) Description &lt;admin&gt; auxInfo, noteLinkInfo The TBX &lt;admin&gt; element contains administrative information about the content of the element to which it refers ( e.g. , a &lt;term&gt; or a &lt;note&gt;, etc.). &lt;adminGrp&gt; auxInfo, noteLinkInfo The TBX &lt;adminGrp&gt; element is a container for an &lt;admin&gt; element and supplementary information about that &lt;admin&gt; element. &lt;descrip&gt; auxInfo The TBX &lt;descrip&gt; element contains descriptive information about the content of the element to which it refers ( e.g. , &lt;term&gt;). &lt;descripGrp&gt; auxInfo The TBX &lt;descripGrp&gt; element is a container for an &lt;admin&gt; element and supplementary information about that &lt;descrip&gt; element. &lt;foreign&gt; noteText The TBX &lt;foreign&gt; element contains a text value. &lt;hi&gt; basicText, noteText The TBX &lt;hi&gt; element is an inline markup element which can be used to indicate highlighting. &lt;note&gt; auxInfo, noteLinkInfo The TBX &lt;note&gt; element is used for notes. In some cases of converting from one dialect of TBX to another dialect which lacks support for certain data categories, it has become best practice to store the unsupported data category information in a note. In such scenarios, the name of the data category appears at the beginning of a note, followed by two colon characters, followed by the text content of that data category. This facilitates more accurate backward conversion from the latter TBX document to the former (should it be necessary). Example: &lt;note&gt;partOfSpeech::noun&lt;/note&gt; &lt;ref&gt; auxInfo, noteLinkInfo The TBX &lt;ref&gt; element is used to reference other elements within the TBX document. &lt;transacGrp&gt; auxInfo, noteLinkInfo The TBX &lt;transacGrp&gt; element is a container for a &lt;transac&gt; element and supplementary information about that &lt;transac&gt; element. &lt;xref&gt; auxInfo, noteLinkInfo The TBX &lt;xref&gt; element is used to reference information external to the TBX document via URI. Inline Markup Elements From XLIFF 2.0 Most inline markup elements in TBX v3 have been changed to be compliant with practices in XLIFF 2.0 (see Summary of Changes in ISO 30042 ). While they are defined as in XLIFF, in TBX they still maintain the TBX namespace and may not support all attributes. element contains note information specific to an &lt;admin&gt; element. &lt;back&gt; The TBX &lt;back&gt; element is the root element for the back matter section of a TBX document. &lt;body&gt; The TBX &lt;body&gt; element is the root element for the body section of a TBX document and contains all of the &lt;conceptEntry&gt; elements of the TBX document. &lt;change&gt; The TBX &lt;change&gt; element contains one or more &lt;p&gt; elements which detail changes made to the TBX document (or the termbase from which it was exported). &lt;conceptEntry&gt; The TBX &lt;conceptEntry&gt; is a container for concept level information, including all &lt;langSec&gt; elements belonging to that concept. &lt;date&gt; The TBX &lt;date&gt; element contains a date according to xs:date . &lt;descripNote&gt; The TBX &lt;descripNote&gt; element contains note information speicific to a &lt;descrip&gt; element. &lt;encodingDesc&gt; The TBX &lt;encodingDesc&gt; element originally contained information about an XCS file (see Introduction to TermBase eXchange ). &lt;fileDesc&gt; The TBX &lt;fileDesc&gt; element contains information about the TBX document itself, including its title, publication information, and origins. &lt;item&gt; The TBX &lt;item&gt; element contains back matter text which is supplemental to the terminological information found within the TBX document. &lt;itemGrp&gt; The TBX &lt;itemGrp&gt; element is a container for the &lt;item&gt; element when it is accompanied by supplementary information (such as an &lt;admin&gt; entry). &lt;itemSet&gt; The TBX &lt;itemSet&gt; element is a container for any instances of &lt;item&gt; and/or &lt;itemGrp&gt; which are related to one another. &lt;langSec&gt; The TBX &lt;langSec&gt; element is a container for language level information, including all &lt;termSec&gt; elements belonging to that language (within the same terminological concept). &lt;note&gt; The TBX &lt;note&gt; element contains note text which provides usually provides information about either its parent element, or its sibling element(s). In some cases to prevent data loss in conversion, it has become best practice to store the contents of unsupported data categories as &lt;note&gt; elements using the following convention: &lt;note&gt;[DC-Name]::[DC-Content]&lt;/note&gt; Example: &lt;note&gt;partOfSpeech::noun&lt;/note&gt; &lt;p&gt; The TBX &lt;p&gt; element contains text content and inline markup. The subject of the content may differ depending on the parent of the &lt;p&gt; element. &lt;publicationStmt&gt; The TBX &lt;publicationStmt&gt; element contains publication information about the TBX document. &lt;refObject&gt; The TBX &lt;refObject&gt; element is a grouping container for related &lt;item&gt;, &lt;itemGrp&gt;, and &lt;itemSet&gt; elements in the back mater. &lt;refObjectSec&gt; The TBX &lt;refObjectSec&gt; element is a container for all &lt;refObject&gt; elments in the TBX document. &lt;revisionDesc&gt; The TBX &lt;revisionDesc&gt; element is a container for a list of &lt;change&gt; elements, which records the changes which have been made to the TBX document (or the termbase from which it was exported). &lt;sourceDesc&gt; The TBX &lt;sourceDesc&gt; element contains information about the origins of a TBX document. &lt;tbxHeader&gt; The TBX &lt;tbxHeader&gt; element is the root element for TBX header information. &lt;term&gt; The TBX &lt;term&gt; element contains a single term. &lt;termNote&gt; The TBX &lt;termNote&gt; element contains note information specific to a &lt;termNote&gt; element. &lt;termNoteGrp&gt; The TBX &lt;termNoteGrp&gt; element contains a single &lt;termNote&gt; element and any supplementary information about that &lt;termNote&gt; element. &lt;termSec&gt; The TBX &lt;termSec&gt; element is a container for term level information, including a single &lt;term&gt; any other elements which provide more information or context about that term. &lt;text&gt; The TBX &lt;text&gt; element is a structural container for either &lt;body&gt; and/or &lt;back&gt;. &lt;title&gt; The TBX &lt;title&gt; element contains a title for the TBX document (or the termbase from which it was exported). &lt;titleStmt&gt; The TBX &lt;titleStmt&gt; element is a container for the &lt;title&gt; element and any &lt;note&gt; elements that may be relevant. &lt;tbxHeader&gt; The TBX &lt;tbxHeader&gt; element is a structural container for information about the TBX file. &lt;transac&gt; The TBX &lt;transac&gt; element is a container for transactional information (the exact information depends on the data category associated with the &lt;transac&gt; element). &lt;transacNote&gt; The TBX &lt;transacNote&gt; element contains note information specific to a &lt;transacNote&gt; element.
