Desruisseaux Standards Track [Page 166] RFC 5545 iCalendar September 2009 Appendix A . Differences from RFC 2445 This appendix contains a list of changes that have been made in the Internet Calendaring and Scheduling Core Object Specification from RFC 2445 . A.1 . New Restrictions 1. The &quot;DTSTART&quot; property SHOULD be synchronized with the recurrence rule, if specified. 2. The &quot;RRULE&quot; property SHOULD NOT occur more than once in a component. 3. The BYHOUR, BYMINUTE, and BYSECOND rule parts MUST NOT be specified in the &quot;RRULE&quot; property when the &quot;DTSTART&quot; property is specified as a DATE value. 4. The value type of the &quot;DTEND&quot; or &quot;DUE&quot; properties MUST match the value type of &quot;DTSTART&quot; property. 5. The &quot;DURATION&quot; property can no longer appear in &quot;VFREEBUSY&quot; components. A.2 . Restrictions Removed 1. The &quot;DTSTART&quot; and &quot;DTEND&quot; properties are no longer required to be specified as date with local time and time zone reference when used with a recurrence rule. A.3 . Deprecated Features 1. The &quot;EXRULE&quot; property can no longer be specified in a component. 2. The &quot;THISANDPRIOR&quot; value can no longer be used with the &quot;RANGE&quot; parameter. 3. The &quot;PROCEDURE&quot; value can no longer be used with the &quot;ACTION&quot; property. 4. The value type RECUR no longer allows multiple values to be specified by a COMMA-separated list of values. 5. x-name rule parts can no longer be specified in properties of RECUR value type (e.g., &quot;RRULE&quot;). x-param can be used on RECUR value type properties instead.
