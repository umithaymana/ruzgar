Bad RECURRENCE-ID Component instances are identified by the combination of &quot;UID&quot;, &quot;RECURRENCE-ID&quot;, and &quot;SEQUENCE&quot;. When an &quot;Organizer&quot; sends an iTIP message to an &quot;Attendee&quot;, there are three cases in which an instance cannot be found. They are: 1. The component with the referenced &quot;UID&quot; and &quot;RECURRENCE-ID&quot; has been found but the &quot;SEQUENCE&quot; number in the calendar store does not match that of the iTIP message. 2. The component with the referenced &quot;UID&quot; has been found, the &quot;SEQUENCE&quot; numbers match, but the &quot;RECURRENCE-ID&quot; cannot be found. 3. The &quot;UID&quot; and &quot;SEQUENCE&quot; numbers are found but the CUA does not support recurrences. In case (1), two things can happen. If the &quot;SEQUENCE&quot; number of the &quot;Attendee&#x27;s&quot; instance is larger than that in the &quot;Organizer&#x27;s&quot; message, then the &quot;Attendee&quot; is receiving an out-of-sequence message and MUST ignore it. If the &quot;SEQUENCE&quot; number of the &quot;Attendee&#x27;s&quot; instance is smaller, then the &quot;Organizer&quot; is sending out a newer Daboo Standards Track [Page 114] RFC 5546 iTIP December 2009 version of the component and the &quot;Attendee&#x27;s&quot; version needs to be updated. Since one or more updates have been missed, the &quot;Attendee&quot; SHOULD send a &quot;REFRESH&quot; message to the &quot;Organizer&quot; to get an updated version of the event. In case (2), something has gone wrong. Both the &quot;Organizer&quot; and the &quot;Attendee&quot; should have the same instances, but the &quot;Attendee&quot; does not have the referenced instance. In this case, the &quot;Attendee&quot; SHOULD send a &quot;REFRESH&quot; to the &quot;Organizer&quot; to get an updated version of the event. In case (3), the limitations of the &quot;Attendee&#x27;s&quot; CUA makes it impossible to match an instance other than the single instance scheduled. In this case, the &quot;Attendee&quot; need not send a &quot;REFRESH&quot; to the &quot;Organizer&quot;.
