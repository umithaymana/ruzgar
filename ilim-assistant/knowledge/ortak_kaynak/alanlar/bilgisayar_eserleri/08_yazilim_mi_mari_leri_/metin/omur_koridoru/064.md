Priority Property Name: PRIORITY Purpose: This property defines the relative priority for a calendar component. Value Type: INTEGER Property Parameters: IANA and non-standard property parameters can be specified on this property. Conformance: This property can be specified in &quot;VEVENT&quot; and &quot;VTODO&quot; calendar components. Description: This priority is specified as an integer in the range 0 to 9. A value of 0 specifies an undefined priority. A value of 1 is the highest priority. A value of 2 is the second highest priority. Subsequent numbers specify a decreasing ordinal priority. A value of 9 is the lowest priority. A CUA with a three-level priority scheme of &quot;HIGH&quot;, &quot;MEDIUM&quot;, and &quot;LOW&quot; is mapped into this property such that a property value in the range of 1 to 4 specifies &quot;HIGH&quot; priority. A value of 5 is the normal or &quot;MEDIUM&quot; priority. A value in the range of 6 to 9 is &quot;LOW&quot; priority. Desruisseaux Standards Track [Page 89] RFC 5545 iCalendar September 2009 A CUA with a priority schema of &quot;A1&quot;, &quot;A2&quot;, &quot;A3&quot;, &quot;B1&quot;, &quot;B2&quot;, ..., &quot;C3&quot; is mapped into this property such that a property value of 1 specifies &quot;A1&quot;, a property value of 2 specifies &quot;A2&quot;, a property value of 3 specifies &quot;A3&quot;, and so forth up to a property value of 9 specifies &quot;C3&quot;. Other integer values are reserved for future use. Within a &quot;VEVENT&quot; calendar component, this property specifies a priority for the event. This property may be useful when more than one event is scheduled for a given time period. Within a &quot;VTODO&quot; calendar component, this property specified a priority for the to-do. This property is useful in prioritizing multiple action items for a given time period.
