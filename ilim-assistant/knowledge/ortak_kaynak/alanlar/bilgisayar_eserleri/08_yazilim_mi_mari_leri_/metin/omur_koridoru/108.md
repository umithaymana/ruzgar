Link Relation Other representations [ edit ] xCal is an XML representation of iCalendar data, as defined in RFC 6321 . jCal is a JSON representation of iCalendar data, as defined in RFC 7265 . hCalendar is an (x)HTML representation of a subset of iCalendar data using microformats . hEvent is an HTML representation of a subset of iCalendar data using microformats addressing some accessibility concerns with the hCalendar format.
