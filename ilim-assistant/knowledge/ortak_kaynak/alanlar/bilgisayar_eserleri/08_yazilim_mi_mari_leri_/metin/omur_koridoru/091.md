Extension Tokens To make iCalendar objects extensible, new component, property, or property parameters can be used. Two types of extensions are defined by [ RFC5545 ]: IANA-registered tokens (&quot;iana-token&quot;) and experimental use tokens (&quot;x-name&quot;). A client SHOULD save &quot;iana-token&#x27;s&quot; and MAY use them in replies. A client MAY save &quot;x-name&#x27;s&quot; and MAY use them in replies. Published Event Examples In the calendaring and scheduling context, publication refers to the one-way transfer of event information. Consumers of published events simply incorporate the event into a calendar. No reply is expected. Individual &quot;A&quot; publishes an event. Individual &quot;B&quot; reads the event and incorporates it into their calendar. Events are published in several ways, including embedding the event as an object in a web page, emailing the event to a distribution list, or posting the event to a newsgroup.
