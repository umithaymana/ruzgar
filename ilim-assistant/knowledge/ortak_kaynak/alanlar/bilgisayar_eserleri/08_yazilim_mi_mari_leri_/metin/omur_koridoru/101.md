UID Property This specification modifies the definition of the &quot;UID&quot; property to allow it to be defined in an iCalendar object. The following additions are made to the definition of this property, originally specified in Section&nbsp;3.8.4.7 of [RFC5545] . Purpose: This property specifies the persistent, globally unique identifier for the iCalendar object. This can be used, for example, to identify duplicate calendar streams that a client may have been given access to. It can be used in conjunction with the &quot;LAST-MODIFIED&quot; property also specified on the &quot;VCALENDAR&quot; object to identify the most recent version of a calendar. Conformance: This property can be specified once in an iCalendar object. The description of the &quot;UID&quot; property in [ RFC5545 ] contains some recommendations on how the value can be constructed. In particular, it suggests use of host names, IP addresses, and domain names to construct the value. However, this is no longer considered good practice, particularly from a security and privacy standpoint, since use of such values can leak key information about a calendar user or their client and network environment. This specification updates [ RFC5545 ] by stating that &quot;UID&quot; values MUST NOT include any data that might identify a user, host, domain, or any other security- or privacy-sensitive information. It is RECOMMENDED that calendar user agents now generate &quot;UID&quot; values that are hex-encoded random Universally Unique Identifier (UUID) values as defined in Sections 4.4 and 4.5 of [ RFC4122 ]. The following is an example of such a property value: UID:5FC53010-1267-4F8E-BC28-1D7AE55A7C99 Additionally, if calendar user agents choose to use other forms of opaque identifiers for the &quot;UID&quot; value, they MUST have a length less than 255 octets and MUST conform to the &quot;iana-token&quot; ABNF syntax defined in Section&nbsp;3.1 of [RFC5545] . SOURCE Property Property Name: SOURCE Purpose: This property identifies a URI where calendar data can be refreshed from. Value Type: URI -- no default Property Parameters: IANA and non-standard property parameters can be specified on this property. IMAGE Property Property Name: IMAGE Purpose: This property specifies an image associated with the calendar or a calendar component. Value Type: URI or BINARY -- no default. Property Parameters: IANA, non-standard, display, inline encoding, and value data type property parameters can be specified on this property.
