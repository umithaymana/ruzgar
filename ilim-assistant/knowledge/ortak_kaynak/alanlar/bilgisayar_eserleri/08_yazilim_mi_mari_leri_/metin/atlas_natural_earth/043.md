Tooltip Used to display small texts on top of map layers. Usage example If you want to just bind a tooltip to marker: marker. bindTooltip ( "my tooltip text" ). openTooltip (); Path overlays like polylines also have a bindTooltip method. A tooltip can be also standalone: const tooltip = new Tooltip () . setLatLng (latlng) . setContent ( 'Hello world!&lt;br /&gt;This is a nice tooltip.' ) . addTo (map); or const tooltip = new Tooltip (latlng, { content : 'Hello world!&lt;br /&gt;This is a nice tooltip.' }) . addTo (map); Security note. Tooltip string content is rendered as HTML. If your content may include untrusted input (e.g. data from users or external APIs), sanitize it first, or build a DOM element using textContent to render it as plain text: const el = document. createElement ( 'div' ); el.textContent = untrustedString; marker. bindTooltip (el); Note about tooltip offset. Leaflet takes two options in consideration for computing tooltip offsetting: the offset Tooltip option: it defaults to [0, 0], and it&#39;s specific to one tooltip. Add a positive x offset to move the tooltip to the right, and a positive y offset to move it to the bottom. Negatives will move to the left and top. the tooltipAnchor Icon option: this will only be considered for Marker. You should adapt this value if you use a custom icon.
