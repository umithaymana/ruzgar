Built-in handlers Handler Description DragHandler Makes the map draggable with panning inertia ( map.dragging ), enabled by default. Its moved() and moving() methods tell whether the last drag moved the map and whether a drag is in progress. BoxZoomHandler Zooms to a box drawn with Shift-drag ( map.boxZoom ), enabled by default. Rebind keys by changing the static KeyboardHandler.keys object of KeyboardEvent.key values per action. PinchZoomHandler Zooms with a two-finger pinch on touch devices ( map.pinchZoom ), enabled by default. TapHoldHandler Fires a contextmenu event on long tap, which mobile Safari doesn&#39;t fire on its own ( map.tapHold ), enabled by default.
