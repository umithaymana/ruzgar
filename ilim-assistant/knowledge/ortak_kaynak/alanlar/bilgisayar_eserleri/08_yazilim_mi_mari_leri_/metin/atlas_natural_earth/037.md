Map panes Panes are DOM elements used to control the ordering of layers on the map. You can access panes with map.getPane or map.getPanes methods. New panes can be created with the map.createPane method. Every map has the following default panes that differ only in z-index. ZoomOptions Option Type Default Description animate Boolean If not specified, zoom animation will happen if the zoom origin is inside the current view, and if the user prefers reduced motion, only when zooming by at most one level. PanOptions Option Type Default Description animate Boolean If true , panning will always be animated if possible, even if the user prefers reduced motion. If false , it will not animate panning, either resetting the map view if panning more than a screen away, or just setting a new offset for the map pane (except for panBy which always does the latter). If not specified, panning is animated, except for pans longer than half the map size when the user prefers reduced motion. duration Number 0.25 Duration of animated panning, in seconds. easeLinearity Number 0.25 The curvature factor of panning animation easing (third parameter of the Cubic Bezier curve ). 1.0 means linear animation, and the smaller this number, the more bowed the curve. noMoveStart Boolean false If true , panning won&#39;t fire movestart event on start (used internally for panning inertia). originalEvent Event The DOM event that triggered the change, passed on in the move events it fires.
