Usage example import { version } from 'leaflet' ; console. log (version); // "2.0.0", or whatever version is in use Class Class is the base of Evented , Handler , Icon and Control , and through them of almost all of the Leaflet classes documented here. Leaflet classes are plain JavaScript classes: extend them with extends and put setup code in constructor() , after calling super() . Class adds what plugins need on top of that: default options, mixins and constructor hooks. Usage example class MyClass extends Class { constructor ( greeter ) { super (); this .greeter = greeter; } greet ( name ) { alert ( this .greeter + ', ' + name) } } // create instance of MyClass, passing "Hello" to the constructor const a = new MyClass ( "Hello" ); // call greet method, alerting "Hello, World" a. greet ( "World" ); Leaflet 1.x classes used an initialize() method instead of constructor() . Constructing a class that still has an initialize() method throws an error. Options Declare the default options of a class with a static defaultOptions field. They are merged with the default options of the parent class instead of replacing them, which makes managing configuration of objects and default values convenient: class MyClass extends Class { static defaultOptions = { myOption1 : 'foo' , myOption2 : 'bar' }; } class MyChildClass extends MyClass { static defaultOptions = { myOption1 : 'baz' , myOption3 : 5 }; } const a = new MyChildClass (); a.options.myOption1; // 'baz' a.options.myOption2; // 'bar' a.options.myOption3; // 5 Every instance gets its own options object, which inherits from the default options of its class. Changing a default later, like Marker.defaultOptions.riseOnHover = true , affects all instances that don&#39;t set the option themselves. mergeOptions() adds or changes defaults of an existing class without touching the defaults of its parent, which makes it the way to change defaults from a plugin: MyChildClass. mergeOptions ({ myOption4 : true }); There&#39;s also Util.setOptions , a method for conveniently merging options passed to constructor with the defaults defined in the class: class MyClass extends Class { static defaultOptions = { foo : 'bar' , bla : 5 }; constructor ( options ) { super (); Util. setOptions ( this , options); ... } } const a = new MyClass ({ bla : 10 }); a.options; // {foo: 'bar', bla: 10} Note that the options object allows any keys, not just the options defined by the class and its base classes. This means you can use the options object to store application specific information, as long as you avoid keys that are already used by the class in question. Mixins You can add methods and properties from other objects using the include method (such objects are called mixins). An options property of the mixin is merged into the default options of the class: const MyMixin = { foo () { ... }, bar : 5 }; class MyClass extends Class {} MyClass. include (MyMixin); const a = new MyClass (); a. foo (); Constructor hooks If you&#39;re a plugin developer, you often need to add additional initialization code to existing classes (e.g. editing hooks for Polyline ). Leaflet comes with a way to do it easily using the addInitHook method: MyClass. addInitHook ( function () { // ... do something in constructor additionally // e.g. add event listeners, set custom properties etc. }); You can also use the following shortcut when you just need to make one additional method call: MyClass. addInitHook ( 'methodName' , arg1, arg2, …); Hooks added to a class also run for instances of its subclasses, parent class hooks first, and each hook runs once per instance. For Leaflet&#39;s own classes, they run after the constructor has finished, so a hook added to Layer sees a fully built Polygon . For a class of your own that extends a Leaflet class, they run before the constructor body of your class. If other code adds hooks to a class of yours and these hooks need the constructor of your class to have run, mark the class with static initHooks = true and end its constructor with this.callInitHooks() : class MyLayer extends Layer { static initHooks = true ; constructor ( options ) { super (); Util. setOptions ( this , options); this ._items = []; this . callInitHooks (); } } Methods Method Description callInitHooks () Called at the end of the constructor of every class with static initHooks = true . The last of these calls, from the deepest such class, runs all hooks of the chain once, so they see a fully built instance.
