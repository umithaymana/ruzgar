Layer A set of methods from the Layer base class that all Leaflet layers use. Inherits all methods, options and events from Evented . Usage example const layer = new Marker (latlng). addTo (map); layer. addTo (map); layer. remove (); Options Option Type Default Description pane String &#39;overlayPane&#39; By default the layer will be added to the map&#39;s overlay pane . Overriding this option will cause the layer to be placed on another pane by default. Not effective if the renderer option is set (the renderer option will override the pane option). attribution String null String to be shown in the attribution control, e.g. &quot;© OpenStreetMap contributors&quot;. It describes the layer data and is often a legal obligation towards copyright holders and tile providers.
