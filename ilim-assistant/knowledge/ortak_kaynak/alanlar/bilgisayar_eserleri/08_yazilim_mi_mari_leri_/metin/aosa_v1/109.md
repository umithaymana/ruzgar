In practice, this means that whenever the user makes a change in the input box, the JS model will update sheet[col+row] to match the content, and trigger its calc() function to recalculate values of all formula cells. To avoid repeated calls to calc() when the user presses and holds a key, ng-model-options limits the update rate to once every 200 milliseconds. The id attribute here is interpolated with the coordinate col+row . The id attribute of a HTML element must be different from the id of all other elements in the same document. This ensures that the #A1 ID selector refers to a single element, instead of a set of elements like the class selector .formula . When the user presses the UP / DOWN / ENTER keys, the keyboard-navigation logic in keydown() will use ID selectors to determine which input box to focus on. After the input box, we place a &lt;div&gt; to display the calculated value of the current cell, represented in the JS model by objects errs and vals : &lt;div ng-class= &quot;{ error: errs[col+row], text: vals[col+row][0] }&quot; &gt; {{ errs[col+row] || vals[col+row] }} &lt;/div&gt; If an error occurs when computing a formula, the text interpolation uses the error message contained in errs[col+row] , and ng-class applies the error class to the element, allowing CSS to style it differently (with red letters, aligned to the center, etc.).
