Filter für Audioeffekte definieren Schnittstellen zur Definition von Effekten, die Sie auf Ihre Audioquellen anwenden möchten. BiquadFilterNode Die Schnittstelle BiquadFilterNode stellt einen einfachen Filter niedriger Ordnung dar. Sie ist ein AudioNode , der verschiedene Filterarten, Klangregler oder grafische Equalizer darstellen kann. Ein BiquadFilterNode hat immer genau einen Eingang und einen Ausgang. ConvolverNode Die Schnittstelle ConvolverNode ist ein AudioNode , der eine lineare Faltung auf einen bestimmten AudioBuffer anwendet und häufig zur Erzeugung eines Halleffekts verwendet wird. DelayNode Die Schnittstelle DelayNode stellt eine Verzögerungsleitung dar: ein Audioverarbeitungsmodul vom Typ AudioNode , das die Weitergabe eingehender Daten an den Ausgang verzögert. DynamicsCompressorNode Die Schnittstelle DynamicsCompressorNode bietet einen Kompressionseffekt, der die Lautstärke der lautesten Signalanteile verringert. So lassen sich Clipping und Verzerrungen vermeiden, die auftreten können, wenn mehrere Klänge gleichzeitig wiedergegeben und zusammengemischt werden. GainNode Die Schnittstelle GainNode stellt eine Lautstärkeänderung dar. Sie ist ein Audioverarbeitungsmodul vom Typ AudioNode , das die Eingangsdaten mit einem bestimmten Verstärkungsfaktor multipliziert, bevor es sie an den Ausgang weitergibt. WaveShaperNode Die Schnittstelle WaveShaperNode stellt einen nichtlinearen Verzerrer dar. Sie ist ein AudioNode , der mithilfe einer Kurve eine Waveshaping-Verzerrung auf das Signal anwendet. Neben deutlich hörbaren Verzerrungseffekten wird er häufig verwendet, um dem Signal einen wärmeren Klang zu verleihen. PeriodicWave Beschreibt eine periodische Wellenform, mit der sich die Ausgabe eines OscillatorNode formen lässt. IIRFilterNode Implementiert einen allgemeinen Filter mit unendlicher Impulsantwort (IIR). Dieser Filtertyp kann auch für Klangregler und grafische Equalizer verwendet werden. AudioDestinationNode Die Schnittstelle AudioDestinationNode stellt das endgültige Ausgabeziel einer Audioquelle in einem bestimmten Kontext dar – normalerweise die Lautsprecher Ihres Geräts. MediaStreamAudioDestinationNode Die Schnittstelle MediaStreamAudioDestinationNode stellt ein Audioausgabeziel dar, das aus einem WebRTC - MediaStream mit einem einzelnen AudioMediaStreamTrack besteht. Dieser kann ähnlich wie ein über getUserMedia() erhaltener MediaStream verwendet werden. Sie ist ein AudioNode , der als Audioausgabeziel dient. Räumliche Audiowiedergabe Mit diesen Schnittstellen können Sie Ihren Audioquellen räumliche Panning-Effekte hinzufügen. Audioverarbeitung in JavaScript Mit Audio-Worklets können Sie eigene Audioknoten definieren, die in JavaScript oder WebAssembly geschrieben sind. Audio-Worklets implementieren die Schnittstelle Worklet , eine schlankere Variante der Schnittstelle Worker . AudioWorklet Die Schnittstelle AudioWorklet ist über die Eigenschaft audioWorklet eines AudioContext -Objekts verfügbar. Mit ihr können Sie dem Audio-Worklet Module hinzufügen, die außerhalb des Haupt-Threads ausgeführt werden. AudioWorkletNode Die Schnittstelle AudioWorkletNode stellt einen AudioNode dar, der in einen Audiographen eingebunden ist und Nachrichten mit dem zugehörigen AudioWorkletProcessor austauschen kann. AudioWorkletProcessor Die Schnittstelle AudioWorkletProcessor stellt Audioverarbeitungscode dar, der in einem AudioWorkletGlobalScope ausgeführt wird, Audio direkt erzeugt, verarbeitet oder analysiert und Nachrichten mit dem zugehörigen AudioWorkletNode austauschen kann. AudioWorkletGlobalScope Die Schnittstelle AudioWorkletGlobalScope ist ein von WorkletGlobalScope abgeleitetes Objekt, das einen Worker-Kontext für die Ausführung eines Audioverarbeitungsskripts darstellt. Sie ermöglicht es, Audiodaten mit JavaScript direkt in einem Worklet-Thread statt im Haupt-Thread zu erzeugen, zu verarbeiten und zu analysieren. Veraltet: Script-Processor-Knoten Bevor Audio-Worklets definiert wurden, verwendete die Web Audio API ScriptProcessorNode für die Audioverarbeitung mit JavaScript. Da der Code im Haupt-Thread ausgeführt wird, ist die Leistung schlecht. ScriptProcessorNode bleibt aus historischen Gründen erhalten, ist aber als veraltet gekennzeichnet. ScriptProcessorNode Die Schnittstelle ScriptProcessorNode ermöglicht es, Audio mit JavaScript zu erzeugen, zu verarbeiten oder zu analysieren. Sie ist ein Audioverarbeitungsmodul vom Typ AudioNode , das mit zwei Puffern verbunden ist: einem für die aktuellen Eingangsdaten und einem für die Ausgangsdaten. Jedes Mal, wenn der Eingangspuffer neue Daten enthält, wird ein Ereignis an das Objekt gesendet, das die Schnittstelle AudioProcessingEvent implementiert. Der Event-Handler endet, sobald er den Ausgangspuffer mit Daten gefüllt hat. audioprocess (Ereignis) Das Ereignis audioprocess wird ausgelöst, wenn ein Eingangspuffer eines ScriptProcessorNode der Web Audio API zur Verarbeitung bereit ist. AudioProcessingEvent AudioProcessingEvent stellt Ereignisse dar, die auftreten, wenn ein Eingangspuffer eines ScriptProcessorNode zur Verarbeitung bereit ist. Offline- und Hintergrundverarbeitung von Audio Mit den folgenden Schnittstellen können Sie einen Audiographen im Hintergrund sehr schnell verarbeiten beziehungsweise rendern – in einen AudioBuffer statt über die Lautsprecher des Geräts. OfflineAudioContext Die Schnittstelle OfflineAudioContext ist eine AudioContext -Schnittstelle, die einen Audiographen aus miteinander verbundenen AudioNode -Knoten darstellt. Im Gegensatz zu einem normalen AudioContext gibt ein OfflineAudioContext das Audio nicht in Echtzeit wieder, sondern erzeugt es so schnell wie möglich in einem Puffer. complete (Ereignis) Das Ereignis complete wird ausgelöst, wenn das Rendering eines OfflineAudioContext abgeschlossen ist. OfflineAudioCompletionEvent OfflineAudioCompletionEvent stellt Ereignisse dar, die auftreten, wenn die Verarbeitung eines OfflineAudioContext abgeschlossen ist. Das Ereignis complete verwendet diese Schnittstelle.
