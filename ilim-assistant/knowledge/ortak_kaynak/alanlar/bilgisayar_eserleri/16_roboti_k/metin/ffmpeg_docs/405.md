The range is -1 to INT_MAX ; the default is -1 (no explicit override). &lsquo; constqp &rsquo; Constant QP (0). &lsquo; vbr &rsquo; Variable bitrate (1). &lsquo; cbr &rsquo; Constant bitrate (2). multipass integer Select multipass encoding using a named value from the table (recommended) or its integer. The default is 0 (automatic). The range is 0 to 51 for H.264 and HEVC, or 0 to 63 for AV1. qp integer Set the constant quantization parameter. The default is -1 (unset). The range is -1 to 51 for H.264 and HEVC, or -1 to 255 for AV1. init_qpP integer init_qpB integer init_qpI integer Set the initial QP for P-, B- and I-frames, respectively. Each defaults to -1 (unset). The range is -1 to 51 for H.264 and HEVC, or -1 to 255 for AV1. qp_cb_offset integer qp_cr_offset integer Set the chroma QP offsets for the Cb and Cr channels, respectively. The default is 0. ldkfs integer Set the low-delay keyframe scale, which specifies the scene-change frame size increase allowed with a single-frame VBV buffer and CBR. The range is 0 to 255 and the default is 0. cbr_padding boolean Pad the bitstream to prevent the bitrate falling below the target in CBR mode. The default is 1. H.264 and HEVC use SEI payloads; AV1 uses metadata OBUs. This gates the payload array used for a53cc , HEVC and AV1 s12m_tc , and H.264 and HEVC udu_sei . a53cc boolean Use AV_FRAME_DATA_A53_CC side data for A53 closed captions when available. Requires extra_sei . The default is 1. H.264 and HEVC carry it in ITU-T T.35 registered user-data SEI; AV1 uses an ITU-T T.35 metadata OBU. s12m_tc boolean Use AV_FRAME_DATA_S12M_TIMECODE side data when available. The default is 1. H.264 uses picture timing and requires SDK 12.2 or newer; HEVC uses timecode SEI; AV1 uses timecode metadata OBUs. The HEVC and AV1 paths require extra_sei ; the H.264 path is independent of it. With SDK 13.0 or newer, HEVC and AV1 also support mastering-display and content-light-level metadata. The corresponding AV_FRAME_DATA_MASTERING_DISPLAY_METADATA and AV_FRAME_DATA_CONTENT_LIGHT_LEVEL entries in AVCodecContext.decoded_side_data enable output at initialization. Frame side data supplies per-frame values, falling back to those stream values when absent. This path is independent of extra_sei . 16.29.3.5 Other common options # TOC level integer Set the encoding level restriction using a named value (recommended) or its integer.
