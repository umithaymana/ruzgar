Exposes each JPEG image stored in a CIPA DC-007 MP file as a separate stream, in the order of the MP Entries, with the First Individual Image flagged as the default stream. If the file contains an ISO 21496-1 gain map, as is the case for JPEG Ultra HDR, the primary image and the gain map are linked by a &lsquo; gain_map &rsquo; stream group, and the gain map parameters are exported as frame side data by the decoder. Images of any other type (e.g. large thumbnails or multi-view images) are exposed as additional streams. This demuxer accepts the following options, which behave like the options of the same name of the &lsquo; image2 &rsquo; demuxer: framerate Set the frame rate of the video streams. It should only be enabled if the source is known to be non-malicious. seek_streams_individually When seeking, identify the closest point in each stream individually and demux packets in that stream from identified point. This can lead to a different sequence of packets compared to demuxing linearly from the beginning. Default is true. ignore_editlist Ignore any edit list atoms. The demuxer, by default, modifies the stream index to reflect the timeline described by the edit list. Default is false. advanced_editlist Modify the stream index to reflect the timeline described by the edit list. ignore_editlist must be set to false for this option to be effective. If both ignore_editlist and this option are set to false, then only the start of the stream index is modified to reflect initial dwell time or starting timestamp described by the edit list.
