libavformat library provides some generic global options, which can be set on all the muxers and demuxers. In addition each muxer or demuxer may support so-called private options, which are specific for that component. Options may be set by specifying - option value in the FFmpeg tools, or by setting the value explicitly in the AVFormatContext options or using the libavutil/opt.h API for programmatic use. The list of supported options follows: avioflags flags ( input/output ) Possible values: &lsquo; direct &rsquo; Reduce buffering. probesize integer ( input ) Set probing size in bytes, i.e. the size of the data to analyze to get stream information. A higher value will enable detecting more information in case it is dispersed into the stream, but will increase latency. Must be an integer not lesser than 32. It is 5000000 by default. max_probe_packets integer ( input ) Set the maximum number of buffered packets when probing a codec. Default is 2500 packets. packetsize integer ( output ) Set packet size. fflags flags Set format flags. Some are implemented for a limited number of formats. Possible values for input files: &lsquo; discardcorrupt &rsquo; Discard corrupted packets. &lsquo; fastseek &rsquo; Enable fast, but inaccurate seeks for some formats. &lsquo; genpts &rsquo; Generate missing PTS if DTS is present. &lsquo; igndts &rsquo; Ignore DTS if PTS is also set. In case the PTS is set, the DTS value is set to NOPTS. This is ignored when the nofillin flag is set. &lsquo; ignidx &rsquo; Ignore index. &lsquo; nobuffer &rsquo; Reduce the latency introduced by buffering during initial input streams analysis. &lsquo; nofillin &rsquo; Do not fill in missing values in packet fields that can be exactly calculated. &lsquo; noparse &rsquo; Disable AVParsers, this needs +nofillin too. &lsquo; sortdts &rsquo; Try to interleave output packets by DTS. At present, available only for AVIs with an index. Possible values for output files: &lsquo; autobsf &rsquo; Automatically apply bitstream filters as required by the output format. Enabled by default. &lsquo; bitexact &rsquo; Only write platform-, build- and time-independent data. This ensures that file and data checksums are reproducible and match between platforms. Its primary use is for regression testing. &lsquo; flush_packets &rsquo; Write out packets immediately. &lsquo; shortest &rsquo; Stop muxing at the end of the shortest stream. It may be needed to increase max_interleave_delta to avoid flushing the longer streams before EOF. seek2any integer ( input ) Allow seeking to non-keyframes on demuxer level when supported if set to 1. Default is 0. analyzeduration integer ( input ) Specify how many microseconds are analyzed to probe the input. A higher value will enable detecting more accurate information, but will increase latency. It defaults to 5,000,000 microseconds = 5 seconds. cryptokey hexadecimal string ( input ) Set decryption key. indexmem integer ( input ) Set max memory used for timestamp index (per stream). rtbufsize integer ( input ) Set max memory used for buffering real-time frames. fdebug flags ( input/output ) Print specific debug info.
