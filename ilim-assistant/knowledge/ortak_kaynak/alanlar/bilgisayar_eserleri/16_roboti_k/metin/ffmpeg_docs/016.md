A SBG script looks like that: @example -SE a: 300-2.5/3 440+4.5/0 b: 300-2.5/0 440+4.5/3 off: - NOW == a +0:07:00 == b +0:14:00 == a +0:21:00 == b +0:30:00 off @end example A SBG script can mix absolute and relative timestamps. On the other hand, if the script mixes both kind of timestamps, then the @var{NOW} reference for relative timestamps will be taken from the current time of day at the time the script is read, and the script layout will be frozen according to that reference.
