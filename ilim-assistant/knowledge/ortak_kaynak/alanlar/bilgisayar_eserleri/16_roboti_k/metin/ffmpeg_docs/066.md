They are separated into two categories: @table @option @item generic These options can be set for any container, codec or device. The first instance is encoded with codec ac3 and bitrate 640k. The second instance is downmixed to 2 channels and encoded with codec aac. A bitrate of 128k is specified for it using absolute index of the output stream. Note: the @option{-nooption} syntax cannot be used for boolean AVOptions, use @option{-option 0}/@option{-option 1}.
