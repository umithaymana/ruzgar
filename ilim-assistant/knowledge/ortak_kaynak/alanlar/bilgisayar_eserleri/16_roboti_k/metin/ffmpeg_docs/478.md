It takes three input streams and outputs one stream, the first input is the source, and second and third input are displacement maps. The second input specifies how much to displace pixels along the x-axis, while the third input specifies how much to displace pixels along the y-axis. If one of displacement map streams terminates, last frame from that displacement map will be used. Note that once generated, displacements maps can be reused over and over again. A description of the accepted options follows. edge Set displace behavior for pixels that are out of range. Available values are: &lsquo; blank &rsquo; Missing pixels are replaced by black pixels. &lsquo; smear &rsquo; Adjacent pixels will spread out to replace missing pixels. &lsquo; wrap &rsquo; Out of range pixels are wrapped so they point to pixels of other side. &lsquo; mirror &rsquo; Out of range pixels will be replaced with mirrored pixels. The filter accepts the following options: dnn_backend Specify which DNN backend to use for model loading and execution. This option accepts only openvino now, tensorflow backends will be added. model Set path to model file specifying network architecture and its parameters. Note that different backends use different file formats. input Set the input name of the dnn network. output Set the output name of the dnn network. confidence Set the confidence threshold (default: 0.5). labels Set path to label file specifying the mapping between label id and name. The filter accepts the following options: dnn_backend Specify which DNN backend to use for model loading and execution. This option accepts the following values: &lsquo; tensorflow &rsquo; TensorFlow backend. &lsquo; openvino &rsquo; OpenVINO backend. &lsquo; onnx &rsquo; ONNX Runtime backend. model Set path to model file specifying network architecture and its parameters. Note that different backends use different file formats. input Set the input name of the dnn network. output Set the output name of the dnn network. The TensorFlow and ONNX Runtime backends accept multiple output names separated by &lsquo; &amp; &rsquo;, e.g. output=yolo_13&amp;yolo_26 . confidence Set the confidence threshold (default: 0.5). labels Set path to label file specifying the mapping between label id and name. Each label name is written in one line, tailing spaces and empty lines are skipped. The first line is the name of label id 0 (usually it is &rsquo;background&rsquo;), and the second line is the name of label id 1, etc. The label id is considered as name if the label file is not provided. model_type Set the detection model output format. The following values are accepted: &lsquo; ssd &rsquo; Single-stage detector (default). &lsquo; yolo &rsquo; YOLO v1/v2. &lsquo; yolov3 &rsquo; YOLOv3. &lsquo; yolov4 &rsquo; YOLOv4. anchors Anchor box dimensions, separated by &lsquo; &amp; &rsquo;. Required for YOLO-family models. The list is consumed in output order, so the anchors of the first output come first: with output=yolo_13&amp;yolo_26 the leading pairs belong to yolo_13 . nb_classes Number of detection classes. Required for YOLO-family models. backend_configs Set the configs to be passed into backend. To use async execution, set async (default: set).
