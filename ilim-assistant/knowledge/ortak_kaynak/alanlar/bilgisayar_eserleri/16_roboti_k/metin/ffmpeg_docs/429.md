This identifies a transponder in DVB. Default is 0x0001 . mpegts_original_network_id integer Set the &lsquo; original_network_id &rsquo;. This is unique identifier of a network in DVB. Its main use is in the unique identification of a service through the path &lsquo; Original_Network_ID, Transport_Stream_ID &rsquo;. Default is 0xff01 . mpegts_service_id integer Set the &lsquo; service_id &rsquo;, also known as program in DVB. Default is 0x0001 . mpegts_service_type integer Set the program &lsquo; service_type &rsquo;. Default is digital_tv . Accepts the following options: &lsquo; hex_value &rsquo; Any hexadecimal value between 0x01 and 0xff as defined in ETSI 300 468. &lsquo; digital_tv &rsquo; Digital TV service. &lsquo; digital_radio &rsquo; Digital Radio service. &lsquo; teletext &rsquo; Teletext service. &lsquo; advanced_codec_digital_radio &rsquo; Advanced Codec Digital Radio service. &lsquo; mpeg2_digital_hdtv &rsquo; MPEG2 Digital HDTV service. &lsquo; advanced_codec_digital_sdtv &rsquo; Advanced Codec Digital SDTV service. &lsquo; advanced_codec_digital_hdtv &rsquo; Advanced Codec Digital HDTV service. &lsquo; hevc_digital_hdtv &rsquo; HEVC Digital Television service. mpegts_pmt_start_pid integer Set the first PID for PMTs. Default is 0x1000 , minimum is 0x0020 , maximum is 0x1ffa . This option has no effect in m2ts mode where the PMT PID is fixed 0x0100 . mpegts_start_pid integer Set the first PID for elementary streams. Default is 0x0100 , minimum is 0x0020 , maximum is 0x1ffa . This option has no effect in m2ts mode where the elementary stream PIDs are fixed. mpegts_m2ts_mode boolean Enable m2ts mode if set to 1 . Default value is -1 which disables m2ts mode. muxrate integer Set a constant muxrate. Default is VBR. pes_payload_size integer Set minimum PES packet payload in bytes. Default is 2930 . mpegts_flags flags Set mpegts flags. Accepts the following options: &lsquo; resend_headers &rsquo; Reemit PAT/PMT before writing the next packet. &lsquo; latm &rsquo; Use LATM packetization for AAC. &lsquo; pat_pmt_at_frames &rsquo; Reemit PAT and PMT at each video frame. &lsquo; system_b &rsquo; Conform to System B (DVB) instead of System A (ATSC). &lsquo; initial_discontinuity &rsquo; Mark the initial packet of each stream as discontinuity. &lsquo; nit &rsquo; Emit NIT table. &lsquo; omit_rai &rsquo; Disable writing of random access indicator. mpegts_copyts boolean Preserve original timestamps, if value is set to 1 . Default value is -1 , which results in shifting timestamps so that they start from 0. omit_video_pes_length boolean Omit the PES packet length for video packets. Default is 1 (true). pcr_period integer Override the default PCR retransmission time in milliseconds. Default is -1 which means that the PCR interval will be determined automatically: 20 ms is used for CBR streams, the highest multiple of the frame duration which is less than 100 ms is used for VBR streams. mpegts_pcr_pid integer Set a separate PID for PCR packets. When set to a valid PID value, PCR is carried in adaptation-field-only packets on the specified PID, separate from the elementary stream PIDs. This is required for example by ARIB TR-B14. Default is -1 which means PCR is placed on the elementary stream PIDs. pat_period duration Maximum time in seconds between PAT/PMT tables. Default is 0.1 . sdt_period duration Maximum time in seconds between SDT tables. Default is 0.5 . nit_period duration Maximum time in seconds between NIT tables. Default is 0.5 . tables_version integer Set PAT, PMT, SDT and NIT version (default 0 , valid values are from 0 to 31, inclusively). This option allows updating stream structure so that standard consumer may detect the change. The muxer will attempt to create pages that are approximately duration microseconds long. This allows the user to compromise between seek granularity and container overhead. The default is 1 second. A value of 0 will fill all segments, making pages as large as possible. A value of 1 will effectively use 1 packet-per-page in most situations, giving a small seek granularity at the cost of additional container overhead. -serial_offset value Serial number of the first stream in bitexact mode, the others following consecutively. Chained links need distinct serial numbers, which disjoint ranges of values guarantee. The default of -1 derives each serial number from the stream&rsquo;s headers instead. This makes links with different headers or tags unlikely to share a serial number, without ruling it out. Links with identical headers and tags always share one, which separately muxed outputs avoid with explicit offsets. A link the muxer starts itself on new stream metadata keeps the offset of the link before it. With an explicit offset it then reuses its serial number. With the default it does so when its headers and tags are unchanged. 21.72 pdv # TOC Playdate Video muxer. This muxer writes the Playdate video container used by Panic&rsquo;s Playdate SDK.
