The kernel function needs to take the following arguments: @itemize @item Destination image, @var{__write_only image2d_t}. This image will become the output; the kernel should write all of it. @item Frame index, @var{unsigned int}. This is a counter starting from zero and increasing by one for each frame. @item Source images, @var{__read_only image2d_t}. These are the most recent images on each input.
