Sponsors &amp; Supporters Sponsors &amp; Supporters This page is a work in progress and is not yet a complete list of FFmpeg's sponsors and supporters. FFmpeg is developed by volunteers and runs on donated money, hardware and services. This page thanks the organizations and individuals whose support keeps the project going, lists what the project needs next, and explains how to become a sponsor. Funding and Grants Sovereign Tech Fund Germany's Sovereign Tech Fund became FFmpeg's first governmental sponsor in 2024. Its grant funds maintenance of the project, a critical multimedia component for billions of people every day. Hardware and Infrastructure Ampere Computing Ampere donated an AmpereOne&reg; server with 192 Arm cores in 2026. It handles the base load of FFmpeg's ARM CI, and Fairy builds and tests on it when reviewing pull requests and investigating issues. See the announcement . Telepoint &amp; MediaHub Telepoint, a carrier-neutral data center in Sofia, and MediaHub, a Bulgarian IPTV provider, have hosted FFmpeg servers with free internet connectivity since 2015 and recently added two more. Developer Tools and Services GitHub GitHub provides the FFmpeg organization with a free Team plan and runs FFmpeg's CI on GitHub Actions. Anthropic Anthropic gives some FFmpeg developers access to Claude through its open source program. OpenAI OpenAI provides API credits to FFmpeg. Cursor Cursor provides free credits to FFmpeg developers. depthfirst depthfirst provides its security scanner to FFmpeg. Blacksmith Blacksmith provides runners for FFmpeg's CI jobs on GitHub Actions. Individual Supporters Many individuals donate to FFmpeg through SPI and GitHub Sponsors. These donations pay for servers, hardware and other project expenses. Thank you! Community Programs Google Summer of Code FFmpeg takes part in Google Summer of Code as a mentoring organization. Google pays contributors to work on FFmpeg over the summer, mentored by FFmpeg developers. Past and current projects are listed on the wiki . OSS-Fuzz Google's OSS-Fuzz continuously fuzzes FFmpeg and reports the crashes it finds to the developers. What FFmpeg Needs FFmpeg is used by nearly every product that touches audio or video, but the work that keeps it secure and reliable is largely done by volunteers. Support in the following areas has the largest effect: Maintainers: people who review changes, fix bugs and keep their part of FFmpeg working. Companies that depend on FFmpeg can help most by letting their developers maintain the code they use. Hardware: access to any hardware you want FFmpeg to keep working reliably on, preferably as a VM or an account on a machine you maintain. It lets the project test every change there (CI and FATE ) and run Fairy , the project's assistant that reviews pull requests and investigates bug reports. Money: donations in USD or EUR through SPI or GitHub Sponsors pay for servers, hardware and other project expenses. Become a Sponsor Fund the project Donations are received by Software in the Public Interest , a US 501(c)(3) non-profit, and may be tax deductible for US taxpayers. For larger grants or earmarked funding, get in touch first. Donate Donate hardware or services Servers, test machines, hosting, bandwidth and developer tools are all welcome. Write to the ffmpeg-devel mailing list to find out what is currently needed. Contact Fund specific work To get a feature or fix you need, hire an FFmpeg developer. This also supports the project indirectly. Hire Developers Sponsors are listed on this page.
