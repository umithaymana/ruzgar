Writing a fragmented file has the advantage that the file is decodable even if the writing is interrupted (while a normal MOV/MP4 is undecodable if it is not properly finished), and it requires less memory when writing very long files (since writing normal MOV/MP4 files stores info about every single packet in memory until the file is closed). The downside is that it is less compatible with other applications. Fragmentation is enabled by setting one of the options that define how to cut the file into fragments: frag_duration frag_size min_frag_duration movflags +frag_keyframe movflags +frag_custom If more than one condition is specified, fragments are cut when one of the specified conditions is fulfilled. The exception to this is the option min_frag_duration , which has to be fulfilled for any of the other conditions to apply. 21.4.3 Options # TOC brand brand_string Override major brand. empty_hdlr_name bool Enable to skip writing the name inside a hdlr box.
