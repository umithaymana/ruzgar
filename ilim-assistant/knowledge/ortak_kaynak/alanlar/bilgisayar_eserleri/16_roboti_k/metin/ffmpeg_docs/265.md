The default is 1. H.264 and HEVC use SEI payloads; AV1 uses metadata OBUs. This gates the payload array used for a53cc , HEVC and AV1 s12m_tc , and H.264 and HEVC udu_sei . a53cc boolean Use AV_FRAME_DATA_A53_CC side data for A53 closed captions when available. Requires extra_sei . The default is 1. H.264 uses picture timing and requires SDK 12.2 or newer; HEVC uses timecode SEI; AV1 uses timecode metadata OBUs. The HEVC and AV1 paths require extra_sei ; the H.264 path is independent of it. With SDK 13.0 or newer, HEVC and AV1 also support mastering-display and content-light-level metadata. The corresponding AV_FRAME_DATA_MASTERING_DISPLAY_METADATA and AV_FRAME_DATA_CONTENT_LIGHT_LEVEL entries in AVCodecContext.decoded_side_data enable output at initialization.
