Go to http://www.openh264.org/ and follow the instructions for installing the library. Then pass --enable-libopenh264 to configure to enable it. For decoding, this library is much more limited than the built-in decoder in libavcodec; currently, this library lacks support for decoding B-frames and some other main/high profile features. (It currently only supports constrained baseline profile and CABAC.) Using it is mostly useful for testing and for taking advantage of Cisco&rsquo;s patent portfolio license ( http://www.openh264.org/BINARY_LICENSE.txt ). 41.22 OpenJPEG # TOC FFmpeg can use the OpenJPEG libraries for decoding/encoding J2K videos. Due to security concerns, Vapoursynth scripts will not be autodetected so the input format has to be forced.
