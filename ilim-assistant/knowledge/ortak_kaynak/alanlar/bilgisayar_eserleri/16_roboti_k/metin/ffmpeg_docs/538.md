Once libcodec2 is installed you can pass --enable-libcodec2 to configure to enable it. The easiest way to use codec2 is with .c2 files, since they contain the mode information required for decoding. To encode such a file, use a .c2 file extension and give the libcodec2 encoder the -mode option: ffmpeg -i input.wav -mode 700C output.c2 . Playback is as simple as ffplay output.c2 . For a list of supported modes, run ffmpeg -h encoder=libcodec2 . Raw codec2 files are also supported.
