Supports more pixel formats than nlmeans or nlmeans_opencl , including alpha channel support. The filter accepts the following options. s Set denoising strength for all components. Default is 1.0. Must be in range [0.0, 100.0]. p Set patch size for all planes. Default is 7. Must be odd number in range [0, 99]. r Set research size. Default is 15.
