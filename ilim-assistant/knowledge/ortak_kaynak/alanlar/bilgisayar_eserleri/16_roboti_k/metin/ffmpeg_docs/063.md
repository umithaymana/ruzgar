For example it can be used to check the format of the container used by a multimedia stream and the format and type of each media stream contained in it. If a url is specified in input, ffprobe will try to open and probe the url content. If the url cannot be opened or recognized as a multimedia file, a positive exit code is returned. If no output is specified as output with @option{o} ffprobe will write to stdout. ffprobe may be employed both as a standalone application or in combination with a textual filter, which may perform more sophisticated processing, e.g. statistical processing or plotting. Options are used to list some of the formats supported by ffprobe or for specifying which information to display, and for setting how ffprobe will show it. ffprobe output is designed to be easily parsable by a textual filter, and consists of one or more sections of a form defined by the selected writer, which is specified by the @option{output_format} option. Sections may contain other nested sections, and are identified by a name (which may be shared by other sections), and an unique name. See the output of @option{sections}.
