Default is 1 (on). 9.29 NVENC encoders # TOC The h264_nvenc , hevc_nvenc and av1_nvenc encoders use NVIDIA NVENC hardware to encode H.264, HEVC and AV1 video, respectively. Building them requires the ffnvcodec headers provided by nv-codec-headers . They are autodetected by configure; they can also be enabled explicitly with --enable-ffnvcodec and --enable-nvenc . Available options and values depend on the SDK version exposed by the headers at build time. Feature checks in libavcodec/nvenc.h distinguish SDK versions 12.0, 12.1, 12.2, 13.0 and 13.1. Runtime support also depends on the GPU and driver. Use ffmpeg -h encoder=hevc_nvenc , or substitute h264_nvenc or av1_nvenc , to list the options, devices and pixel formats available in a particular build. 9.29.1 Hardware input and devices # TOC These encoders accept system-memory frames and CUDA hardware frames ( AV_PIX_FMT_CUDA ). Builds using SDK 13.1 or newer also accept CUDA array frames ( AV_PIX_FMT_CUARRAY ). Builds with d3d11va support accept D3D11 hardware frames ( AV_PIX_FMT_D3D11 ). The input pixel format and encoding features must be supported by the selected GPU. For CUDA decoding followed by encoding, use the input options -hwaccel cuda -hwaccel_output_format cuda to keep decoded frames on the device. A hardware device can also be created with -init_hw_device and supplied to the encoder, directly or through its hardware frames context. For system-memory input without a supplied hardware device, the encoder option gpu selects the device. See its entry under Other common options below. 9.29.2 Generic options # TOC Several generic encoding options are mapped to NVENC settings. The bitrate options b , maxrate and bufsize set the average bitrate, the maximum bitrate and the VBV buffer size; the NVENC default for b is &lsquo; 2M &rsquo;. g sets the GOP length, with 0 requesting intra-only encoding. bf sets the number of B-frames between non-B-frames. refs sets the number of reference frames in each reference list. g and bf default to -1 and refs defaults to 0; these defaults leave the values of the preset unchanged. The generic qmin and qmax options are honoured in VBR mode with a warning; API users should set the encoder options of the same names listed below instead. Only applications calling the libavcodec API can change AVCodecContext.bit_rate , AVCodecContext.rc_max_rate and AVCodecContext.rc_buffer_size during encoding. The encoder checks these fields before encoding each frame. When dynamic bitrate changes are supported and rate control is not &lsquo; constqp &rsquo;, changed positive values trigger reconfiguration, reset the encoder and force an IDR. A change to the display aspect ratio also triggers reconfiguration. 9.29.3 Common options # TOC The following option names are shared by all three encoders.
