The video processor and output color properties are configured from the first frame and reused for subsequent frames. Changes in frame dimensions require filter-graph reinitialization. If this filter changes the output color primaries and/or transfer characteristics relative to the input, side data describing those properties (mastering display metadata, HDR10+/Dolby Vision metadata, ICC profile, ...) is removed from the output frame. Alpha is preserved for RGB formats that have it ( bgra , rgba , rgbaf16 ); other formats, and devices that cannot pass alpha through, produce opaque alpha instead. A premultiplied-alpha input is rejected if the requested conversion cannot preserve it correctly (e.g. it also changes color space); unpremultiply the input first in that case. This is done by changing the specified Sample (aka Pixel) Aspect Ratio, according to the following equation: DAR = HORIZONTAL_RESOLUTION / VERTICAL_RESOLUTION * SAR Keep in mind that the setdar filter does not modify the pixel dimensions of the video frame.
