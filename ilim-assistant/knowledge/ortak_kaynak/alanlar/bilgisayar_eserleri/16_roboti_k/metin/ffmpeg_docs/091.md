This filter accepts the following options: @table @option @item mapping Set input to output plane mapping. Default is @code{0}. The mappings is specified as a bitmap. It should be specified as a hexadecimal number in the form 0xAa[Bb[Cc[Dd]]]. 'Aa' describes the mapping for the first plane of the output stream.
