In addition each muxer or demuxer may support so-called private options, which are specific for that component. Options may be set by specifying - option value in the FFmpeg tools, or by setting the value explicitly in the AVFormatContext options or using the libavutil/opt.h API for programmatic use. The list of supported options follows: avioflags flags ( input/output ) Possible values: &lsquo; direct &rsquo; Reduce buffering. probesize integer ( input ) Set probing size in bytes, i.e. the size of the data to analyze to get stream information. A higher value will enable detecting more information in case it is dispersed into the stream, but will increase latency. Must be an integer not lesser than 32. It is 5000000 by default. max_probe_packets integer ( input ) Set the maximum number of buffered packets when probing a codec. Default is 2500 packets. packetsize integer ( output ) Set packet size. fflags flags Set format flags. Some are implemented for a limited number of formats. Possible values for input files: &lsquo; discardcorrupt &rsquo; Discard corrupted packets. &lsquo; fastseek &rsquo; Enable fast, but inaccurate seeks for some formats. &lsquo; genpts &rsquo; Generate missing PTS if DTS is present. &lsquo; igndts &rsquo; Ignore DTS if PTS is also set. In case the PTS is set, the DTS value is set to NOPTS. This is ignored when the nofillin flag is set. &lsquo; ignidx &rsquo; Ignore index. &lsquo; nobuffer &rsquo; Reduce the latency introduced by buffering during initial input streams analysis. &lsquo; nofillin &rsquo; Do not fill in missing values in packet fields that can be exactly calculated. &lsquo; noparse &rsquo; Disable AVParsers, this needs +nofillin too. &lsquo; sortdts &rsquo; Try to interleave output packets by DTS. At present, available only for AVIs with an index. Possible values for output files: &lsquo; autobsf &rsquo; Automatically apply bitstream filters as required by the output format. Enabled by default. &lsquo; bitexact &rsquo; Only write platform-, build- and time-independent data. This ensures that file and data checksums are reproducible and match between platforms. Its primary use is for regression testing. &lsquo; flush_packets &rsquo; Write out packets immediately. &lsquo; shortest &rsquo; Stop muxing at the end of the shortest stream. It may be needed to increase max_interleave_delta to avoid flushing the longer streams before EOF. seek2any integer ( input ) Allow seeking to non-keyframes on demuxer level when supported if set to 1. Default is 0. analyzeduration integer ( input ) Specify how many microseconds are analyzed to probe the input. A higher value will enable detecting more accurate information, but will increase latency. It defaults to 5,000,000 microseconds = 5 seconds. cryptokey hexadecimal string ( input ) Set decryption key. indexmem integer ( input ) Set max memory used for timestamp index (per stream). rtbufsize integer ( input ) Set max memory used for buffering real-time frames. fdebug flags ( input/output ) Print specific debug info. Possible values: &lsquo; ts &rsquo; Print timestamp information. &lsquo; id3v2 &rsquo; Print ID3v2 frame data when demuxing files containing ID3v2 tags. max_delay integer ( input/output ) Set maximum muxing or demuxing delay in microseconds. fpsprobesize integer ( input ) Set number of frames used to probe fps. audio_preload integer ( output ) Set microseconds by which audio packets should be interleaved earlier. chunk_duration integer ( output ) Set microseconds for each chunk. chunk_size integer ( output ) Set size in bytes for each chunk. err_detect, f_err_detect flags ( input ) Set error detection flags. f_err_detect is deprecated and should be used only via the ffmpeg tool. Possible values: &lsquo; crccheck &rsquo; Verify embedded CRCs. &lsquo; bitstream &rsquo; Detect bitstream specification deviations. &lsquo; buffer &rsquo; Detect improper bitstream length. &lsquo; explode &rsquo; Abort decoding on minor error detection. &lsquo; careful &rsquo; Consider things that violate the spec and have not been seen in the wild as errors. &lsquo; compliant &rsquo; Consider all spec non compliancies as errors. &lsquo; aggressive &rsquo; Consider things that a sane encoder should not do as an error. max_interleave_delta integer ( output ) Set maximum buffering duration for interleaving. The duration is expressed in microseconds, and defaults to 10000000 (10 seconds). To ensure all the streams are interleaved correctly, libavformat will wait until it has at least one packet for each stream before actually writing any packets to the output file. When some streams are &quot;sparse&quot; (i.e. there are large gaps between successive packets), this can result in excessive buffering. This field specifies the maximum difference between the timestamps of the first and the last packet in the muxing queue, above which libavformat will output a packet regardless of whether it has queued a packet for all the streams. If set to 0, libavformat will continue buffering packets until it has a packet for each stream, regardless of the maximum timestamp difference between the buffered packets. use_wallclock_as_timestamps integer ( input ) Use wallclock as timestamps if set to 1. Default is 0. avoid_negative_ts integer ( output ) Possible values: &lsquo; make_non_negative &rsquo; Shift timestamps to make them non-negative. Also note that this affects only leading negative timestamps, and not non-monotonic negative timestamps. &lsquo; make_zero &rsquo; Shift timestamps so that the first timestamp is 0. &lsquo; auto (default) &rsquo; Enables shifting when required by the target format. &lsquo; disabled &rsquo; Disables shifting of timestamp. When shifting is enabled, all output timestamps are shifted by the same amount.
