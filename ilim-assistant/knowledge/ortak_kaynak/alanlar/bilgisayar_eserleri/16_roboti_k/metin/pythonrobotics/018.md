Distance Map &mdash; PythonRobotics documentation Mapping Distance Map Edit on GitHub Distance Map  This is an implementation of the Distance Map algorithm for path planning. The Distance Map algorithm computes the unsigned distance field (UDF) and signed distance field (SDF) from a boolean field representing obstacles. The UDF gives the distance from each point to the nearest obstacle. The SDF gives positive distances for points outside obstacles and negative distances for points inside obstacles.
