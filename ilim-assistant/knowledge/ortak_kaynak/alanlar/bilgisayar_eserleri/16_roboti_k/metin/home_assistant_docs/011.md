For the steps, refer to Performing an action . What the response data looks like Response data is a set of keys, each with a value. Which keys it contains depends on the action: An action that targets entities, such as calendar.get_events or weather.get_forecasts , returns one entry for each entity. The key of each entry is the entity ID. This is why the earlier example uses agenda['calendar.school'] . Use the entity ID even if the action targets only one entity. Other actions return their own keys. To see them, perform the action in Settings &gt; Tools &gt; Actions . For the steps, refer to Performing an action . Response data from scripts A script can also return response data. To return data, the script uses the Stop building block with a response variable. To use the data, run the script as an action, for example, script.morning_report . For scripts, the response variable is optional. If you start the script with script.turn_on , you don’t get its data. This action starts the script and continues right away, without waiting for it to finish. Some integrations that run your own commands can also return data, such as RESTful Command , Shell Command , and Python Scripts . For these actions, the response variable is optional, too. Templates in actions With templating , an action can decide what to do when it runs. In text fields, such as the message of a notification, you can enter a template directly. For other templates, such as for the action itself, its targets, or all its options at once, select Menu &gt; Edit in YAML on the action. Choosing the action with a template A template can choose which action to perform. For example, the following action turns a switch on or off based on the temperature. Action An action makes Home Assistant do something, for example, turn on a light, send a notification, or activate a scene. Automations and scripts run a list of actions. [Learn more] action: &gt; {% if states('sensor.temperature') | float(15) &gt; 15 %} switch.turn_on {% else %} switch.turn_off {% endif %} target: entity_id: switch.ac Setting targets and options with a template Templates can also set the target and the options that you pass to the action. Action An action makes Home Assistant do something, for example, turn on a light, send a notification, or activate a scene. Automations and scripts run a list of actions. [Learn more] action: climate.set_temperature target: entity_id: &gt; {% if now().hour &gt;= 22 %} climate.bedroom {% else %} climate.living_room {% endif %} data: temperature: "{{ 18 if now().hour &gt;= 22 else 21 }}" A template can also return all options at once, as a dictionary. Use this when different situations need different options, not just different values. The action is performed right away. For example, a light turns on, or a notification is sent. To run an action that you already added, select Menu &gt; Run action on the action. For the steps and results, refer to Testing an action . To run all the actions of an automation at once, refer to Testing all the actions .
