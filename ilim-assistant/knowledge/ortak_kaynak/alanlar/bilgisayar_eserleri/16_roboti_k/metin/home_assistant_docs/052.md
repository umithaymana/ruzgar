Removing a device from the current Z-Wave network Do this before using the device with another adapter, or when you don’t use the device anymore. It removes the device from the Z-Wave network stored on the adapter. It also removes the device and all its entities from Home Assistant. You cannot join a device to a new network if it is still paired with an adapter. In Home Assistant, go to Settings &gt; Devices &amp; services . Select the Z-Wave integration. Then, select the device you want to remove. Under Device info , select the three-dot menu, then select Delete . This opens a dialog with options for removing the device. Select Remove a working device . The Z-Wave adapter is now in exclusion mode. Put the device you want to remove in exclusion mode. Refer to its manual to learn how this is done. The UI should confirm that the device was removed and the device and entities will be removed from Home Assistant. Removing a device from a foreign Z-Wave network Do this when you have a device that is still paired with an adapter, but you don’t have access to that adapter anymore. If the device was not excluded from that adapter, you cannot join it to a new network. This process removes the device from the previous adapter’s network, allowing you to pair it with a new adapter. In Home Assistant, go to Settings &gt; Connectivity &gt; Z-Wave . Select Options . Next to Remove foreign device , select Remove &gt; Start exclusion . Put the device you want to remove in exclusion mode. Refer to its manual to learn how this is done. The UI should confirm that the device was removed and the device and entities will be removed from Home Assistant. Using a Z-Wave adapter connected to an ESPHome device Your Z-Wave adapter doesn’t have to be plugged into your Home Assistant server. It can also connect to an ESP32-based device running ESPHome . The ESPHome device then passes the Z-Wave traffic to Home Assistant over your network. This lets you place the adapter anywhere you have a Wi-Fi or Ethernet connection. For example, you can use the experimental Portable Z-Wave firmware with a Home Assistant Connect ZWA-2 . Portable Z-Wave is ESPHome firmware for connecting a Z-Wave adapter to Home Assistant over your network. You can use it in two ways: Install it on the Home Assistant Connect ZWA-2 itself. The adapter then connects over its built-in Wi-Fi. Install it on an ESP32 board with Power over Ethernet (PoE). Then plug the Home Assistant Connect ZWA-2 into that board by USB. The adapter keeps its standard firmware. To install the firmware, use the Open Home Foundation toolbox . Over the network, Z-Wave devices respond a little slower than over USB. On most home networks, you won’t notice the difference. On a busy network or with a weak Wi-Fi signal, the delay can become noticeable. How Home Assistant finds an adapter connected to an ESPHome device Two integrations work together to find the adapter: The ESPHome integration finds the ESPHome device on your network. After you add the ESPHome device, it tells Home Assistant that a Z-Wave adapter is connected to it. The Z-Wave integration then shows the adapter as a discovered device. Its name has the format Network home ID via ESPHome device name (ESPHome) . It includes Home Assistant Core, the Home Assistant Supervisor, and supports apps. Home Assistant Supervisor keeps it up to date, removing the need for you to manage an operating system. Home Assistant Operating System is the recommended installation type for most users. . To set up a Z-Wave adapter connected to an ESPHome device Go to Settings &gt; Devices &amp; services . Under Discovered , find the ESPHome device and select Add . For example: your Home Assistant Connect ZWA-2 running Portable Z-Wave, or the ESP32 board it’s plugged into. Follow the steps on screen to add the device to the ESPHome integration. If you already added the ESPHome device, skip this step. Continue with the Z-Wave adapter: If the adapter is already part of a Z-Wave network, the Z-Wave setup opens right after you add the ESPHome device. Otherwise, or if you closed that dialog, wait for the Z-Wave adapter to show up under Discovered , then select Add . Its name ends with (ESPHome) . Follow the steps that match your situation: If you don’t use Z-Wave yet, select Recommended installation . Then follow the steps to set up a Z-Wave server , starting with step 3. If you already use Z-Wave with a different adapter, the Migrate to a new adapter dialog opens. Select Submit . Home Assistant backs up the network from the old adapter. When asked, unplug the old adapter and select Submit . Result: Home Assistant restores the network to the new adapter. If you moved your existing adapter to the ESPHome device, select Recommended installation . Result: Home Assistant confirms that the migration was successful. Your Z-Wave devices and entities stay as they are. What changes in the Z-Wave JS app When the adapter is connected to an ESPHome device, the Z-Wave JS app connects to it over your network instead of through a USB port. Home Assistant sets this up for you. You don’t need to change any settings in the app. On the app’s Configuration tab, the Device option is no longer set. The Socket option holds the address of the ESPHome device, for example esphome://192.168.1.50:6053 . If the ESPHome device uses API encryption, the address also includes the encryption key. If the IP address of the ESPHome device changes, Home Assistant updates the Socket option automatically. The app connects to one adapter at a time. To use a USB adapter and an adapter connected to an ESPHome device at the same time, you need a second Z-Wave JS server. Migrating a Z-Wave network to a new adapter Do this if you have an existing Z-Wave network and want to replace its adapter with a new adapter. The Z-Wave integration with all its entities will stay in Home Assistant. The new adapter is added to Home Assistant and paired with the existing network.
