Setting the group parameter enforce_joint_model_state_space:true in the ompl_planning.yaml file enforces the use of joint space for all plans. By default, planning requests with orientation path constraints are sampled in cartesian space so that invoking IK serves as a generative sampler. By enforcing joint space , the planning process will use rejection sampling to find valid requests. Please note that this might increase planning time considerably.
