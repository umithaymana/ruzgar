MoveIt 2 Documentation &mdash; MoveIt Documentation: Rolling documentation MoveIt 2 Documentation Edit on GitHub MoveIt 2 Documentation  Welcome to the unified MoveIt documentation, which includes tutorials, how-to guides, core concepts, and more. MoveIt 2 is the robotic manipulation platform for ROS 2 and incorporates the latest advances in motion planning, manipulation, 3D perception, kinematics, control, and navigation. MoveIt 2 was first released in 2019; for ROS 1 documentation, see MoveIt 1 tutorials . For the commercially supported version see MoveIt Pro tutorials . MoveGroup - ROS Wrappers in C++  The simplest way to use MoveIt through scripting is using the move_group_interface . This interface is ideal for beginners and provides unified access to many of the features of MoveIt. Move Group C++ Interface Using MoveIt Directly Through the C++ API  Building more complex applications with MoveIt often requires developers to dig into MoveIt’s C++ API. As an added plus, using the C++ API directly skips many of the ROS Service/Action layers resulting in significantly faster performance.
