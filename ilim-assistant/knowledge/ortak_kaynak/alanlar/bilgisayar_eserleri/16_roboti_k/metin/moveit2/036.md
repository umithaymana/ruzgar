Planning For Differential-Drive Mobile Base and an Arm &mdash; MoveIt Documentation: Rolling documentation Examples Planning For Differential-Drive Mobile Base and an Arm Edit on GitHub Planning For Differential-Drive Mobile Base and an Arm  This tutorial will show how you can configure a mobile manipulator with a differential drive base so that you can plan coordinated motions for the base and the other degrees of freedom using MoveIt. While you could use MoveIt to plan for just the base, this is not recommended. Use Nav2 for pure navigation. Note that the tutorial uses Hello Robot’s Stretch platform for demonstration purposes, the same approach can be used for any mobile manipulator with a diff-drive base. For the source-code take a look at stretch_kinematics_plugin Setting up the kinematics model for the base  To be able to generate plan for a differential-drive base we need to set-up two joint properties motion_model  This’s used to config the planar joint model, it can have two values: holonomic: The joint can move in any direction, this is the default value if no motion_model joint property is specified diff_drive: The joint will have differential drive constraint (can’t move side-ways) &lt;joint_property joint_name= &quot;planar_joint_name&quot; property_name= &quot;motion_model&quot; value= &quot;diff_drive&quot; /&gt; min_translational_distance  If the distance between two states is less than min_translational_distance the motion will be pure rotation, the default value is 1e-5 , for more info see computeTurnDriveTurnGeometry for why this’s needed &lt;joint_property joint_name= &quot;planar_joint_name&quot; property_name= &quot;min_translational_distance&quot; value= &quot;0.01&quot; /&gt; angular_distance_weight  Could be set for both planar joints (diff_drive/holonomic) and floating joints, the default value is 1.0 This is used when calculating the distance between two base poses (x0, y0, theta0) and (x1, y1, theta1) which is defined as the weighted sum of the distance between position and orientation: ||(x0, y0) - (x1, y1)|| + angular_distance_weight * |theta0 - theta1| . &lt;joint_property joint_name= &quot;planar_joint_name&quot; property_name= &quot;angular_distance_weight&quot; value= &quot;0.5&quot; /&gt; Running the Code  Open a shell and start RViz and wait for everything to finish loading: ros2 launch stretch_moveit_config demo . launch . py use_fake_controller := True Planning for differential-drive base and arm Planning after adding a collision object to planning scene The Launch File  The entire launch file is here on GitHub.
