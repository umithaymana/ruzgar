You can then run the scripts by typing their name, as well as the .sh extension, in the terminal environment. &nbsp; If you want to avoid typing the &#39;sh&#39; extensions, you can create (once and for all) symbolic links in your ~/bin folder. Here is an example how to do it for, say, the HardwareSimulator tool: &nbsp; ln -s ~/nand2tetris/tools/HardwareSimulator.sh HardwareSimulator chmod +x HardwareSimulator ​ Windows users ​ For the batch files to work from the command line, you must add (once and for all) the nand2tetris/tools folder to your PATH variable. ​ To run a batch file from command-line, type its name, without the .bat extension. ​ If you use Windows 7 64-bit you need to install the 64-bit version of Java so that 64-bit cmdexe can run Java commands in batch files. If you get the output &quot;&#39;java&#39; is not recognized...&quot; you likely only have the 32-bit Java installed on your computer. ​ You can create desktop icons and use them to invoke the interactive versions of the following supplied tools: HardwareSimulator, Assembler, CPUEmulator and VMEmulator. This can be done by finding the disk locations of the respective batch files, right-clicking on them and picking &quot;Send to &gt; Desktop.&quot; Edit the shortcuts&#39; properties and set &quot;Run&quot; to &quot;minimized.&quot; ​ Usage ​ Hardware Simulator : To invoke the hardware simulator in interactive mode, type &quot;HardwareSimulator&quot; in the command line. For example: ​ C:\...\projects\02&gt; HardwareSimulator (a window will open up, running the interactive version of the Hardware Simulator) ​ To invoke the hardware simulator in batch (shell/cmd) mode, type &quot;HardwareSimulator&quot; in the command line. For example: ​ C:\...\projects\02&gt;HardwareSimulator ALU.tst (invokes the simulator, loads the given test script, executes it, and reports the result). Note that the simulator&#39;s interactive mode also enables loading and executing test scripts. &nbsp; Successful test (example): ​ C:\...\projects\02&gt; HardwareSimulator ALU.tst End of script - Comparison ended successfully &nbsp; Failed test (example): ​ C:\...\projects\02&gt; HardwareSimulator ALU.tst Comparison failure at line 24 &nbsp; Error in the associated HDL file: ​ C:\...\projects\02&gt; HardwareSimulator ALU.tst In HDL file C:\...\projects\02\ALU.hdl, Line 60, out[16]: the specified sub bus is not in the bus range: load ALU.hdl ​ CPU Emulator and VM Emulator : The operations of these tools follow the same convention described above. If you invokve either tool without a parameter, the tool will work in interactive mode; if you supply a parameter (test script), the tool will run batch-style. ​ Assembler : Typing &quot;Assembler&quot; will start the supplied assembler in interactive mode. Typing &quot;Assembler xxx.asm&quot; will assemble the specified xxx.asm file and generate a file named xxx.hack, containing the translated binary code. Note that the assembler&#39;s interactive mode also enables loading and translating .asm files. &nbsp; Successful assembly (example): ​ C:\...\projects\04\fill&gt; Assembler Fill.asm Assembling &quot;c:\...\projects\04\fill\Fill.asm&quot; &nbsp; Failed assembly (example): &nbsp; C:\...\projects\04\fill&gt; Assembler Fill.asm Assembling &quot;C:\...\projects\04\fill\Fill.asm&quot; In line 15, Expression expected ​ To compare the resulting .hack code file to some expected .hack file, use the supplied TextComparer tool, described below. ​ Compiler : Typing &quot;JackCompiler fileName.jack&quot; will compile the supplied Jack file. Typing &quot;JackCompiler folderName&quot; will compile all the Jack file in the specified folder. Wildcards are not supported. Examples: &nbsp; Compile a single file: ​ C:\...\projects\09\Reflect&gt; JackCompiler Mirrors.jack Compiling &quot;C:\...\projects\09\Reflect\Mirrors.jack&quot; &nbsp; Compile a folder named &quot;reflect&quot;: ​ C:\...\projects\09&gt; JackCompiler reflect Compiling &quot;C:\...\projects\09\reflect&quot; ​ TextComparer : Compares two given files ignoring white space, and reports success or failure. For example, suppose you run the hardware simulator with some test script and get a comparison failure. If you want, you can then use the TextComparer to investigate the problem: &nbsp; C:\...\projects\02&gt; HardwareSimulator ALU.tst Comparison failure at line 24 &nbsp; C:\...\projects\02&gt; TextComparer ALU.cmp ALU.out Comparison failure in line 23: |0101101110100000|0001111011010010|1|1|0|0|0|0|0001111011010010|0|0| |0101101110100000|0001111011010010|1|1|0|0|0|0|0001111011010010|0|1| ​ (Note the line number discrepancy between the reports of the two tools). ​ Help : In Windows, each batch file accepts a &quot;/?&quot; option that shows its intended usage. In Mac and Unix, use &quot;-h&quot;. For example: ​ C:\...\projects\09&gt;JackCompiler /? Usage: JackCompiler Compiles all the .jack files in the current working directory.
