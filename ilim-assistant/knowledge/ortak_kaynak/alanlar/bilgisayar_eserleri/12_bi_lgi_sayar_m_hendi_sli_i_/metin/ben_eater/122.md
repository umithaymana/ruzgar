(other than p->lock) on a single-core machine, imagine this: P1 P2 acq(Lx) sched() acq(Ly) acq(Lx) P2 will wait forever: P2 will spin waiting for P1 to release Lx P2 holds Ly, so it must keep interrupts off No clock interrupts, so P1 won't run So Lx won't ever be released possible even on multi-core, with more locks/threads solution: forbid holding lock when yielding the CPU!
