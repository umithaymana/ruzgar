# Web önbelleği (geçici / güncel)

Kalıcı kütüphane (`KAYNAK_KAYIT.json`) ile **karıştırılmaz**.

- Web’den gelen bilgi için mümkünse `url` + `erisim_utc` saklanır.
- `kaynak_sinifi`: her zaman `web`.
- Atıfta web ile kalıcı kaynak aynı blokta «tek kitapmış gibi» birleştirilmez; web ayrı belirtilir.

Web araştırması ürünü ileride eklenecek; bu klasör yer tutucudur.
